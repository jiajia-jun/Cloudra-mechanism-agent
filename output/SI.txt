S1 Benchmark design and experimental protocol
S1.1 Task specification and study units
CloudraBench tests whether agents can construct the requested species and reaction pathways, run the calculations, and
draw conclusions supported by the results. It comprises 50 tasks: 20 Easy, 10 Normal, 10 Hard, and 10 Impossible. Easy
tasks cover elementary transformations, conformational changes, and basic execution; Normal tasks require identifying
intermediates and connecting successive elementary steps; Hard tasks compare competing pathways and stereochemical
products; Impossible tasks require recognizing what the allowed electronic-structure methods can support. Each task
specifies reactant and target identities, reaction conditions, total charge, spin multiplicity, requested results, and permitted
methods. All configurations receive the same specifications for that task. The complete catalogue accompanies the per-task
results.
The repeated-task study, P1b, measures repeated runs on four tasks; the full-benchmark study, P2, compares all 50 tasks
(Table S1). P1b contains three independent runs for each task and configuration. E1 concerns elimination preorganization;
NB1 concerns multistep decarboxylation; HA1 concerns stereochemical ring opening; and IA1 concerns an electronic-
structure method limitation. P2 retains one run per task and configuration, so comparisons pair the four configurations on
the same task. The 48 repeated-task runs and the 200 full-benchmark runs are analyzed separately.

The configuration commits identify the code used to run the experiments. The main-text implementation, later evaluator
fixes, and publication-table reproduction have separate version records. The companion metadata file gives the archive
path of each configuration and runtime record. Its request-start and completion counts include auxiliary LLM calls and
cancelled P2b attempts; the benchmark includes only the 200 retained task runs.
Fixed geometric heuristics. Atom maps are ranked with fixed costs: 2 for each formed or broken bond, 1 for each bond-
order change, 4 for a hydrogen-count mismatch, 8 for charge or radical-electron mismatches, and 2 for a stereochemical
mismatch. Maps within Jmin + 2 are retained when reporting ambiguity. The branch-crowding descriptor uses decay
ρ = 0 .5, traversal through depth five, and a congestion flag when the four-branch total Baxis ≥ 9.0. These heuristics
rank maps and flag structures for inspection. Physical validation uses the quantum-chemical results. The imaginary-
mode participation ratio is compared with 0.5 as an advisory diagnostic; validation requires the first-order saddle and
IRC/endpoint calculations.
Conformational sampling. Default preorganization places molecular fragments using their topology, relaxes them with
guided MMFF94 optimization, and selects candidates by energy and RMSD. For multicomponent systems, it samples 32
relative orientations and retains up to eight guided placements. A separate conformer-search tool uses RDKit by default

S1.4 Allowed calculations and reference definitions
Easy, Normal, and Hard tasks permit xTB, PM7, and B3L YP-D3(BJ)/def2-SVP .[ 4–11] Impossible tasks are restricted
to xTB and PM7. Computational quantities and termination status are read from native ORCA, Gaussian, and MOPAC
outputs.[12–15] Each result retains its program, calculation level, species, and task conditions.
The reference answer (Gold) specifies the mechanistic species and elementary steps, stereochemical identities, applicable
numerical targets, and explicit negative targets. Numerical activation barriers use electronic energies at a consistent level
of theory:

These benchmark barriers use electronic energies alone. The energy reference is the verified stable minimum of the
corresponding species. Declared conformational connections within the same species can share that stable reference;
a conformational conversion itself uses its own starting conformer. Distinct stereochemical substrates and independent
channel contact complexes retain separate references. The IRC endpoint and the energy reference are recorded separately,
since they can be different conformers of the same species.
References follow the individual task definitions. NB1_E2 and NQ5_E2 are exempt from numerical references under
the specified proton-transfer policy. IB9 combines a numerical first-step reference of 5.65 kcal mol −1 with a negative
second-step target. Section S2 specifies the qualitative selectivity targets and numerical tolerances. Each reference record
separately states whether the task and Gold graph are available and whether the complete calculation chain has been
physically validated.
S1.5 Physical evidence associated with a mechanism
A mechanism graph represents species occurrences as nodes and elementary steps as edges. A species minimum requires
a converged optimization and zero imaginary frequencies. An accessible transition-state step requires a first-order saddle
with exactly one imaginary frequency associated with the intended reaction, plus IRC results connecting that saddle to the
declared endpoint species.[16, 17] Normal termination, geometry convergence, frequencies, and pathway connectivity are
checked separately.
Both IRC directions must start at the same transition state. The actual outer frame from each direction is then optimized
to a minimum with zero imaginary frequencies and the declared chemical identity and stereochemistry. This outer-frame–
optimization–frequency chain can establish the connection from a short IRC. The frames and links between calculations are
archived. Native calculation results establish the endpoint connection; geometric interval measurements aid interpretation.
For separated products, the required constituent minima are verified; an intact molecular complex is evaluated as a whole-
system species.
These requirements apply to the species and steps requested by the task. A negative conclusion marks the target as
physically inaccessible under the permitted methods and records the reason. A species-only negative question is evaluated
directly on that species claim.
S1.6 Offline organization and publication records
Formal evaluation represents the research completed by all four configurations in the same mechanism-graph format. Hu-
man organizers read each run’s conversations, tool records, reports, geometries, and native calculation outputs, then encode
the agent’s stated species, steps, mechanistic intent, and conclusions. They recover graph entries, repair file references,
and convert quantities already present in the run; each recovered field records its source. The evaluator searches that run’s
sandbox for native calculation results and applies the same physical criteria and scoring rules to every configuration. Orga-
nization is confined to that run’s existing calculations and stated conclusions; Gold supplies the evaluation reference. The
procedure and field sources allow the graph to be reconstructed from the original run materials.
The full-benchmark table contains 200 runs, all 600 Graph, Self-consistency, and Accuracy values, and their evaluation
sources. The weighted components reproduce the final totals to four decimal places; Section S7 specifies the references
and evaluator revision. The tables also record whether the run wrote a root mechanism graph and whether it was organized
offline. Readers can therefore inspect graph delivery separately from the score for the run’s research results.
The repeated-task study retains its historical results for all four configurations. The later offline organization updates
Standard separately; the other configurations in the 48-run study retain their historical scores. Analyses of this archive
identify which version supplies each result.

S2 Score components and scientific completion
S2.1 Composite score and reported outcomes
The composite score combines graph structure G, physical self-consistency SC, and accuracy A:
S = 0.1G + 0.3SC + 0.6A. (S3)
The three components are reported separately, alongside execution status, original graph delivery, and completion of the
requested steps. Complete scientific validation additionally requires every requested species and step to meet its physical
criteria.
S2.2 Graph structure and chemical correspondence
The graph component measures how well the delivered mechanism covers the reference species and steps. For comparison,
transition-state nodes are folded into their elementary-step edges. Species are matched by chemical identity; steps are
compared by their endpoints and atom-mapped bond changes. RDKit represents the species and NetworkX represents and
matches the graphs.[18, 19] Missing reference species or steps, incorrect chemical identities, and mismatched accessibility
declarations add edit costs. The graph component permits additional nodes and edges.
Graph comparison ignores stereochemistry for Easy and Normal tasks and retains it for Hard tasks. A species’ linked
native calculation results determine which evidence is assessed for it. Graph coverage receives its own score independently
of the binary self-consistency result.
S2.3 Graded physical self-consistency
Self-consistency is scored on the species and steps in the organized graph, independently of numerical agreement with Gold.
Table S4 lists the credit for each calculation stage of a transition-state step; a complete verified chain receives 1.0. The
evaluator searches the same run’s sandbox for the native files and links between calculations, recovering file associations
where needed. It assigns credit from these results using the common physical criteria.

For graphs containing reaction edges, SC is the mean of the delivered edge scores. An edge represented by its endpoints

The archived binary self-consistency indicator requires coverage of all physical checks created for the delivered species
and steps, including minimum characterization and transition-state/IRC associations. Its scope follows the delivered graph.

S2.5 Qualitative selectivity and property targets
For HA1, HA6, HB1, and HF1, Accuracy scores the qualitative choice of favored channel. The delivered mechanism
must identify one favored edge matching the reference channel or its product. Product identity is used when the agent’s
channel label differs from the reference label. Numerical barrier spreads are retained as calculations; the scored target is
the qualitative channel preference. HL1 scores its independently referenced channel barriers.
For species-property tasks, Accuracy compares the declared properties with their references. Numerical comparison
widths are 0.02 Å for bond lengths, 50 cm −1 for frequencies, and 2.0 kcal mol −1 for energy differences. State-ordering
text is compared after case and whitespace normalization. When several properties are requested, their scores are averaged.
S2.6 Impossible tasks and final scientific claims
Impossible tasks are scored on the agent’s final conclusion about the requested target. Correctly identifying that target
as physically inaccessible under the allowed methods earns negative-target credit, including after exploratory calculations.
Credit is lost for an incorrect claim that the target is accessible, a barrier or property presented as trustworthy for that
negative target, or omission of the required negative conclusion. Endpoint species associated with a negative step receive
the same treatment. A species-only negative target is evaluated directly on the species claim.
A result must answer the question about the requested electronic state, species, or pathway. The per-task tables and case
analyses identify that target alongside its score.
S2.7 Original delivery, organized evaluation, and score reproduction
Original delivery completeness records whether the run generated its mechanism graph during execution. Evaluation
uses the graph organized by the common offline procedure in Section S1. The publication table records each run’s final
component scores and field sources. All configurations use the same final references and scoring rules.
The reproduction procedure reads the evaluation records to rebuild the per-run table, summaries, and figure data. It
checks for 200 unique task/configuration records, 600 nonmissing component values, and agreement between the weighted
components and the 200 final totals. The maximum absolute difference from the published four-decimal composites is
4.9711 × 10−5. Rebuilding the publication tables uses the retained component records; independently reassessing the
calculations also requires the run files and evaluator revision.

S3 CloudraBench task catalogue
CloudraBench comprises 20 Easy, 10 Normal, 10 Hard, and 10 Impossible tasks. Tables S5–S8 list each task’s chemistry,
charge, multiplicity, conditions, and research question. The machine-readable catalogue contains task names and molecular
inputs; the full task definitions also contain atom mappings, prompts, reference graphs, and scoring settings.
Method set A permits xTB, PM7, and B3L YP-D3(BJ)/def2-SVP for Easy, Normal, and Hard tasks. Method set B
permits xTB and PM7 for Impossible tasks. Each answer is evaluated under its task’s permitted methods. Mechanism
tasks request the investigated species and elementary steps as a graph, electronic activation barriers for computed steps,
and the corresponding stationary-point and pathway calculations. Stereochemical tasks also require assigning identities
from the computed geometries. The tables list each task’s specific question in addition to these shared requirements.
For Impossible tasks, the listed quantity or process is the question posed to the agent. A supported conclusion that the
target is physically inaccessible under the allowed methods is a valid result. Exploratory values can be labelled as such,
and species-property questions are evaluated directly on the species claims.

S4.10 Discussion of the supplementary comparisons
Tool and task graphs organize computational execution. Cloudra’s Delivery DAG constrains the agents’ submitted mecha-
nism representation through species-occurrence nodes and elementary-step edges that carry molecular geometries, bonding
patterns, and reaction connectivity. Cheminformatics algorithms establish and compare identities and atom correspon-
dences; frequency and IRC/endpoint calculations determine the supported stationary points and connections. The Normal
and Hard cases show why these assignments matter: HA8 requires correcting the reactant energy reference, and NU6
requires recognizing that a search has returned to a different saddle region. Agents use the represented species and steps to
choose new geometries, continue a path calculation, or revise the mechanism, complementing external planning and tool
feedback.[20–22]
P2 retains one run per task and configuration. Its task-cluster bootstrap intervals measure variation across the sampled
tasks. P1b supplies three repeats on each of four tasks under each configuration; these 48 runs provide repeat measurements
on those four tasks within the 50-task P2 study. The P2 table includes all 200 runs and their three components. Some
Hard tasks score qualitative channel identity, so the gain includes pathway identification and completion of the supporting
calculations as well as numerical barriers. Repeating the full task set would measure run-to-run variation and how often
the agents select each route.
The Impossible rubric concerns targets judged physically inaccessible under the specified methods; self-consistency
credit records the supported negative conclusion. A positive step requires its own TS–IRC–endpoint chain. IA5 and IC3
require matching the requested pathway and electronic state before scoring the answer. Brief’s crossed outcomes suggest
task-dependent effects of diagnostic content; the causal effect of diagnostic length remains unmeasured. In NU6, the
matching energy difference prompts a check of the assigned step. The native geometries and paths determine whether two
calculations found the same saddle.
Timing comparisons use batch elapsed time for P1b and accumulated job-hours for P2. Separate measurements of
queueing, calculation, agent-active time, and end-to-end P2 latency remain future work.
Cloudra’s default preorganization samples 32 rigid relative placements, relaxes them with MMFF94, and selects candi-
dates by energy and clustering. It samples local arrangements; global-minimum coverage requires a separate assessment.

CREST is an optional backend, and its coverage across the 200 runs remains to be established. Flexible systems may need
broader sampling and more quantum-chemical calculations. Further work should measure which conformers are found
and how calculations can be allocated among competing candidates.
The benchmark scores electronic energy differences alone; zero-point, thermal/entropic, standard-state, and solvation
free-energy contributions remain outside this comparison. NI5 specifies weakly acidic aqueous solution, and NU5 specifies
dichloromethane at high concentration; both are scored against the prescribed electronic-energy references. Solution-phase
free-energy barriers and solvent sensitivity, including the magnitude and direction of solvent effects, remain unassessed.
All workflow comparisons used the same atom-mapping coeﬀicients and ambiguity window, and the same branch-
crowding decay, depth, and congestion settings. Their individual effects remain unmeasured. The imaginary-mode align-
ment ratio of 0.5 is advisory; physical validation uses the stationary-point and IRC/endpoint calculations. All P2 configura-
tions used DeepSeek-v4.1-flash (1017), the API alias deepseek-v4-flash, and the recorded request settings. Additional
backbones would test whether the workflow improvements extend to other models.
The Easy cases show two different problems. In F4, the final graphs assign different reactant identities despite calcula-
tions supporting essentially the same pathway. In G2, validation feedback prompts deletion of structured numerical fields
while the values remain in prose. Recording validation status separately would let the agent state a quantity’s scientific
qualification while retaining the quantity and its source. The 2 November 2026 target-correspondence overlay is the of-
ficial Accuracy postprocess for these Impossible pathway and electronic-state assignments; Graph, Self-consistency, and
the unchanged runs remain those of the organized publication records.

S5.2 Chemical identity under equivalent representations and answer reversal
Sixteen molecular pairs were derived from four task systems. They include pairs representing the same molecule, different
connectivities with the same formula, changes in connectivity and formal-charge location, different double-bond stereo-
chemistry, and protonation changes. Each pair was presented in its original notation and an equivalent rewriting, with both
answer orders. In the forward order, A means the same chemical identity and B means different identities; in the swapped
order the meanings exchange. The questions instruct the model to compare connectivity, bond orders, formal charges, and
specified stereochemistry, allowing differences in traversal order, ring digits, and disconnected-component order.
Across the resulting 64 judgments, 58 answers were correct. For the same pair and answer order, equivalent rewriting
changed the chemical judgment in four of 32 comparisons. For the same pair and representation, reversing the options
changed the judgment in six of 32 comparisons. All six selected A in both option orders. In the same-formula pair
CC1CC=C1 and C=C1CCC1, the double bond lies within and outside the ring, respectively. The model answered A under all
four representation/order conditions, even though A changed from “same” to “different” when the options were reversed.
Identical strings test whether the model recognizes a representation as matching itself. Equivalent rewritings test recog-
nition of the same molecule in another notation. Different-identity controls test whether it detects changed connectivity
or stereochemistry despite a shared molecular formula. All strings and expected judgments are saved with the diagnostic
data.

S5.5 Single-token transfer of a reported numerical fact
The activation experiment uses the archived local quantized model for a reported-distance comparison.[24] We changed the
first reported distance from 2.029 to 1.029 Å. The second distance remains 1.248 Å. This reverses the correct comparison.
The clean and edited prompts each contain 124 tokens; their token IDs differ only at global position 53, corresponding
to the initial digit of the changed measurement. The original-fact answer is B in the forward option order and A in the
reversed order.
For each option order, the residual-stream state at position 53 is captured from the original prompt and transferred
into the edited prompt at zero-based layers 7, 15, 31, and 47. The four layers are fixed in the experiment manifest. The
readout is the full-vocabulary softmax probability mass assigned to the original-fact answer, summing its bare-letter and
leading-space spellings. Table S30 preserves the clean, edited, and transferred-state values.

S5.7 From a detected gap to the next research action
The HA1 and NB1 trajectories show what the agents did after receiving diagnostics. In a Brief HA1 run, the agent repeat-
edly changed the source-minimum reference after compact feedback, while the IRC endpoint link remained unresolved. In
a Guided NB1 run, the frequency calculation found zero imaginary modes and returned a normal-mode diagnostic. The
Coordinator requested changes to the transition-state guess and optimization constraints; the next calculation used those
changes. The saved sequences connect each diagnostic to the next instruction and calculation request.[ 21]
In IA1, the delivery report has complete=false, a pending bidirectional short-IRC verification, and an empty formal-
waiver list. After earlier positive comments about intermediate optimization, the Coordinator requests to stop with the
study marked complete. The completion check returns the pending IRC requirement to the model. The next stop request
marks the study partial.
The local IA1 test asks three questions: whether the latest report declares completion, whether a formal short-IRC
waiver exists, and whether the missing calculation remains required. Each question is presented with the report alone or a
quoted 12-message history, in both answer orders. All 12 answers match the recorded report fields and waiver list; all six
option-reversed pairs preserve the same judgment.
S5.8 Discussion of the diagnostic scope
The tests examine whether a model recognizes a molecule in different notations, compares distances, requests measure-
ments for the specified atoms, uses a supplied numerical fact, detects changed calculation links, and identifies pending
IRC verification. They describe the recorded local model and the tested inputs. The native follow-up uses cases selected
after first-stage errors and retains all their variants; its counts apply to that selected set. The common output limit bounds
response length; actual computation depends on prompt conditioning and the tokens generated in each thinking mode.
Activation replacement measures the effect of a changed state on the quantized Qwen model’s distance-comparison
answer. Establishing the original DeepSeek runs’ internal mechanism or the chemical validity of their results requires
separate evidence. In the E1 trajectory, Supervisor/workspace input intervenes between the measurements and the agent’s
use of candidate B. The separate local tests vary the supplied target measurements to examine their effect on the choice.
The completed IA1 tests use the report-only and 12-message inputs. A separate request with the full 306-message
history contained 242,803 counted input tokens in a 262,144-token context. It reached the 3,600-s HTTP waiting limit
while awaiting an answer, leaving the saved response empty. Of six planned full-history inputs, the first was attempted and
the other five remain unattempted. This incomplete request is recorded separately from the 12 completed short-context
judgments.
