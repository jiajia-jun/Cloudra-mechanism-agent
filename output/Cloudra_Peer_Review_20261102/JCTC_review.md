# Cloudra 独立模拟同行审稿：Journal of Chemical Theory and Computation

审稿版本：2026 年 11 月 2 日桌面提交包中的英文正文（24 页）及 SI（32 页）。正文题为 *Cloudra: Geometric Reasoning and Scientific Validation for Autonomous Reaction Mechanism Exploration*。以下正文页码为 PDF 印刷页码，SI 页码记为 S1–S32。本轮通读正文，并阅读 SI 的实验协议、评分、任务目录、结果、行为诊断和复现说明；另外查看 2 November target-correspondence 配套 README 和全 200 图审计摘要。没有修改稿件、运行新计算或提交材料，也没有逐个复算 200 次运行的全部原生日志。

**最终建议：Minor revision（小修后接收），并非直接接收。**

这是一篇有实际计算支撑的科学工作流方法论文，贡献是把 LLM 对物种、步骤、几何和能量的判断接到可以检查的计算对象上，并用同模型对照评估这一整套设计。它没有提出新的电子结构近似，也没有展示新的反应化学发现；这两点都不能单独构成拒稿理由。当前结果足以支持“在该任务集、该模型和所用研究预算下，Guided 改善归档整理后机制计算结果的综合评价”这一限定主张。接收前需要修正近邻工作的定位、负目标的物理含义及公开可用性的事实陈述；我不要求新增量子化学计算、完整 50 题重复或另一套大规模 benchmark。

## 1. 期刊适配与实际同刊尺度

## 2. 本文的实质贡献与可信部分

我认可的贡献可以独立于标题中的“geometric reasoning”概括为：让研究者提出的反应步骤和计算真正找到的驻点、构象及连接关系保持一致，并把这种一致性作为 Agent 的下一步行动依据。几何测量、旋转、MCS、Kabsch 和 IDPP 多为既有算法，本文的方法创新主要来自它们在这个研究循环中的组合与约束关系。正文第 3–7 页已给出足够具体的数学和实现定义，而非只画一张 Agent 方框图。

同模型比较有实质信息。P2 是 50 题、4 工作流、200 次保留运行，Guided/Standard 分别为 0.8050/0.5836；Hard 为 0.9577/0.6888（正文第 8–11 页，图 7–8；SI S12–S13，表 S12–S14）。Record 保留可用工具，Guided 相对 Record 的增益因而支持强制验证与指导这一整包设计的价值。它不是某个几何公式的独立因果实验，但论文也不需要把它包装成这种实验才有价值。

最有说服力的化学案例是：NI1 把两个 saddle、同源短 IRC 和端点 Opt/Freq 连成两步机制，同时区分第二步实际 IRC 端点构象与更低能构象，且明确没有计算两构象之间的转化（正文第 8–9 页，图 6；SI S10–S11，表 S9）；HA8 区分稳定参考与反应构象；NU6 区分相同能量差与不同路径归属（正文第 13、15、21 页，图 12；SI S14–S15）。这些案例不等于发现新反应，但它们展示了可推广的计算化学信息管理和推理问题。

作者还保留 G2 的负面案例：验证反馈促使模型删除已有计算支撑的数值字段，最终 Accuracy 降为零（正文第 13、21 页；SI S15–S16）。这是有价值的系统失效分析，说明强制验证也可能损害结果交付。保留该例比只展示成功轨迹更能支撑方法论文的可信性。

物理解释方面，正文和 SI 已明确电子能差不是溶液自由能或实验选择性；NI5/NU5 的介质问题也有具体说明（正文第 22 页，SI S17）。因此我没有把“缺少所有体系的溶剂/自由能敏感性研究”列为当前接收的必要条件。NI1 的短 IRC 到达点数上限，但后续实际终帧的优化和频率才承担端点证据；不能仅因为 IRC 短就否定这个链条，也不能只凭一条虚频就接受所有步骤。

## 3. 接收前必须解决的三项意见

### 意见 1：应当重写最接近工作的对比，而不必另造一项研究

**是否阻止当前原样接收：是；属于小修。能否用现有资料修复：能，无须新计算。**

正文第 1–2 页、贡献段与图 1–3 花了较多篇幅统计 85 个系统，但“做过 T/E/O/F/R/D”不能回答 Cloudra 与最接近方法究竟有什么差别。ARplorer 已具备 LLM 辅助、多步探索、手性和 TS/IRC 的组合；现稿对 ARCHE 的介绍也主要落在片段编辑、映射和 TS 几何准备，容易缩窄其自主提出、修正和验证机理的实际范围。Chemoton 原文也已讨论 IRC 局部端点与最低能构象参考的区别。

请在引言和讨论增加一段直接对比，并相应调整能力矩阵的解释：哪些工作在规则整理阶段使用 LLM，哪些让 LLM 持续作研究决策；机制对象如何绑定到实际计算证据；如何评价算到的路径是否回答原问题。把原创性明确放在“持续研究循环中的对象绑定和证据反馈，以及相应实证评价”上。不要声称首次实现 LLM 辅助机制探索或首次使用化学对象/IRC，当前文本也无需为了突出新意贬低既有软件。

**对结论的影响：**改变贡献的定位，不必改变 P2 的数值或主比较。若作者坚持比“该系统工作流”更强的首创性或普适优越性，现有实验就不足；这是可避免的过强主张，而不是当前稿必须承担的新实验。

### 意见 2：负目标应明确为方法可信性问题，不能用“物理不存在”统称

**是否阻止当前原样接收：是；按现有证据属于可通过解释和溯源完成的小修。能否用现有资料修复：原则上能，需把已有逐题依据集中呈现；我不擅自制定新的科学阈值。**

正文第 21 页和 SI S5、S17 使用“physically nonexistent under the task’s permitted methods”概括 Impossible，而同一研究又把“目标本身不存在”和“xTB/PM7 不足以给出可信结果”放在负结论范围内。这两种说法对物理化学读者含义不同。例如 IA1 的正方形 cyclobutadiene automerization saddle 是实际物理研究对象，其多组态特征可使特定方法失效；不能据此说目标本身不存在。相关原始研究 **Reference Energies for Cyclobutadiene: Automerization and Excited States**, *J. Phys. Chem. A* **2022**, 126, 4664–4679，DOI **10.1021/acs.jpca.2c02480**，明确研究这一对象及其多组态困难。[出版社记录](https://doi.org/10.1021/acs.jpca.2c02480)

配套 task definitions 的提示已经允许“无法达到可信精度”时给负结论，因此主要问题是论文描述没有把这一含义讲得同样清楚，而不是我发现题目要求一定算出不存在的东西。请用一个简短的逐题表，说明负目标针对哪个物种、电子态或路径；拒绝的依据是没有符合任务定义的一阶 saddle、指定方法不具备所需电子结构能力，还是其他已有依据；列出现有原始文献或参考计算位置。避免把某次优化失败当成不存在的证明，也避免把对近似能量不信任扩展成所有定性物理量都不能判断。

还应在正文第 15–16 页图 13 与 SI S15 附近再次清楚说明：Impossible 的 SC=1 可以来自对一个负结论的相应记账，并不是正向 TS–IRC–端点闭合。稿件已指出 SC=1、Accuracy=0 的组合，这一点应保留。

**对结论的影响：**主要修正“负结论”代表的科学内容，不应无理由改分。若作者核对后发现某题负 Gold 实际缺乏现有依据，则应明确该题不能支持方法边界判断，单独报告其结果，并说明主比较是否受影响；不能用一条笼统说明替代这种核对。本轮没有证据证明整组负 Gold 全部错误，也不据此要求统一重算。

### 意见 3：公开软件与复现材料的可用性陈述必须符合当前事实

**是否阻止以现稿措辞正式发表：是；属于发布与事实修正。能否用现有资料修复：能，不涉及新的科学工作。**

正文第 22 页及 SI S29–S30 多处称源代码 publicly available。本轮并行编辑核查获得的 GitHub 仓库元数据仍为 private。请使实际可访问状态与论文陈述一致，或者准确说明获得代码和冻结版本的方式；不应由审稿过程擅自改变仓库权限。公开源码、公开数据以及复现表格是不同事项，应分别给出真实状态。

另外，SI S6、S29 已正确区别“重建保留组件表”和“从原生日志独立重评”。建议让数据可用性段直接指向这一差别：读者用什么材料复现统计和图，用什么材料才能检查驻点/IRC 等科学证据。JCTC 的数据政策要求提交数据可用性声明，并鼓励公开底层数据；不能据此虚构所有数据必须无条件开放的官方硬性要求。[JCTC Research Data Policy](https://researcher-resources.acs.org/publish/author_guidelines?coden=jctcce)

**对结论的影响：**不改变科学结果，但当前公开性陈述需要真实，复现入口需要可执行或可获得。

## 4. 重要限制，但不是接收前的新实验清单

**完整任务科学完成率：非当前主张的接收阻塞。** 正文第 11 页及 SI S5、S11 已明确，24/40 与 7/40 是 delivered objects 的满分 SC 计数，而非完整任务科学验收率；摘要也写成 self-consistency component 而没有把它们称为成功率。统一检查所有 requested objects 是很有用的后续分析，但不能把我更喜欢的终点临时加为接收条件。建议在图 9 标题附近保持这一范围限定即可。高综合分和高 SC 均不保证整题科学完成；现稿已说清这一点。

**算力：影响解释，不使比较无效。** 正文第 12–13 页与 SI S13–S14 披露，15 个共同深挖任务上 Guided 比 Standard 使用更多累计作业时间，而本文没有声称 Guided 总体节省算力。额外计算既可能是执行验证的成本，也可能是效果改善的一部分。当前比较证明在所执行的研究过程下整套系统得分更好；预算匹配研究能回答另一问题，但不是这篇限定主张必需的补实验。

**消融与因果：当前解释基本适当。** Record 同工具而取消强制验证，足以支持这一整包工作流作用。它不能证明 MCS、旋转、crowding 或某个阈值分别贡献多少；正文第 22 页和 SI S17–S18 已把这些单项归因为未来问题。Brief 对照的总体区间跨零，Impossible 的反向表现也被保留；不应强求所有任务上 detailed diagnostics 均胜出。

**随机性：范围已限定。** P2 每题每臂一次，task bootstrap 衡量本任务组合的差异，而不是同一任务重复运行方差；正文第 21 页和 SI S4–S5 已说明。P1b 48 次运行仅覆盖四题，不能当作整个 P2 的三重复。不过单次跨任务对照本身仍是有效的描述性证据。新的模型和完整重复研究属于推广验证，而不是当前主张必须先完成的工作。

**Accuracy 不是无上限的化学精度。** SI S6 的数值偏差罚分封顶使部分很不接近参考的已支持数值仍可有较高 Accuracy。作者已经另外给出无封顶 kcal/mol 误差（正文第 12 页表 1；SI S11 表 S10–S11），并披露其交集覆盖和排序变化。建议在正文使用该组件名称时始终保留“任务定义的”含义；不能将 Hard 0.958 读作 95.8% 的数值精度。没有必要为了本轮审稿擅改权重、阈值或冻结分数。

**离线整理：评价对象已说明。** 正文第 8、10–11 页和 SI S4 说明从原运行对话、文件及结论恢复图，不添加新计算。此时结果应解释为归档研究成果的统一评价，不能当作完全无人整理的最终文件交付率。稿件已单独报告 43/50 与 50/50 原始根图数。对照臂也能获得其已做研究的信用，不能因为有人整理就一概否定比较。

**2 November 匹配修正：没有依据指控选择性只审 12 次。** 配套 README 和 matching_audit_summary.json 明确，全 200 个最终图均检查了候选/路径/电子态匹配，12 次是受影响三个任务的四臂重放，五个 Accuracy 改变。这不是把五次有利结果挑出来替换；Graph/SC 和原始计算没有随意统一重做。该结构匹配审计也不等于全 200 次原生科学证据重新验收，二者应继续分开。

**局部 Qwen 诊断：支持设计动机，不证明 DeepSeek 内部机制。** 正文第 15–20 页及 SI S23–S26 的选择题、测距与 activation replacement 不是端到端基准的独立重复。作者已经承认换模型、量化、选例及 option order 限制。若压缩篇幅，我建议把单 token 激活实验移入 SI，让正文更多突出 NI1/HA8/NU6 的化学对象，但这属于呈现选择，不是必须新做跨模型解释实验。

## 5. 最终判断及与 arXiv 公开准备度的区别

这篇稿件目前最强的结论是一项可推广的科学工作流方法：在同一 LLM 和本任务集上，把计算结果的身份与归属接回研究决策，可提高证据完成度和任务定义的答案质量。它不是新的全局 PES 探索算法，也没有用 0.805 证明一个统一的机制科学验收率。与 Aitomia 相比，这一对象与证据问题足够具体；与 Chemoton 和 ReNeGate 相比，其新增问题是 LLM 的研究决策与计算事实如何对齐。它因而可以符合 JCTC 的方法/软件定位，虽不是我会评价为突破性理论进展的稿件。

我原先考虑把完整任务验收、新算力匹配和单项几何消融视为大修要求；对照当前全文的明确范围后，这些要求超出了实际主张，因此不保留。小修建议的依据是现有实证已经支持限定主张，而不是对缺失科学证据作乐观假定。上述三项接收前修正均可以用已有资料、准确定位和真实可访问性完成。

arXiv 预印本公开与 JCTC 录用是两回事。当前稿可以作为说明适用范围与未完成事项的研究预印本，不需要先完成上述后续实验才能公开；但公开软件/材料的事实措辞应先修正，且作者与材料公开授权须由作者自行落实。本审稿建议不构成上传、改权限或替全体作者确认公开的授权。
