Cloudra 当前稿用词与句式审查
审查版本：master 0974334b，英文正文、中文正文及英文 SI 的活跃 TeX 源。
本轮只定位和给出修改建议，未修改论文、计算记录或评分。

判断

“口径”“账本”确实在稿中。anchor、anchored、anchoring、achcor 在当前正文和 SI 未见。最需要处理的并非几个孤立词，而是 record、retain、archive、support、correspondence 等在同一句中反复出现，将具体计算和检查动作写成抽象名词。

优先修改

1. 中文方法，paper/overleaf/Cloudra_ZH/sections/02_methods.tex:18
原文：中央计算账本（ComputeDB）记录每个作业的状态。
建议：计算数据库（ComputeDB）记录每个作业的状态。
英文对应 paper/overleaf/Cloudra_EN/sections/02_methods.tex:18
原文：The central calculation ledger (ComputeDB) records each job’s state.
建议：The calculation database (ComputeDB) stores each job’s status.

2. 中文方法标题，paper/overleaf/Cloudra_ZH/sections/02_methods.tex:260
原文：参考答案与评价口径
建议：参考答案与评价方法

3. 中文摘要，paper/overleaf/Cloudra_ZH/sections/00_abstract.tex:3；引言 01_introduction.tex:37
原文：物种节点承载分子几何……基元步骤的边承载过渡态……
建议：物种节点记录分子几何……基元步骤边记录过渡态……
“承载”在这里没有增加含义，用“记录”更直接。不要因此机械改掉其它语境中准确的“记录”。

4. 中英图注，Cloudra_EN/sections/03_figures.tex:23、Cloudra_ZH/sections/03_figures.tex:23
原文：Components are aligned with the final organized totals using each run’s recorded research materials and score records.
中文：各运行分量由其自身研究材料与评分记录对齐至最终整理总分。
问题：“对齐至总分”可能让读者误解为倒推分量配总分。
建议：The component values come from each run’s final evaluation; their weighted sum gives the published composite score to the reported precision.
中文：各次运行的分量来自该次运行的最终评估；按既定权重求和后，与发表的综合分在所报精度内一致。

5. 英文方法，paper/overleaf/Cloudra_EN/sections/02_methods.tex:272
原文：Frozen configurations and actual request/completion records agree on this model identifier.
建议：The saved configurations and the API request and completion logs all specify this model identifier.
中文对应 02_methods.tex:274：“冻结配置”改为“保存的实验配置”。这里保存的是配置与调用日志，不必使用“冻结”比喻。

6. 英文方法，paper/overleaf/Cloudra_EN/sections/02_methods.tex:268
原文：Reference-evidence completeness, special treatment, and qualifications awaiting resolution are documented per task.
建议：For each task, we list the available reference calculations, any task-specific exceptions, and unresolved checks.
后句保留参考图可用不等于各物种和步骤均完成验证的原有限定。

7. 英文方法，paper/overleaf/Cloudra_EN/sections/02_methods.tex:276
原文：run versions, budgets, stopping reasons, and artifact provenance are retained in the archive.
建议：The archive stores each run’s code version, budget and stopping reason, together with the source files for its calculations.
问题：artifact provenance 应按实际所指写成具体文件或结果来源，避免宽泛术语。

8. 英文结果，paper/overleaf/Cloudra_EN/sections/03_results.tex:90
原文：Cloudra records the corresponding artifact references for each species, step, and calculation attempt.
建议：Cloudra links each species, step and calculation attempt to its calculation results, showing which saddle, IRC and endpoint calculations belong together.

9. 英文方法，paper/overleaf/Cloudra_EN/sections/02_methods.tex:255
原文：TS frequencies, bidirectional IRCs, outer-frame provenance, and endpoint optimization/frequency calculations form the evidence chain.
建议：For each accessible reaction step requiring verification, we use TS frequency analysis, bidirectional IRCs, and endpoint optimization and frequency analysis. We also check that each endpoint optimization starts from the actual terminal IRC frame.
问题：outer-frame provenance 将必须核实的起始几何关系压成了一个抽象名词。

10. 英文结果，paper/overleaf/Cloudra_EN/sections/03_benchmark_results.tex:26
原文：Channel and electronic-state correspondence is applied uniformly before Accuracy.
建议：Before calculating Accuracy, we match each reported reaction channel and electronic state to the target specified in the task.

11. 英文引言，paper/overleaf/Cloudra_EN/sections/01_introduction.tex:28
原文：Following intelligent restraint, Cloudra assigns coordinate calculations to deterministic routines.
建议：Cloudra uses deterministic routines to calculate and modify molecular coordinates.
“intelligent restraint / 智能克制”若作为作者提出的概念保留，应先给出明确含义；本句可以直接说明程序执行什么，不依靠概念名代替解释。

12. SI 标题，paper/overleaf/Cloudra_SI/sections/02_scoring.tex:1、4
原文：Layered scoring and scientific completion；Composite and reporting layers
建议：Score components and scientific completion；Composite score and reported outcomes
问题：连续使用 layers，实际内容是评分分量及报告结果。

13. SI，paper/overleaf/Cloudra_SI/sections/02_scoring.tex:5
原文：For a formally organized run, the reported composite combines…
建议：The composite score combines…
整理程序已在前文说明，不必在公式前再加资格式修饰。

14. SI 评分表，paper/overleaf/Cloudra_SI/sections/02_scoring.tex:31
原文：Native outer-frame--optimization--frequency lineage to both declared endpoint minima
建议：Calculation logs linking each IRC terminal frame to an optimized, frequency-verified minimum of the declared species
问题：lineage 与四段连写不利于直接理解实际检查。应保留实际末帧、优化与频率计算的关系，不能只删限定词。

15. SI，paper/overleaf/Cloudra_SI/sections/04_detailed_results.tex:145
原文：Recorded ledger durations are summed across quantum-chemical jobs.
建议：Job-hours sum the durations recorded for individual quantum-chemical jobs.

16. SI，paper/overleaf/Cloudra_SI/sections/05_behavioral_evidence.tex:162
原文：All selected base cases retain their complete frozen variants; budget-truncated inputs remain in the denominators.
建议：All saved input variants are included for each selected case; responses truncated by the output limit remain in the denominators.
问题：base cases、retain、complete frozen variants 连用，模糊了实际纳入哪些输入、哪些响应达到上限。

17. SI，paper/overleaf/Cloudra_SI/sections/archived_barrier_errors.tex:6
原文：156 observations were reproduced… using… consistent methods and continuum settings, and agreement with the original comparison note…
建议：For 156 positive-target observations, barriers recalculated from the selected, normally terminated TS and reference logs agreed with the original comparison notes to the recorded precision of 0.001 kcal/mol. The TS and reference calculations used consistent methods and continuum settings.
问题：句法把 agreement 当作 using 后的并列工具，且未直接说明复核的是能垒。

18. SI，同文件第6行
原文：outside this uniformly sourced original-note cohort
建议：not included in this set, which was assembled from the original comparison notes

19. SI，同文件第31行
原文：Retained selected Gold input files corroborate… for a further-defined common subset…
建议：For a common subset of 19 edges from 17 tasks, the saved Gold input files confirm that the method and continuum setting match those of the run calculations.
保留后句关于输入文件核对不能代替完整原生日志与端点证据的限定。

20. SI，同文件第50行
原文：The archive also permits an explicit inventory of physical-record availability across the 160 positive runs.
建议：We checked which physical-validation records were available for the 160 positive runs.

21. SI，同文件第50行
原文：A common rate of fully supported requested mechanisms therefore requires a uniform offline review of requested-object coverage and the existing native physical conditions…
建议：Estimating the fraction of runs that fully support the requested mechanism still requires an offline review of every requested species and step in each final graph against the existing physical criteria and calculation evidence. Additional exploratory branches must be assessed separately.
必须保留 still requires，不得把尚未完成的审查改写为已完成。

不应机械删除的用词

Kabsch alignment、atom correspondence、imaginary-mode alignment 有具体技术定义。native 在区分量化软件实际输出与模型声明时有必要。中文 NU6 的“闭环”指化学成环，不能按工作流套话删除。Delivery DAG 是系统名称，保留名称不等于其它句子都必须使用“交付”作动词。

技能参考

参考 academic-editing 的实质规则：保留作者原意与技术术语，删除冗词和含糊表达，优先让句子直接说明执行了什么动作。本次没有使用 AI 检测分数或将词汇命中当作作者身份判断。
