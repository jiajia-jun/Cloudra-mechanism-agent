核查日期：2026 年 11 月 1 日。

本文件核对三个运行中“题目要求的对象，究竟对应原图中的哪一个对象”：IA5 区分反应通道，IC3 区分电子态，L2 区分能垒起算构象。核查依据是原运行的最终机理图、研究记录、原生日志、现有任务定义及正式发表评分表。以下是**保持原有规则、Graph 和 Self-consistency 不变，只改变目标对应关系的条件算数**；没有更改正式评分、交付图、Gold、匹配程序或量化计算。

**S = 0.1 × Graph + 0.3 × Self-consistency + 0.6 × Accuracy。**

| 原运行 | 要区分的化学对象 | 已发表 Accuracy | 条件 Accuracy | 已发表综合分 | 条件综合分 | 保持不变的 Graph / SC |

IA5 和 IC3 的条件满分来自现有负目标规则：对题目所要求的对象明确拒绝可信数值、并按原规则声明不可达，可以获得负结论的 Accuracy 信用。它们不是新增 TS–IRC 计算后的满分。L2 的条件 Accuracy 仍低于 1，因为稳定参照能垒与 Gold 尚有约 1.495 kcal/mol 的差别。

## 一、Record / IA5：题目问对旋，原运行也明确拒绝了对旋

### 题目和原运行分别说了什么

IA5 问的是环丁烯的**热对旋开环**。现有 Gold 将这一目标路径列为不可达，不给数值能垒。

Record 最终图同时保留两条通道：

| 原图对象 | 实际含义 | 原图的最终声明 |
|---|---|---|
| `e_dis`，经 `TS_dis` | 题目要求的 disrotatory，对旋通道 | 边与相应 TS 均声明 `accessible=false`，没有数值能垒 |
| `e_con`，经 `TS_con` | 另行研究的 conrotatory，同旋通道 | 声明能垒 33.57 kcal/mol，标为所支持的替代通道 |

原记录把约 42.8 kcal/mol 的对称脊顶写作探索性结果，说明其有两个虚频；没有把它当作已验证的一阶对旋过渡态或可信对旋能垒。最终 `PROCESS.md` 再次明确：所请求的对旋路径不声明能垒，33.57 属于同旋路径。

### 为什么仍得到 Accuracy 0

两条通道连接相同的环丁烯和丁二烯，原图的键变化列表也相同。保存的核查结果显示，当前对应关系选中了有正向计算声明的同旋通道，随后把这条正向声明拿去回答“对旋目标是否被正确拒绝”。因此现有负目标规则给 0。

这里必须保留通道差别：计算了同旋路径，并不等于宣称题目要求的对旋路径可达。

### 条件分数

若题目中的对旋目标对应原图的 `e_dis`，沿用已有负目标规则，其明确拒绝和空缺能垒得到 Accuracy 1。保持已发表 Graph = 1、SC = 1：

```text
原综合分   = 0.1×1 + 0.3×1 + 0.6×0 = 0.4
条件综合分 = 0.1×1 + 0.3×1 + 0.6×1 = 1.0
单次运行变化 = +0.6
```

本计算沿用 IA5 现有负目标判定，不把“几次搜索未找到”扩展成关于整个势能面的新证明。

## 二、Brief-errors / IC3：闭壳层支线不是所请求的最低单重态

### 原图保留了三个不同的电子态对象

IC3 要求苯基氮烯的最低单重态及其与三重态的能隙。原运行最终图明确区分：

| 原图对象 | 电子态身份 | 最终用途 |
|---|---|---|
| `T1_3A2` | 三重态参照 | 已表征的参照态 |
| `S1_1A1`，通过 `e1_T1_to_S1` 连接 | 闭壳层单重态；原图明确写为“不是最低单重态” | 已计算的另一条电子态支线 |
| `S2_1A2`，通过 `e2_T1_to_S2` 连接 | 所请求的最低开壳层单重态 | 节点与边均声明 `accessible=false`，没有该态能量或目标能隙 |

图中所记 PM7 的 +45.9 和 GFN2-xTB 的 −1.7 kcal/mol 均明确限定为闭壳层支线相对三重态的探索值，并明确排除作为题目所问的最低单重态—三重态能隙。目标能隙字段保存的是拒绝给出该数值的说明，而非数值答案。

原记录将该开壳层态的限制具体写为**当时允许的输入路径限制**，不是声称这一电子态在分子中不存在。最终 `PROCESS.md` 将交付标为 partial，并重申没有任何数字被声明为目标能隙。

### 为什么得到 Accuracy 0

两个单重态节点使用相同分子连接图，两个态变化的键变化列表均为空。保存的核查结果显示，对应关系选中的是已计算的闭壳层支线 `e1_T1_to_S1`，随后用它判断是否正确拒绝最低开壳层单重态目标。

这丢失的是电子态身份：一个分子的相同 SMILES 可以对应不同电子态，而已表征闭壳层单重态不等于宣称已经算出最低开壳层单重态。

### 条件分数和采用的基线

若目标对应原图已明确拒绝的 `S2_1A2` / `e2_T1_to_S2`，沿用现有负目标规则，Accuracy 为 1。保持**已发表** Graph = 1、SC = 1：综合分从 0.4 条件变化为 1.0，增量 +0.6。

这里从已发表 0.4 起算。FULL 原始数据库曾因日志引用无法绑定记录 Graph 约 0.3333、SC 0.5、综合分 −1；后来的证据引用整理恢复了 Graph 和 SC，而 Accuracy 仍为 0。两种记录属于不同整理阶段，不能把原始 −1 与当前发表的 0.4 混作本次条件比较的起点。已有核查确认，引用整理改变的是日志路径表达，未改变上述电子态、能量和最终科学声明。

## 三、Standard / L2：两种能垒都已交付，评分选中了局部参照

### 原图和原生日志的实际能量

Standard 已交付稳定 tZt 参照、局部反应构象 cZc，以及同一个环化过渡态。下表前三项电子能同时出现在最终图和相应 Gaussian 原生日志，末项来自 IRC 末帧的后续频率日志及原研究报告。单位为 Hartree；四份日志均正常终止。

| 化学对象 | 电子能 / Ha | 频率事实 | 原生日志，路径相对本次 L2 沙箱 |
|---|---:|---|---|
| 稳定 tZt 参照，`RC` | −233.248473327 | 0 虚频 | `hexatriene_tZt_optfreq.log` |
| 局部反应构象 cZc，`RC_cZc` | −233.233672606 | 0 虚频 | `rc_czc_hexatriene_optfreq.log` |
| 环化过渡态，`TS1` | −233.203414229 | 1 虚频，−566.245 cm⁻¹ | `ts/ts_0001/jobs/declaration_0001/frequency/frequency.log` |
| 原 IRC 反应物侧末帧再优化所得结构 | −233.232689560 | 1 虚频，−50.8323 cm⁻¹ | `ts/ts_0001/jobs/declaration_0001/reactant_frequency/reactant_frequency.log` |

原图同时写了两条能垒记录，均经同一个 `TS1`：

- `e1`：从局部 cZc 反应构象到产物，声明 18.99 kcal/mol。
- `e2`：从稳定 tZt 参照起算，声明 28.28 kcal/mol；原图注释明确说明是同一个反应步骤使用较低参照能量，而非第二个不同过渡态。

两种起算能量相差 **9.287592650465 kcal/mol**。原 `RESULTS.md` 也明确给出稳定参照、局部反应构象和相应两种能垒。因此，不能把这次 Standard 运行描述为“没有计算稳定参照”。

### 已发表 Accuracy 0.7 是如何得到的

L2 的现有 Gold 数值是 **29.77 kcal/mol**，不是原图声明的 28.28；高斯宽度为 3.0 kcal/mol，数值偏差的最大扣分为 0.3。

原数据库明确记载：Gold 的目标步骤对应交付 `e1`，使用日志推导的局部参照能垒约 18.987，与 29.77 比较。两条候选的键变化相同；Gold 的反应物未指定立体标记，在本题匹配规则下两种反应物端点的代价相同，最终按边标识顺序选中了 `e1`。

使用评分中的换算常数 **627.5094740631 kcal mol⁻¹ Ha⁻¹**，从原生日志未舍入能量得到：

```text
局部参照能垒
= [−233.203414229 − (−233.233672606)] × 627.5094740631
= 18.987418237270 kcal/mol

与 Gold 的差 = 18.987418237270 − 29.77
             = −10.782581762730 kcal/mol

原始高斯分 = exp[−(−10.782581762730)² / (2×3²)]
           = 0.001566181214

Accuracy = 1 − min(1 − 原始高斯分, 0.3)
         = 0.7

S = 0.1×1 + 0.3×0.5 + 0.6×0.7 = 0.67
```

这里的 0.7 是已有数值扣分封顶的结果，不是“70% 的科学验收通过率”。

### 条件对应到 e2 时，精确分数是多少

仅把参考步骤对应到已交付的稳定参照记录 `e2`，使用同一 TS 和稳定 tZt 原生日志能量：

```text
稳定参照能垒
= [−233.203414229 − (−233.248473327)] × 627.5094740631
= 28.275010887735 kcal/mol

与 Gold 的差 = 28.275010887735 − 29.77
             = −1.494989112265 kcal/mol

原始高斯分 = exp[−(−1.494989112265)² / (2×3²)]
           = 0.883232993851

数值扣分 = 1 − 0.883232993851 = 0.116767006149 < 0.3
条件 Accuracy = 0.883232993851

保持 Graph = 1、SC = 0.5：
条件 S = 0.1×1 + 0.3×0.5 + 0.6×0.883232993851
       = 0.779939796311

综合分增量 = 0.779939796311 − 0.67
           = 0.109939796311
```

按发表表格的四位小数显示，即 **0.6700 → 0.7799**；Accuracy 为 **0.700000 → 0.883233**。这里按原生日志精度计算，没有用展示用的 18.99 或 28.28 代替原始能量差，也没有复制其它配置略有不同的 L2 分数。

### IRC 源端点一虚频，是独立的物理证据问题

原 IRC 反应物侧末帧优化后，频率日志给出 **−50.8323 cm⁻¹**，电子能为 **−233.232689560 Ha**。这个结构比独立验证为零虚频的 cZc 极小值高 **0.616870678432 kcal/mol**。原报告将其描述为 Cs 对称的浅扭转鞍点，并把 C₂ 对称 cZc 结构另列为零虚频极小值。

因此，已有的独立 cZc 极小值并不自动补成“真实 IRC 末帧 → 优化 → 零虚频极小值”的同一条证据链。原数据库还记录了已声明端点日志的起始几何与实际 IRC 外端帧不相符等关联警告；已发表 SC 为 0.5，二元完整科学验收未通过。

**本次条件 Accuracy 变化只处理能垒参照对应，不改变上述频率和端点关联事实。**所以条件综合分保持 SC = 0.5，不能因能垒对应到 `e2` 就将 SC 提高到 1，也不能说完整路径验证由此通过。

## 四、对配置均值的条件影响

以下均从正式 200 行表中每次运行已保存的综合分起算，只加入上面的三个条件增量；保留其它 197 次运行不变。原综合分本身以四位小数保存，所以这些均值的更长小数是对既有表格的条件算数，并非新一轮全量评分。

| 配置 | 已发表 50 题均值 | 同时采用三项条件对应后的均值 |
|---|---:|---:|
| Guided | 0.792954 | 0.792954 |
| Brief-errors | 0.754138 | 0.766138 |
| Record | 0.691798 | 0.703798 |
| Standard | 0.581390 | 0.583588795926 |

- Record / IA5 的 +0.6 使其 10 题 Impossible 均值 **0.23250 → 0.29250**。
- Brief-errors / IC3 的 +0.6 使其 Impossible 均值 **0.48294 → 0.54294**。
- L2 不属于 Impossible；它使 Standard 的 20 题 Easy 均值增加 **0.005496989816**，50 题均值增加 **0.002198795926**。
- 同时采用这三项条件对应，Impossible 排序为 **Brief-errors 0.54294 > Guided 0.44506 > Record 0.29250 > Standard 0.24733**。原表的 Record–Standard 次序会交换，前两名不变。
- 全 50 题的四配置次序不变。Guided–Standard 平均差从原表的 **0.211564** 条件变化为 **0.209365204074**。这是均值的确定性增量计算，未重算置信区间。

三例共同指向一个具体的信息关系：分子连接图和键变化不足以单独指定反应通道、电子态或能量参照。这里列出的条件分数把原运行已经写明的这些身份用于目标对应；它们没有增加化学证据，也不替代正式数据中的现有结果。
