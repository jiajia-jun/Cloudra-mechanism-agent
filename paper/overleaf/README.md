# Cloudra reproduction materials

The retained [companion data](Cloudra_SI/companion_data/README.md) contains task definitions, scoring records, numerical inputs, and reproduction scripts. Its existing path is preserved so published reproduction commands continue to work.

Manuscript sources, PDFs, and editorial artifacts are kept locally. Earlier tracked versions remain in Git history. See [research data and downloads](../../docs/RESEARCH_DATA.md) for the public data packages and [arXiv:2611.02909](https://arxiv.org/abs/2611.02909) for the preprint.
