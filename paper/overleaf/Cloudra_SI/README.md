# Cloudra Supplementary Information draft

Main file: main.tex. Compile with XeLaTeX, TeX Live 2026 in Overleaf.

The SI uses single-column pages for readable protocols and long tables, retaining the manuscript fonts, vector artwork, and figure colors. Tables, figures, equations, and pages use S-prefixed numbering. Sections are edited directly in sections/; long tables are in tables/; original numerical records and task definitions are in companion_data/.

This is the English SI accompanying the current bilingual manuscript. It covers the 50-task/200-run study, 48-run repeated study, diagnostic experiments, the 85-system literature register, and reproduction materials. Offline organization is part of the evaluation method. No new QM or agent experiments are introduced by this draft.
