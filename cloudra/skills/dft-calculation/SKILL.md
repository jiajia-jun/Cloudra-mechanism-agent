# 泛函选择

## 1. 计算方法的精度阶梯与基本原则
*   **一般精度顺序**：CCSD(T) > 双杂化泛函 > 恰当选用的普通泛函 > MP2 > HF > 半经验方法。
*   **核心原则**：初学者切忌盲目效仿老旧文献或不合理的计算设置；必须结合具体体系和任务需求（如算能量、优化结构、算激发态）选择合适的泛函；强烈建议引入色散校正（DFT-D3 或 DFT-D4）。

## 2. 双杂化泛函的使用建议
双杂化泛函精度极高，但计算几何优化和振动分析极其耗时。**推荐策略**：用普通泛函做结构优化和振动分析，再用双杂化泛函算单点能。
*   **综合最强**：`wB97M(2)`（性能最优秀，需用 ORCA/Q-Chem）。
*   **最稳健首选**：`PWPB95-D3(BJ)`（特别适合金属有机反应、弱相互作用，推荐 ORCA）。
*   **Gaussian 用户首选**：`revDSD-PBEP86-D3(BJ)`（弱相互作用和主族反应能表现极佳）。

## 3. 普通泛函任务选型指南
针对不同计算任务，文章给出了明确的普通泛函推荐（建议优先结合 DFT-D3/D4 甚至大基组使用）：

| 计算任务/体系 | 首选/推荐泛函 | 备选或特定条件泛函 |
| :--- | :--- | :--- |
| **主族结构优化与振动** | `B3LYP-D3(BJ)` | 显著共轭体系用 `wB97XD` |
| **有机体系热力学** (反应能等) | `wB97M-V` | `M06-2X` |
| **各类弱相互作用** | `wB97M-V`, `wB97X-V` | `PW6B95-D3(BJ)`, `M06-2X` |
| **局部激发与一般激发态** | `PBE0` (结合 TDDFT) | `CAM-B3LYP`, `wB97XD` (大共轭/CT) |
| **极化率 / 偶极矩等电性** | `PBE0`, `wB97M-V` | `BHandHLYP` (大共轭), `LC-wPBE` |
| **多参考特征强 / 团簇** | `r2SCAN`, `TPSS` | `PBE0`, `MN15L` |
| **过渡金属 (闭壳层反应)** | `wB97X-V`, `wB97M-V` | `PBE0-D3(BJ)`, `TPSSh-D3(BJ)` |
| **过渡金属 (开壳层反应)** | `TPSS0-D4` | `PBE0-D4` |
| **NMR 化学位移** | `B3LYP` (结合标度法) | `revTPSS` (结合 pcSseg-1 基组) |

## 4. 重点泛函的客观评价
*   **B3LYP**：依然是普适性最好、最稳健的“准万能”泛函。只要加上色散校正（解决弱相互作用描述差的问题）并避开电荷转移/里德堡激发，遇到新问题不知道用什么时，首选 B3LYP 试水依然合理。
*   **M06-2X / wB97XD**：B3LYP 的有效替代品，解决弱相互作用和热力学计算问题表现优异。**缺点**：计算速度慢，对积分格点要求高，**绝对不能**用于含过渡金属的体系（M06-2X 尤其差）。
*   **wB97M-V / wB97X-V**：基态能量计算精度最高的普通泛函，甚至优于部分双杂化泛函。建议仅用于算单点能（因其算频率非常困难/耗时）。

## 5. 高效的计算策略与程序选择
*   **高低搭配策略**：不要试图用一个复杂泛函包打天下。大中型柔性有机体系，强烈推荐用 `B3LYP-D3(BJ)` 优化结构并验证频率（便宜、好收敛），然后用 `M06-2X` 或双杂化泛函算单点能。
*   **程序替换建议 (ORCA vs Gaussian)**：做双杂化泛函或大基组单点计算时，**强烈建议使用免费的 ORCA**。ORCA 借助 RI 技术可以大幅降低耗时和内存/硬盘消耗，速度远超 Gaussian。
*   **超大体系**：几百上千原子的球形大体系（如团簇），使用平面波辅助的 **CP2K** 程序效率最高。
*   **突破极限**：若需要超越双杂化泛函，请使用 `CCSD(T)`。配合 ORCA 的 `DLPNO-CCSD(T)` 技术或 `F12` 显式相关方法，可以在控制耗时的前提下计算较大体系。

## 6. 绝对避坑指南（审稿人雷区）
1.  **禁止使用 HF (Hartree-Fock)**：在现代计算中毫无用处，精度极差。
2.  **强烈不建议使用 MP2**：耗时极高且精度被普通泛函（选对的话）甚至双杂化泛函全面吊打，仅在极个别情况（如氢键、部分 NMR 计算）下有少许价值。
3.  **不要用 APFD**：尽管 Gaussian 官方手册推荐，但其实际表现极为平庸，属于缺乏文献支撑的冷门泛函。
4.  **不要对过渡金属使用 M06-2X**：结果往往惨不忍睹。


# 基组选择

选择基组没有绝对的“唯一解”，必须根据你的体系、计算任务、理论方法和计算资源综合权衡。

以下是文章的核心要点总结，建议在设计计算方案时作为标准参考：

## 1. 选择基组前的必备信息
不要盲目问“算某分子用什么基组”，在确定基组前，必须明确以下 5 个要素：
*   **a) 体系构成**：算什么体系？有多少原子？包含哪些元素？
*   **b) 计算任务**：算能量、优化结构、算光谱还是算极化率？
*   **c) 精度与方法**：要求多高的精度？配合什么理论方法（DFT、MP2、CCSD(T)）？
*   **d) 计算资源**：有多少 CPU 核和内存？能接受多长的计算时间？
*   **e) 选用程序**：用 Gaussian、ORCA 还是其它程序？

## 2. 一般问题的基组选用策略

理论方法对基组的依赖性存在根本差异，**切勿混用评判标准**：
*   **普通泛函 (DFT) 及 HF**：对高角动量基函数（如 f, g）依赖小，提升 s, p 角动量性价比更高。计算耗时主要受 **GTF（高斯型函数）数目**影响。
*   **后 HF 方法 (MP2, CCSD(T) 等)**：高度依赖高角动量基函数来描述电子动态相关，计算耗时受 **基函数总数** 影响。

### 针对 DFT 的基组推荐（同等尺寸下，优先选 def2/pcseg 系列，尽量弃用 Pople 系列）：
*   **最低可接受（底线）**：`def2-SV(P)` ≈ `6-31G*`
*   **还行（日常够用）**：`6-311G**` < `def-TZVP`
*   **理想（高精度）**：`def2-TZVP` < `def2-TZVPP` ≈ `pcseg-2`

### 针对后 HF 方法的基组推荐（绝对不能用 Pople 系列，优先选 Dunning 相关一致性基组或高档 def2）：
*   **最低可接受**：`def-TZVP`
*   **较好**：`cc-pVTZ` ≈ `def2-TZVPP`
*   **高精度**：`cc-pVQZ` ≈ `def2-QZVPP`

> **💡 黄金算力分配法则：**
> **几何优化**和**振动分析**对基组极不敏感但极其耗时，请使用中小基组（如 `6-31G**` 或 `def-TZVP` 足矣）。优化完成后，再换用大基组（如 `def2-TZVPP`）计算**单点能**。

## 3. 特定计算任务的基组选型指南

| 计算任务 | 基组选用建议 | 核心注意事项 |
| :--- | :--- | :--- |
| **弱相互作用能** | 视色散比重而定。起步 `ma-def2-SVP` / `jun-cc-pVDZ`，理想 `ma-def2-TZVP` / `jul-cc-pVTZ`。 | 色散作用主导的体系**必须**加弥散函数，并建议做 BSSE (Counterpoise) 校正。 |
| **NMR 化学位移** | 首选 `pcSseg-1` 或 `pcSseg-2`。备选 `def2-TZVP`。 | **千万不要加弥散**；被考察原子**绝对不能**用赝势基组；算 J 耦合常数必须用专用基组（如 `pcJ-1`）。 |
| **势垒计算** | 参考一般推荐。有富余算力可加少量弥散（如 `ma-`），但优先提升 zeta 数（如升至 3-zeta）。 | 不要给 2-zeta 基组加弥散，性价比极低。 |
| **偶极矩 / 极化率** | 算极化率首选 Sadlej 系列 (`ZPOL`, `POL`) 或 `aug-cc-pVDZ`。偶极矩用 `def2-TZVPD`。 | **必须带弥散函数！必须带！** 否则结果完全不可用。Pople 基组算电性极烂。 |
| **振动频率 (IR/VCD)** | `6-31G*` 到 `def-TZVP` 足够。 | **不要用大基组算谐振频率**（纯属浪费时间），结果主要靠频率校正因子修正。Raman/ROA 需两步法单独加弥散。 |
| **溶剂化自由能** | `M05-2X/6-31G*` (结合 SMD 模型)。 | SMD 模型是在这个级别参数化的，**盲目加大基组反而会导致结果变糟**。 |
| **波函数 / 键级分析** | `6-31G*` 到 `6-311G**` 足够。 | **绝对禁止使用带有弥散函数的基组**做基于原子轨道展开的分析（如 Mulliken, Mayer, CDA, PDOS），否则结果毫无物理意义！ |

## 4. 绝对要避开的“雷区”与常见错误

1.  **关于弥散函数（Diffuse Functions）的滥用**
    *   **能不加就不加！** 乱加弥散函数（如 `6-31+G*`）会导致计算量暴增、SCF 难收敛，且对不必要的体系毫无精度提升。
    *   **氢原子几乎不需要弥散**，除非算质子化、氢转移或高度负电性的氢。
2.  **关于极化函数（Polarization Functions）**
    *   绝大多数情况下，**不带极化函数的基组（如 `6-31G`, `6-311G`）根本没法用**。必须加星号（如 `6-31G*`）。
    *   在 Pople 基组上乱堆砌极化函数（如 `6-31G(2df,2pd)`）是非常愚蠢的行为，不如直接升级为 3-zeta 基组（如 `def2-TZVP`）。
3.  **相对论与赝势的混淆**
    *   做全电子相对论计算（DKH, ZORA）时，**必须用全电子相对论专用基组**（如 `cc-pVnZ-DK`），此时用赝势基组会导致完全错误的结果。
    *   常规含重元素（第四周期及以后）体系，强烈推荐使用**赝势基组**，既省时又能自动计入标量相对论效应。
4.  **基组混合策略（Mixed Basis Sets）**
    *   这是高手常用的技巧：对大体系的核心反应区用大基组（如 `def2-TZVP`），对周围环境或骨架用小基组（如 `6-31G*`）；或者给带负电的局部加弥散，其余不加。这能极大兼顾速度与精度。
5.  **强制一致性的误区**
    *   只有 **IRC（内禀反应坐标）**和 **振动分析（频率计算）** 必须与几何优化时所用的基组严格一致。单点能计算**完全可以且应该**使用更大的基组。

# 过渡态搜索工作流

## **严禁使用QST2,QST3关键词搜索过渡态！！！**

这样做仅仅是浪费计算资源，并且高斯在这一块的bug很多。


## 初猜寻找

过渡态搜索对初猜的搜索极其严格，随便搭个过渡态结构是绝对不可能找到的。
选取反应坐标，若多个键参与反应，取其中一个变化最根本的键 **如加成反应中C-C的形成肯定比氢键的变动更加根本**
对反应坐标进行柔性扫描，取势能最高的一点，同时也要取RMS Gradient Norm较小的点，作为过渡态的初猜。
扫描范围以标准键长乘1.5为中心，跑20个点左右就够了。
在寻找到初猜后一定要给用户看一眼再开始算。
opt=(modredundant,calcfc)

## 编写输入文件

能把配置吃满就吃满，多任务并发会使任务变得更慢，一定要设置nproc和mem，mem留一点点就好

比较万金油的组合是m062x/def2svp，以上面的教程为准。过渡态搜索非常困难，关键词一般这样写：opt=(ts,noeigen,calcfc)
**注意**
必须带上freq，过渡态搜索的本质是在搜索二阶鞍点，必须存在唯一虚频。

noeigen必带。

该加色散矫正时一定要加，这一步不消耗计算量，直接em=...即可。

如果不是有特殊的需求，建议询问用户溶剂，加上溶剂来优化会更好。scrf=(smd,...)

一定要在最后一行留空，否则高斯会报错。

## 递交计算任务

建议使用nohup递交任务，并在任务结束后转化为fchk。

## 计算单点能能量

**一定要保证单点能计算使用的是同一个基组！！！**
去掉opt和freq，计算级别尽量升高。

## 跑irc

**irc的计算级别应与TS搜索严格一致，必须保证势能面相同！**
这个过程会花费大量的时间，应该相当贵，不需要maxstep，recalc等关键词。
irc=(lqa,calcfc,maxpoint=200)

### 结果检验

作irc曲线，确认irc的曲线足够光滑，不允许在过渡态附近出现平台或者噪声，一般情况下是过渡态位置不对导致的，需要调整关键词重算过渡态（加maxstep=10，比recalc便宜）


# 关于反应路径规划

主要算重要的过渡态，像质子转移这种没有必要专门做一个过渡态，但是一定要尽可能地把路径列出来，与其等审稿人质疑，不如自己主动算好所有路径。

# 报错提示

1. 是否在文件尾空了一行
2. 是否将关键词拼写正确
3. 色散矫正是否被当前泛函支持（如m062x不支持gd3bj）
4. 有没有正确写扫描设置
5. **分子中是否存在明显的直线键角，此时可能没办法顺利计算hessian矩阵，可以通过笛卡尔坐标来进行几何优化**
