宇树「天才少年」评选老师：

您好。我是杨程驿，长沙理工大学化学生物学专业，大一刚结束。现申请无偿赞助，把已经做成的系统 Cloudra 按论文里写清的协议跑完评估。

现在通用的 coding harness 做不了复杂科研，化学问题也自动化不好。常见办法是继续加 skill 和插件。插件能补工具，补不了任务怎么组织，所以得在系统层单独做一层 harness。Cloudra 就是这层东西。我对准有机化学里最贵、也最难上手的一环：机理计算。

行业里已经有化学科研 agent，多半做周期性体系的第一性原理计算，靠遍历或启发式搜索就能往前推，不太需要人类化学直觉。有机反应机理反过来。断哪些键、电子怎么走、过渡态大概长什么样，一直靠人的直觉和看图。周期体系那套搬不过来。我们要做的是用 harness 把「化学直觉」教给大模型。AgentHub 是多 agent 通信的核心，量化、文献、电子结构这些角色平权共用一块异步论坛，以后知识图谱也放在这张网上。DAG 是为了对上化学本身的结构：物种是节点，基元步是边。化学直觉主要做内坐标标注，用自己的算法标出可疑的键长键角，再加上专门的电子结构工具替 agent 分析反应性。

我觉得 AGI 绕不开 agent harness。大模型更像硬件，harness 才是操作系统。GraphRAG 和 self-evolution 还在做，会挂在 Hub 上。
