## 1. 这件事新在哪

现在通用的 coding harness 做不了复杂科研，化学问题也自动化不好。常见办法是继续加 skill 和插件。插件能补工具，补不了任务怎么组织。科研是一条很长、会中断、还得记住自己走到哪的工作，所以得在系统层单独做一层 harness。

Cloudra 就是这层东西。我对准有机化学里最贵、也最难上手的一环：机理计算。行业里已经有化学科研 agent，多半做周期性体系的第一性原理计算，靠遍历或启发式搜索就能往前推，不太需要化学家那套直觉。有机反应机理反过来。断哪些键、电子怎么走、过渡态大概长什么样，一直靠人的直觉和看图。周期体系那套搬不过来。

我们要做的是用 harness 把「化学直觉」教给大模型。做成了 AgentHub 和 DAG，再加一组化学信息学工具。

AgentHub 是多 agent 通信的核心。算量化的、查文献的、看电子结构的会同时干活。常见做法是再设一个指挥官往下派，话转一手就丢。Hub 里角色平权，共用一块异步论坛，发帖、检索、点名、叫醒睡着的人，记录可以回放。以后知识图谱也放在这张网上，GraphRAG 从这里进出。

DAG 是因为化学本身就是图。物种是节点，基元步是边，路径有方向、有先后。把机理收成 DAG，是用图去对上化学自己的结构。模型换一轮或进程重启，图上的债还在。

化学直觉主要做在工具上。内坐标标注用我们自己的算法标键长、键角、二面角，并标出可疑的几何参数，比如该断的键是不是已经拉得太长、角是不是歪了。电子结构解析有专门工具，替 agent 看电荷、键级、自旋和轨道，分析反应性。模型拿到的是「这里可疑、这里可能在成键」这类判断。

GraphRAG 和 self-evolution 还在做，图谱清洗和 Hub 上的知识沉淀是下一步。我觉得 AGI 绕不开 agent harness。大模型更像硬件，harness 才是操作系统。Cloudra 是在机理计算这条线上试。

这笔赞助用来按已经写清的协议把计算跑实，并把 Hub 上的图谱做起来。
