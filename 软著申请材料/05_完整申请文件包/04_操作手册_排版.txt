# Cloudra 软件使用说明书

## 一、软件概述

### 1.1 软件名称
**Cloudra**

### 1.2 软件版本
**V2.0**

### 1.3 开发完成日期
2026 年 8 月 17 日

### 1.4 软件用途
Cloudra 是一款面向有机小分子反应机理研究的自主计算 Agent 软件。它以事件驱动运行时协调总控 Agent（Coordinator）与领域子 Agent，从反应物出发自主提出机理假设、编排 DFT 验证链（原子映射、构象采样、过渡态搜索、IRC、热化学），并以机理证据图（DAG）与分阶段复核保证结论可审计。内置几何与电子感知工具禁止手写坐标，支持本地与 Slurm 计算监视、危险操作审批与不可变产物快照。

### 1.5 运行环境
- **操作系统**：Linux、macOS、Windows
- **编程语言**：Python 3.11 及以上
- **依赖环境**：OpenAI 兼容的大语言模型 API
- **界面环境**：现代浏览器（Chrome / Edge / Firefox）

## 二、软件功能模块

### 2.1 事件驱动运行时内核

- **事件日志与事件总线**：全部会话行为（消息、工具调用、审批、提醒等）以事件形式顺序记录并广播，前端实时订阅，完整日志可持久化重放。
- **命令总线**：所有写操作先事件后状态，保证多 Agent 并发下的状态一致性；对已失败或取消的 Agent 发送消息时自动重开新一轮运行。
- **Agent 会话状态机**：每个 Agent 拥有独立身份与状态（idle、running、waiting_approval、waiting_input、finished 等），重启会话保留身份并基于目标、DAG、长期记忆与工作区外化重建上下文。
- **并发运行器**：每个 Agent 一个异步任务，真并发且可取消；单轮崩溃原地自动重试（默认 2 次、退避 2/4 秒），历史仅记录成功轮次。
- **固定轮次管道**：每轮依次经过权限策略、DAG 策略、目标策略三个可插拔阶段；LLM 输出以 token 增量流式推送，每轮完整推理过程落持久化事件。

### 2.2 多 Agent 协作体系

- **Coordinator（协调者）**：接收用户需求、拆解任务并调度各专业子 Agent。
- **八类专业子 Agent**：

| Agent 名称 | 标识 | 功能定位 |
|-----------|------|---------|
| Coordinator | a-0 | 任务协调与总控 |
| Explorer | a-1 | 项目文件结构导航与发现 |
| Writer | a-2 | 文档撰写、报告总结、代码编写 |
| Researcher | a-3 | 学术文献检索与专业数据调研 |
| small_mol | a-4 | 小分子建模、构象与结构文件处理 |
| md | a-5 | 分子动力学模拟、力场与轨迹分析 |
| dft | a-6 | 量子化学（Gaussian）输入输出与计算流程 |
| experiment | a-7 | 实验数据处理与操作辅助 |
| env | a-8 | 系统环境配置与软件安装管理 |

- **子 Agent 调度与蜂群**：按模板批量展开的 Swarm 并发调度（可设并发上限）、同步等待与父任务取消级联。

- **AgentHub 论坛**：Agent 间公告板，支持发帖、浏览、检索与跨 Agent 来电呼叫。
- **统一信箱**：用户与 Agent 间消息统一投递，支持定向回复与呼叫。
- **提醒调度**：定时工具由提醒代理拦截，到期自动投递提醒并唤醒对应 Agent。

### 2.3 推理与上下文管理

- **流式输出**：LLM token 增量以事件流直达前端逐字渲染；瞬时数据不落日志、不参与重放。
- **持久化推理记录**：每轮完整思考过程落一条持久事件，历史轮次刷新后仍可回看。
- **常驻与一次性注入**：目标、DAG 等常驻说明固定注入每轮组装；通知类一次性注入在轮内统一收集。
- **手动上下文压缩**：超长对话可一键压缩历史（非流式摘要 + 工具配对边界对齐），在轮边界安全执行。
- **长期记忆**：MEMORY.md 长期记忆文件自动加载，跨会话保留研究偏好与结论。

### 2.4 工具套件

- **Chemtool 化学工具**：SMILES 生成与转换（smiles_to_mol）、Gaussian 输入文件编写（gjf_writer）、量子化学输出解析（SCF 能量、振动频率、过渡态虚频判别等）、NMR/IR 光谱处理与格式转换。
- **Searchtool 检索工具**：arXiv、OpenAlex（含 ChemRxiv 聚合）学术文献检索，原生联网搜索适配。
- **Bashtool 命令工具**：跨平台 Shell 执行，内置命令分级、文件变更审批与危险命令守卫。
- **Writetool 写作工具**：结构化文档、实验记录与报告写入。
- **Plantool 计划工具**：研究计划与机理图（DAG）操作，提供机理草稿、证据绑定等十余种图操作指令。
- **Managetool 管理工具**：子 Agent 调度、蜂群展开、AgentHub 论坛、定时提醒。
- **Skilltool 技能工具**：加载科研方法技能包（DFT 计算、文献综述、论文写作等）。
- **Stoptool 终止工具**：按目标完成度门禁终止会话，防止过早收尾。

### 2.5 DAG 机理图引导编排

软件支持按会话开启的 DAG 引导编排模式，用于有机反应机理研究：

- **机理草稿与阶段契约**：模型提出机理草稿（节点与基元步骤边），经接受后落为交付图；阶段按契约顺序绑定。
- **调用复核**：声明为证据源的工具调用完成后自动进入复核收件箱，由机制检查器（如过渡态虚频数 n_imag==1）确定性派生证据等级。
- **覆盖率审计**：停止会话时审计交付覆盖率，存在未决缺口时阻止提交，保证机理闭环。
- **督导模式**：可选的科学督导 Agent 接受/驳回草稿、逐调用复核并绑定阶段。

### 2.6 安全与权限系统

- **五级权限模型**：READ（读）、WRITE（写）、MANAGE（管理子 Agent）、SCRIPT（执行脚本）、DESTRUCTIVE（破坏性操作）。
- **危险操作审批流**：危险工具调用挂起并等待用户确认；请求与决策全部事件化、可追溯。
- **YOLO 自动审批守卫**：可选全自动模式，由独立 LLM 守卫对审批请求进行安全判断。
- **专项守卫**：坐标守卫（拦截绕过审查直接改写量子化学坐标文件的写法）、命令习惯守卫（提示 heredoc/sed -i 等易错写文件命令）、委派守卫（提示 Coordinator 自行提交计算任务）。

### 2.7 计算执行与数据管理

- **本地与 Slurm 计算**：计算代理扫描会话库认领就绪任务，本地拉起监视进程持续解析输出；支持多节点注册表与 Slurm 作业提交、轮询与续租。
- **SQLite 持久化**：会话级数据库承载事件日志、DAG 图存储与复核收件箱，支持 WAL 模式与增量重放恢复。
- **不可变产物快照**：工具产生的文件以内容寻址快照保存，支持短期下载授权。
- **备份恢复**：内置 backup 子命令，在线快照 + SHA-256 清单，支持校验与恢复。

### 3.1 安装步骤

```bash
# 克隆代码仓库
git clone <仓库地址>
cd <仓库目录>
```

```bash
cloudra config init    # 交互式初始化：LLM 地址、模型、密钥等

cloudra config set coordinator.model gpt-4o   # 设置单个配置项
cloudra config get coordinator.model           # 读取单个配置项
```

## 四、软件使用方法

### 4.1 启动图形界面

```bash
cloudra                 # 构建并启动 Web 服务（默认打开浏览器）
cloudra web --skip-build   # 复用已有 frontend/dist 构建
```

前端界面由三部分组成：

- **项目栏与 Agent 栏**：切换会话项目、查看各 Agent 状态（空闲/运行/等待审批/等待输入）。
- **对话区**：流式对话输出、推理过程分段折叠、工具调用行、Markdown 与 KaTeX 公式渲染。
- **检查器（Inspector）**：六个标签页，管理目标、DAG 编排模式、权限、审批请求、提醒与上下文压缩。

### 4.2 常用管理指令

```bash
cloudra --version      # 查看版本
cloudra logs <对话ID>  # 查看某个对话的日志
cloudra skills         # 列出可用的科研技能包
cloudra backup create  # 创建数据备份（含 SHA-256 清单）
cloudra backup verify  # 校验备份完整性
cloudra backup restore # 恢复到空目录
```

## 五、典型使用场景

### 5.1 反应机理研究（DAG 模式）

----------------------------------------------------------------------
用户在项目设置中开启 DAG 引导编排，向 Coordinator 提出 D-A 环加成机理研究目标。系统引导模型提出机理草稿，经接受后按阶段契约绑定证据：DFT 子 Agent 提交过渡态计算，计算作业完成后自动进入复核收件箱，由虚频检查器确定证据等级；全部必需阶段达成后经覆盖率审计交付完整机理图。

### 5.2 DFT 计算全流程
用户描述目标分子与计算需求，Coordinator 调度 dft 子 Agent：先生成 Gaussian 输入文件（经坐标守卫校验来源），提交计算后由监视进程实时解析输出，自动提取 SCF 能量、HOMO-LUMO 能隙、振动频率等关键指标并写入报告。

### 5.3 文献调研与综述
用户要求调研某课题最新进展，Researcher 子 Agent 检索 arXiv 与 OpenAlex 数据库，Writer 子 Agent 依据检索结果撰写综述，产出结构与引用规范的 Markdown 报告。
