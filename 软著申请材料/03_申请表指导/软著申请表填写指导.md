## 二、软件用途与技术特点

### 2.1 软件用途（300字以内）

**参考填写内容：**

本软件是一款面向化学科研领域的 AI Agent 协作框架。它通过协调多个专业化智能代理，为化学研究人员提供文献检索、数据分析、化学结构处理、光谱数据解析及代码执行等一站式科研辅助服务。软件采用多进程架构确保任务隔离与系统稳定性，内置 ReAct 推理引擎实现智能决策，并集成专业的光谱处理工具，支持多种主流仪器数据格式。

### 2.2 技术特点（300字以内）

**参考填写内容：**

1. 多进程 Manager-Worker 架构，实现 Agent 间任务隔离与并发执行
2. ReAct 单循环推理-行动引擎，支持流式输出与多模态降级
3. 集成 nmrglue、spectrochempy 等专业库，支持 NMR、IR 光谱的完整处理流水线
4. 五级权限模型（READ/WRITE/MANAGE/SCRIPT/DESTRUCTIVE）保障操作安全
5. 危险操作人工审批机制，防止误操作造成数据损失
6. SQLite 持久化存储，支持多会话隔离与历史回溯

## 六、常见填写问题

### Q1：软件名称有什么要求？
A：名称中应包含"软件"或"系统"字样，避免使用过于通用的词汇。建议全称与简称都填写。

### Q2：开发完成日期如何确定？
A：以代码实际开发完成日期为准。本软件以 Git 首次提交日期（2026-05-12）作为开发完成日期。

### Q3：源程序需要提交全部代码吗？
A：不需要。前后各连续 30 页即可。如果代码不足 60 页，则全部提交。

### Q4：可以一个人申请吗？
A：可以。个人申请需提交身份证复印件；多人合作需所有著作权人签字。

### Q5：申请费用是多少？
A：官方费用一般为 250-300 元/件（以版权中心最新标准为准）。如需加急办理，费用会相应增加。

## 七、申请流程

1. **在线填报**：登录中国版权保护中心官网，在线填写申请表
2. **打印签字**：打印申请表，著作权人签字/盖章
3. **准备材料**：
   - 申请表原件
   - 源程序前后各30页（已准备）
   - 操作手册/使用说明书（已准备）
   - 身份证明文件复印件
4. **提交材料**：邮寄或现场递交至版权保护中心
5. **等待受理**：约 1-2 个月收到受理通知书
6. **等待审查**：普通件约 30-60 个工作日下证；加急件约 20-30 个工作日
