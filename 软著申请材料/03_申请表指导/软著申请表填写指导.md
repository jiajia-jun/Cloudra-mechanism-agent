## 二、软件用途与技术特点

### 2.1 软件用途（300字以内）

**参考填写内容：**

本软件是一款面向化学科研领域的 AI Agent 协作框架。它通过协调多个专业化智能代理，为化学研究人员提供文献检索、化学结构识别、光谱数据解析、DFT 计算任务提交与监控、代码执行及远程邮件交互等一站式科研辅助服务。软件采用多进程架构确保任务隔离与系统稳定性，内置 ReAct 推理引擎实现智能决策，并集成专业的光谱处理与计算化学工具，支持多种主流仪器数据格式。

### 2.2 技术特点（300字以内）

**参考填写内容：**

1. 多进程 Coordinator-Follower 架构，实现 Agent 间任务隔离与并发执行。
2. ReAct 推理-行动-观察循环引擎，支持流式输出、多模态降级与上下文压缩。
3. 集成 nmrglue、spectrochempy、RDKit 等专业库，支持 NMR、IR 光谱处理与分子结构识别。
4. 五级权限模型（READ/WRITE/MANAGE/SCRIPT/DESTRUCTIVE）保障操作安全。
5. 危险操作人工审批机制，并支持 YOLO 模式下由独立 LLM Guard 自动审批。
6. SQLite 持久化存储，支持多会话隔离、审批记录与历史回溯。
7. 内置 FastAPI 服务，支持本地 HTTP API 与静态文件访问。

## 六、常见填写问题

### Q1：软件名称有什么要求？
A：名称中应包含"软件"或"系统"字样，避免使用过于通用的词汇。建议全称与简称都填写。

### Q2：开发完成日期如何确定？
A：以当前版本实际开发完成日期为准。本软件以 2026 年 7 月 4 日作为 V1.6.1 开发完成日期。

### Q3：源程序需要提交全部代码吗？
A：不需要。前后各连续 30 页即可。如果代码不足 60 页，则全部提交。

### Q4：可以一个人申请吗？
A：可以。个人申请需提交身份证复印件；多人合作需所有著作权人签字。

### Q5：申请费用是多少？
A：官方登记费已取消（2023 年起），仅需支付证书邮寄到付费用。如需加急办理，代理会收取额外服务费。

## 七、申请流程

1. **在线填报**：登录中国版权保护中心官网，在线填写申请表
2. **打印签字**：打印申请表，著作权人签字/盖章
3. **准备材料**：
   - 申请表原件
   - 源程序前后各30页（已准备）
   - 操作手册/使用说明书（已准备）
   - 身份证明文件复印件
4. **提交材料**：邮寄或现场递交至版权保护中心
5. **等待受理**：约 1-2 个月收到受理通知书
6. **等待审查**：普通件约 30-60 个工作日下证；加急件约 20-30 个工作日
