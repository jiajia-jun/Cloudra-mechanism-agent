## 二、在线申请流程

### 2.1 注册账号

1. 访问中国版权保护中心官网：https://www.ccopyright.com.cn
2. 点击"登记大厅"进入著作权登记系统
3. 注册个人/机构账号
4. 完成实名认证（需上传身份证/营业执照）

> **注意**：实名认证审核通常需要 1-3 个工作日，请提前完成。

### 2.2 填写申请表

1. 登录系统后，选择"计算机软件著作权登记申请"
2. 按以下信息填写：

| 页面 | 填写要点 |
|-----|---------|
| 软件基本信息 | 全称/简称/版本/完成日期，参见本指南第一部分 |
| 软件技术信息 | 硬件环境/软件环境/编程语言/源程序量 |
| 软件功能与特点 | 用途（300字内）+ 技术特点（300字内） |
| 著作权人信息 | 姓名/单位、证件类型及号码、国籍、省份城市 |
| 申请人信息 | 通常与著作权人一致 |
| 代理人信息 | 如自行办理，无需填写 |
| 软件鉴别材料 | 选择"源程序"和"文档"提交方式 |

3. 保存并提交申请表
4. 打印申请表（带条形码）

### 2.3 签字/盖章

- **个人申请**：著作权人在申请表第2页签字
- **企业申请**：在申请表第2页加盖公章
- **多个著作权人**：每一页均须所有著作权人签字/盖章

## 三、材料递交

### 3.1 材料清单

请按以下顺序整理：

1. **软件著作权登记申请表**（原件，签字/盖章）
2. **源程序**（前后各30页，A4纸单面打印）
3. **操作手册/使用说明书**（已准备，A4纸单面打印）
4. **身份证明文件**（复印件）
   - 个人：身份证复印件
   - 企业：营业执照副本复印件（加盖公章）
5. **其他材料**（如适用）
   - 合作开发协议（多人合作）

## 四、审查与领证

### 4.1 审查流程

```
材料递交 → 形式审查（1-2周）→ 受理通知书 → 实质审查（30-60工作日）→ 登记证书
```

### 4.2 各阶段说明

| 阶段 | 时间 | 说明 |
|-----|------|------|
| 形式审查 | 1-2 周 | 检查材料是否齐全、格式是否正确 |
| 受理通知 | 形式审查通过后 | 收到《受理通知书》，获得受理号 |
| 实质审查 | 30-60 工作日 | 审查软件独创性等 |
| 补正通知 | 如材料有问题 | 需在30日内补正，否则视为撤回 |
| 登记证书 | 审查通过后 | 可自取或邮寄领取 |

### 4.3 进度查询

1. 登录中国版权保护中心官网
2. 进入"我的登记"查询申请状态
3. 或拨打咨询电话：010-68003887

### 4.4 证书领取

- **自取**：携带受理通知书和领取人身份证
- **邮寄**：在申请表中选择邮寄方式，到付

## 六、常见问题 FAQ

### Q1：源代码中出现开源代码会影响登记吗？
A：一般不会。只要软件的独创性部分（如架构设计、业务逻辑等）是自主开发的即可。本软件使用 MIT 许可证，对软著登记无影响。

### Q2：软件还在开发中可以申请吗？
A：建议开发完成后再申请。开发完成日期以实际完成日期为准，后续版本更新可以办理变更或重新登记。

### Q3：申请表填错了怎么办？
A：在线提交前可以反复修改。打印签字后如发现错误，需重新在线填写并打印。

### Q4：一个软件可以申请多个软著吗？
A：同一软件的不同大版本（如 V1.0 和 V2.0）可以分别登记。小版本更新通常无需重新登记。

### Q5：软著登记后有什么好处？
A：
- 作为软件著作权归属的初步证明
- 可用于 App 上架、微信小程序审核
- 可用于企业申报高新技术企业
- 可用于知识产权保护维权

### Q6：收到补正通知怎么办？
A：仔细阅读补正意见，在 30 日内按要求修改并重新提交材料。如不确定如何处理，可电话咨询版权中心。
