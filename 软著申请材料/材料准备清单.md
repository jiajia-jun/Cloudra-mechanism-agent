## 待办事项

### 阶段一：信息确认（需要你完成）

- [ ] **确认软件全称**：是否使用"Cloudra化学科研AI Agent协作框架软件"？
- [ ] **确认开发完成日期**：是否以 2026年07月04日 为准？
- [ ] **确认著作权人**：
  - [ ] 个人申请：填写你的姓名和身份证号
  - [ ] 企业申请：填写企业全称和统一社会信用代码
- [ ] **确认是否委托代理**：自行办理 / 委托代理机构

### 阶段二：材料打印

- [ ] 打印申请表（在线填写后打印，带条形码）
- [ ] 打印源代码前30页（A4单面，左侧装订）→ 使用 `05_完整申请文件包/02_源程序_前30页_排版.txt`
- [ ] 打印源代码后30页（A4单面，左侧装订）→ 使用 `05_完整申请文件包/03_源程序_后30页_排版.txt`
- [ ] 打印操作手册（A4单面，左侧装订）→ 使用 `05_完整申请文件包/04_操作手册_排版.txt`
- [ ] 复印身份证明文件

### 阶段三：签字盖章

- [ ] 申请表签字（个人）/ 盖章（企业）
- [ ] 身份证明文件上注明"与原件一致"并签字/盖章（如需要）

### 阶段四：递交申请

- [ ] 在线提交申请表
- [ ] 邮寄或现场递交纸质材料
- [ ] 保留邮寄凭证

### 阶段五：跟踪进度

- [ ] 1-2周后查询是否收到受理通知书
- [ ] 定期登录系统查询审查进度
- [ ] 如收到补正通知，30日内完成补正
