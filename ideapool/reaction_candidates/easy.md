# Easy 档候选反应清单（聚焦七类，29 个）

> 生成日期：2026-08-25；2026-08-28 重构聚焦七类并逐条复核锚点。用途：量子化学机理推导 agent benchmark 的 Easy 档候选池。
>
> **Easy 档定义**：教材级经典单步基元反应；重原子 ≤7（边界放宽到 ≤10）；CHNO 主族原型（含少量 F/Cl/Br/S/B，均为 MACE-OMol25 / OMol25 训练覆盖元素）；闭壳层单重态；气相可算。
>
> **类型范围（2026-08-28 收敛）**：只保留七类——**Diels-Alder、[3,3]-σ 迁移、[1,5]-氢迁移、SN2、E2、羰基亲核加成、质子转移/互变异构**。剔除电环化、ene、螯变、[3+2] 1,3-偶极环加成（强电荷分离体系，MACE 短程模型的自洽性未验证）与其余加成，避免把"化学正确但 MACE 不自洽"的体系计入通过性。
>
> **金标准引擎适配自查**：MACE-OMol25 训练于 ωB97M-V/def2-TZVPD 级别的 OMol25（含 Transition-1x 反应子集）。其舒适区高密度区恰为"重原子 ≤7、CHNO、单步气相反应"。每条候选的"舒适区自查"栏给出元素集合 + 重原子数 + 闭壳层确认；✅ = 完全落在高密度区。
>
> **能垒锚点标注约定**：
> - [已核实] = 经 WebSearch 确认文献真实存在且关键数值被核对；[部分核实] = 文献存在已确认、但具体数值或卷页为回忆值待二次核对；[未核实] = 出处凭记忆，使用前必须复查。
> - 对气相离子-分子反应（SN2/E2/阴离子加成），势能面为双阱型：标注**中央能垒**（TS 相对离子-偶极络合物），并注明 TS 相对反应物渐近线的位置，避免 gold 值口径混淆。
> - 能垒类型标注：Ea = Arrhenius 活化能，ΔH‡ = 活化焓，ΔE‡ = 电子能垒，ΔG‡ = 活化自由能。**评分绑定 agent 实际计算证据（TS 搜索 + IRC + 频率），锚点只作 ±2 kcal/mol 参考，不作 pass/fail 硬线**——Easy 档考"自洽的机理闭环"，不追绝对真值。
