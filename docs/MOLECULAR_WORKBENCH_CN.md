# 分子工作台使用指南

[文档首页](README.md) · [项目首页](../README_CN.md)

分子工作台是 Cloudra 内置的三维分子编辑器和计算结果浏览器。在项目控制台的 **「结构、计算与机理」** 页面里，点任意一张结构预览卡片或者「打开工作台」就能进去；在项目内任何地方（只要光标没停在输入框里）直接按 **Alt+M** 也能随时呼出。在调度队列页点某条作业的「查看结果」，可以直接跳到对应记录。

## 结构和机理图的关系

- **standard 项目**不需要建机理图，页面直接把保存过的结构、计算记录和普通文件列成卡片。
- **DAG 项目**会在同一个页面里展示机理图。点中图里的某个物种或反应步，下方只显示关联到它的计算；反过来点卡片上的对象标签，也能跳回图里的对应节点。
- 还没绑定到机理图的文件照样可以打开、编辑和查看。想归位时点卡片上的「关联对象」手动选一下就行。关联只记录来源，不会替你把科学验收改成通过；程序也不会仅凭文件名猜它属于哪个物种。

## 导入结构和回看计算轨迹

工作台顶部可以直接粘 SMILES、XYZ、MOL/SDF、Gaussian 或 ORCA 的输入输出，也可以填项目内路径或者选本地文件。

用 SMILES 生成的是初始三维构型，不代表已经优化。导入 XYZ 或量化日志时，坐标里本来就没有显式键级，需要改键或预优化时先点一下「明确感知连接关系」，检查完再动手。

打开计算记录时，画面默认停在**最后一帧有真实坐标的位置**。你可以拖帧滑块、点播放，或者直接点能量曲线上的点来切换帧（只有能量、没有坐标的步会留在曲线里，但无法编辑结构）：

- **几何优化**：看每一帧构型、能量、RMS 力、最大力和软件原生收敛标记。
- **频率计算**：列出每个真实频率和振动位移；选中某条频率点「播放真实位移」，直接看它到底在震哪里。
- **IRC 路径**：看反应坐标、方向、能量剖面和沿途结构（ORCA 逐点结构需要同目录下的轨迹边文件，所以最好直接从项目作业路径打开，别只单独拖一个主 `.out` 文件）。
- **势能面扫描**：看采样点坐标和能量；二维扫描默认画散点，选好横轴并固定其他维度就能连成切片曲线。
- **力场轨迹**：保留原始力场来源、能量和梯度。

点「导出 CSV」能把帧号、能量、力指标和扫描坐标直接导出来画图。工作台坚持有一说一：日志里缺的指标就老实显示未知，绝不拿最大力冒充 RMS 力，也不会在缺位移数据时瞎播假动画。

## 基于历史帧做编辑、调内坐标和设约束

工作台把 **「来源帧」**（只读回看原计算）和 **「编辑稿」**（你正在改的版本）分得很清楚。想从轨迹里的某一帧出发改结构，先切到那一帧，点「以此帧建立编辑稿」，以后保存时就会牢牢记着你是以哪一帧为起点的。

在 **「选择模式」** 下依次点原子（或者在右侧原子列表里点），就能定义内坐标，画布顶部会实时标出编号、顺序和当前实测值：选 2 个原子是键长（Å），选 3 个是键角（°），选 4 个是二面角（°）。拖动画布旋转缩放不会把选中的原子点丢。

选好原子后点「编辑距离／键角／二面角」，同一组选择可以做两件事：

1. **直接调几何**：填目标值，先预览再确认。默认固定前侧、移动后侧基团，方向可以切。遇到环状体系分不清哪边该动时，点「画布选择移动原子」自己框出要动的原子就行。
2. **给下次计算设冻结或扫描**：展开「冻结与扫描」，把当前坐标设成冻结，或者填好起点、终点和步数加进扫描列表（支持多维独立扫描）。

除此之外，选两个原子可以加键、删键或改键级，也能做整分子或局部镜像。所有改动都可以随时撤销。如果你删掉的原子正好被某个冻结/扫描用到了，界面会主动清掉失效条目并提醒你重设，不会让旧编号悄悄错位指向别的原子。

## 从零画分子、改基团和力场预优化

新建空白画布默认进入 **「编辑模式」**。选好元素或基团后，点空白处独立放置，点已有原子就会从它身上长出一根单键。在「选择模式」下点一个原子，可以换元素、改形式电荷、改杂化或一键补氢。程序会按常见主族闭壳层规则给 sp / sp² / sp³ 摆出合理方向（孤对电子自动占方向，不塞假原子）；这只是建模初猜，精确键角还是要靠后续优化。

想换取代基时，先依次点**保留侧原子**和**被替换侧原子**，再到「基团替换与共享历史」里填基团 SMILES（没写连接标记的话，先预览一下点选连接原子）。你确认用过的基团会自动记在跨项目的共享历史里，按使用频次排在前面，下次直接复用。

画完草稿想顺一下几何，可以在建模区选 **MMFF94**（默认）或 **UFF** 点「力场预优化」。它只在当前构象上就地松弛、不增删原子，需要先把键级、形式电荷和显式氢补齐（有冻结坐标或开壳层体系时不启用）。优化完可以直接接着改或撤销，只有你主动点保存才会落盘。记住力场预优化只是理顺初猜，不能代替量子化学优化。

## 保存结构与生成计算输入

填好名字点「保存编辑稿到项目」，完整的分子连接图、来源帧和冻结/扫描设置会存进 `.cloudra/structures/`，同时生成 XYZ、MOL 等常用格式方便下载。保存后主 Agent 会立刻收到通知知道你存了新结构，但**保存本身不会自动提交计算**。

如果你想顺手生成 Gaussian 或 ORCA 的输入文件，勾上「同时生成原生计算输入」，自己填好引擎、方法、基组、电荷、自旋多重度和任务类型——程序不会自作主张替你挑泛函和基组。人工改过的结构会被当成新的候选结构，不会自动继承旧文件的能量、虚频或过渡态验收结论。

## 周期性体系与直接在图上给 Agent 派活

打开 EXTXYZ、带晶胞的 XYZ、POSCAR/CONTCAR 或有序 CIF 时，画布会自动画出晶胞，勾上「显示相邻晶胞」还能看周期镜像（发给 Agent 时仍保持原晶胞不变）。

在画布上不用写冗长的原子编号说明——选择模式下点中原子点「标记原子」就会贴上 `A`、`B` 这样的标签，选两个支撑原子点「标记中心位点」就能标出桥位中心。然后在画布底下直接写人话指令（比如“把 A 上的氧移到 B 位点，先给我看初始构型”），点 **「发射给 Agent」**。

Cloudra 会把你的原话、带标签的画布截图、精确坐标和标记坐标文件一起发进当前对话（就算所用模型不看图，也能从结构化标记文件里读懂你在指哪儿）。哪怕是还没保存的草稿或者暂停在半路的轨迹帧也能直接发射，Agent 回复里提到的项目结构文件也能一键点回工作台继续看。
