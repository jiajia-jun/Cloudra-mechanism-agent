# 球面上随机均匀分布点算法 — 知识卡片

## 1. 轴旋转法生成球面随机点及其缺陷

选取起始点(1,0,0)后，依次绕Z、Y、X轴随机旋转0到2π角度生成球面点；此方法点数较少时看似均匀，但点数增多（如100000个）会隐约出现环状密集分布。原因是第二步旋转导致球的两极出现聚集，第三步虽弱化了聚集，但两极经绕X轴旋转后仍形成环状密集区。
x=1
y=0
z=0
!Step 1: Rotate about Z axis
call RANDOM_NUMBER(rotval)
rotval=rotval*2*pi
xtmp=cos(rotval)*x-sin(rotval)*y
ytmp=sin(rotval)*x+cos(rotval)*y
x=xtmp
y=ytmp
!Step 2: Rotate about Y axis
call RANDOM_NUMBER(rotval)
rotval=rotval*2*pi
xtmp=cos(rotval)*x-sin(rotval)*z
ztmp=sin(rotval)*x+cos(rotval)*z
x=xtmp
z=ztmp
!Step 3: Rotate about X axis
call RANDOM_NUMBER(rotval)
rotval=rotval*2*pi
ytmp=cos(rotval)*y-sin(rotval)*z
ztmp=sin(rotval)*y+cos(rotval)*z
y=ytmp
z=ztmp

## 2. 直接球坐标变换法及其缺陷

在0到π间随机选取θ，在0到2π间随机选取φ，通过球坐标变换公式x=sin(θ)cos(φ)、y=sin(θ)sin(φ)、z=cos(θ)计算坐标；此方法会导致点在两极严重聚集，是一种错误且不负责任的算法。
call RANDOM_NUMBER(rotval)
theta = pi*rotval
call RANDOM_NUMBER(rotval)
phi = 2*pi*rotval
x=sin(theta)*cos(phi)
y=sin(theta)*sin(phi)
z=cos(theta)

## 3. Marsaglia方法生成均匀球面点

在(-1,1)区间内随机取x1和x2，若x1²+x2²≥1则重新选取，直到满足条件；随后通过公式x=2*x1*sqrt(1-x1²-x2²)、y=2*x2*sqrt(1-x1²-x2²)、z=1-2*(x1²+x2²)计算坐标。该算法源自http://mathworld.wolfram.com/SpherePointPicking.html，生成的点分布非常均匀完美。
do while(.true.)
call RANDOM_NUMBER(x1)
call RANDOM_NUMBER(x2)
x1=2*(x1-0.5D0)
x2=2*(x2-0.5D0)
if (x1**2+x2**2<1) exit
end do
x=2*x1*dsqrt(1-x1**2-x2**2)
y=2*x2*dsqrt(1-x1**2-x2**2)
z=1-2*(x1**2+x2**2)
