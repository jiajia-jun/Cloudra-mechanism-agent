## 1. 反应概览
DDQ（2,3-二氯-5,6-二氰基-1,4-苯醌）是高电位醌类选择性氧化剂：氧化苄位/烯丙位 C-H 为醇/醚/羰基，氧化富电子杂环（吲哚→氮杂醌）、脱氢芳构化，并广泛用于对甲氧基苄基（PMB）/对甲氧基苯基（PMP）保护基的脱除。产率 70–95%。机理为氢负转移与 SET 通道并存，依底物与溶剂而变。

## 2. 主机理链：CT 络合
富电子芳环/苄醚与 DDQ 醌面形成黄色电荷转移络合物——颜色变化常作为反应进度指示。该预平衡降低了后续电子转移的表观活化能。

## 3. 主机理链：氢负/SET 转移
对活化 C-H（如 PMB 醚的苄位）：氢负转移到醌羰基生成 DDQH- 与苄基碳正离子（净氢负转移）；对某些底物则是 SET 后质子耦合电子转移。两条通道在动力学同同位素效应上可区分（KIE 接近 1 提示 SET 主导）。

## 4. 主机理链：正离子捕获
苄基碳正离子：有水/醇→醇/醚（脱 PMB 保护）；无亲核体且能芳构化→消除脱氢（如四氢萘→萘）。DDQH2 沉淀或水洗除去。

## 5. 关键条件与试剂选择
- 溶剂开关：无水 DCE/DCM 倾向脱氢；含水 MeCN/DCM 或 MeCN/H2O 得醇（脱保护标准条件）。
- HFIP/TFE：氢键供体溶剂大幅加速 PMB 脱保护（常用催化量 DDQ）。
- 当量：脱保护 1.0–1.2 eq；脱氢芳构化可 1.2–2 eq。
- 温度：室温或 0 °C；富电子底物低温防过度氧化。

## 6. 底物范围与局限
擅长：PMB/PMP 醚、苄醇、烯丙醇/醚、四氢萘、富电子芳环（茴香醚类）。不擅长：脂肪 C-H、贫电子芳环、简单烷基苯。局限：① 颜色深、后处理有色杂质；② 过度氧化到酯/酸；③ 对强还原性官能团（硫醚→亚砜）共氧化。

## 7. 副路径与抑制策略
- 过度氧化成酸/原酸酯：抑制——1 eq、低温、及时水淬。
- 硫醚共氧化：抑制——换 CAN 或 Ce 类；或保护硫。
- 脱保护不完全：富电子底物若 CT 络合弱——加 HFIP、延时、催化量补 DDQ。
- 脱氢误发生（想要醇却得烯）：控制含水量与溶剂极性。

## 8. 选择性控制
chemo：活化 C-H（BDE 低、正离子稳定）优先；位点选择由正离子稳定性排序（苄位 > 烯丙位 >> 烷基）。对 PMB vs MBn 选择脱除是正交保护策略核心。对映：通常无手性控制，但可用于动力学拆分（少见）。

## 9. 与计算化学的衔接
计算方向：① DDQ/底物单电子转移自由能 ΔG_ET（与 CV 测量的氧化电位对照，Marcus 理论估速率）；② 氢负 vs SET 通道的势能面比较（溶剂极性显著翻转通道顺序——SMD 的必要性演示案例）；③ 苄位 BDE 与 DDQ 氧化速率的 Brönsted/BDE 相关。醌的电子亲和能计算相对成熟；注意溶剂化自由能在 MeCN vs DCE 的差别对机理判定的影响。
