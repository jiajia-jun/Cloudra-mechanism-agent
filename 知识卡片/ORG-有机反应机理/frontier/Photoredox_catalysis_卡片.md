## 1. 反应概览

光氧化还原催化（photoredox catalysis）用可见光激发的光敏剂实现单电子转移（SET），在温和条件（室温、可见光）下生成自由基/自由基离子中间体，完成传统热化学难以实现的极性翻转偶联。三类主流光催化剂：1) 过渡金属配合物——Ru(bpy)₃²⁺（E₀,₀≈2.1 eV，三重态寿命~1.1 μs）、fac-Ir(ppy)₃（更强还原剂）、Ir[dF(CF₃)ppy]₂(dtbbpy)⁺（更强氧化剂，氟配体拉低 HOMO）；2) 有机染料——Eosin Y、Rose Bengal、曙红/吡喃鎓盐，成本低但光稳定性稍差；3) 半导体/异相材料（近年扩展）。2008–2015 年由 MacMillan、Yoon、Nicewicz、Molander 等奠定基础，近十年与 Ni/Cu 催化、HAT、电化学交叉形成"自由基接力"工具箱。典型产率 60–95%，对光敏剂与猝灭剂的氧化还原电位匹配极其敏感。

## 2. 主机理链：光激发与三重态生成

基态光敏剂吸收可见光（MLCT 或 π→π*）到单重激发态 S₁，经内转换/系间窜越（ISC，重原子效应使 Ir/Ru 的 ISC 近乎高效）到达长寿命三重态 T₁。T₁ 既是比基态更强的还原剂也是更强的氧化剂：激发态氧化电位 E*(PC⁺/PC*) = E(PC⁺/PC) − E₀,₀；激发态还原电位 E*(PC/PC*) = E(PC/PC) + E₀,₀（Rehm–Weller 关系，含做功项 wᵣ）。T₁ 寿命（ns–μs 量级）决定与底物双分子 SET 的时间窗口；寿命过短则猝灭不完全，过长则促进副反应。激发态电子转移以外球方式进行——催化剂配位饱和，电子"隧穿"发生，Marcus 理论要求低重组能，这正是刚性八面体联吡啶/苯基吡啶配合物的优势。

## 3. 主机理链：氧化猝灭循环（oxidative quenching）

氧化猝灭循环：激发态 PC* 把电子交给底物/受体（氧化猝灭），自身成为氧化态 PC⁺，底物生成自由基阴离子（如 R–X + e⁻ → R• + X⁻，卤代烃还原裂解）。随后 PC⁺ 被计量还原剂（Hantzsch 酯、TEA、硅烷、抗坏血酸）还原回基态 PC，完成催化循环。适用场景：底物容易被还原（活化卤代烃、重氮盐、 redox-active ester），需要温和的计量还原剂再生催化剂。例如 Ir(ppy)₃ 直接还原未活化 C–I（强还原），或 [Ru(bpy)₃]²⁺* 还原 α-溴代羰基化合物。循环推动力判据：ΔG = −F[E(PC/PC*) − E(R•/R–X)]（电子转移步）；负值越大越快但可能落入 Marcus 上翻转区。

## 4. 主机理链：还原猝灭循环与自由基捕获

还原猝灭循环：给电子体（TEA、DIPEA、DMF、烯胺、富电子芳烃）先还原 PC* → PC•⁻，再由 PC•⁻ 还原第二个受体或被氧化剂（O₂、Selectfluor、水溶性氧化剂）再氧化回 PC。胺类电子给体常被氧化为 α-氨基自由基，进而脱羧/碎裂（如 DIPEA 促进的自由基反应）。生成的碳自由基随后：1) 加成到烯烃/羰基（自由基加成）；2) 被第二分子捕获剂（如分子内环化、另一金属催化剂）捕获；3) 从 H 原子供体（Hantzsch 酯、硫醇、硅烷）夺氢完成还原官能团化。光催化剂经第二次 SET 再生，净结果是"光驱动的单电子氧化还原对循环"，计量氧化剂/还原剂只负责闭合总质量平衡。

## 5. 关键条件：光源、气氛与催化剂选择

光源：450 nm 蓝光 LED（最常用）、440–560 nm 螺旋灯、太阳光（Eosin Y 可用）；光强需匹配反应瓶几何（光子通量决定 TOF 上限）。气氛：绝大多数 SET 循环严格除水除氧（O₂ 是三重态猝灭剂与自由基捕获剂，生成过氧自由基引发副反应）——Schlenk 冻融/惰性气体保护；少数需 O₂ 作终末氧化剂（如酚氧化偶联）。催化剂选择原则：需要强还原用 fac-Ir(ppy)₃ 或4CzIPN（有机）；需要强氧化用 Ir[dF(CF₃)ppy]₂(dtbbpy)PF₆ 或吖啶鎓盐；成本敏感用 Eosin Y/4CzIPN。溶剂：MeCN、DMF、DMSO、DCM（注意电位窗口）；溶剂极性影响离子对与猝灭速率。催化剂载量 0.5–5 mol%；与 Ni 双催化时常 1–3 mol%。反应瓶用透明硼硅玻璃，避免紫外截止。

## 6. 底物范围与局限

适用：活化/未活化卤代烃、重氮盐、磺酰肼、redox-active ester（NHP 酯）的还原裂解；富电子芳烃/胺/烯醇硅醚的氧化；烯烃的氢官能团化、双官能团化；[2+2] 环加成（经 radical ion 路径）；亚胺/氧鎓离子的光催化生成。局限：1) 纯热激发禁阻的直接激发通常需 UV，光敏剂是必需中介；2) 强猝灭剂（如自由基抑制剂 BHT、痕量 O₂）毒化循环；3) 电位窗口之外的底物无法有效猝灭——需调整光敏剂或加介体（mediator）；4) 放大时受光穿透深度限制（<1 cm 有效层），流动化学是放大方案；5) 有机染料的光漂白。

## 7. 副路径与抑制策略

副路径一：背电子转移（back electron transfer, BET）复合——初始 SET 生成的溶剂分离自由基对（SSIP）或接触自由基对（CRP）在扩散逃逸前重新组合回到原料，量子效率下降。抑制：选择自由基碎裂速率快的底物（如生成稳定 R• + 稳定阴离子的 C–X、N–O 键）；加大底物浓度提高笼外逃逸；更换位阻更大的光敏剂降低电子耦合。副路径二：光敏剂自身降解（配体解离、染料氧化）——Ir 配合物较稳，Eosin Y 在强还原条件易漂白。抑制：降低光强、缩短光照时间、添加催化量苯醌作为光稳定剂、换更稳的4CzIPN。副路径三：O₂ 诱导的自由基氧化副产物（过氧化物、醇/酮混合物）。抑制：严格除氧；需要 O₂ 时控制分压与通气速率。副路径四：非选择性 HAT/极性不匹配的副加成——通过调节光敏剂电位与溶剂极性纠正。

## 8. 选择性控制、计算化学衔接与进展

选择性：1) 化学选择性由 SET 电位窗口决定——只氧化/还原目标官能团；2) 对映选择性用共价手性催化剂（烯胺/亚胺离子/NHC）接力，而非手性光敏剂（ee 通常 >90%）；3) 区域选择性由自由基加成的极性匹配与位阻控制。计算化学衔接：激发态用 TD-DFT（CAM-B3LYP/ωB97X-D）算 E₀,₀ 与 TDDFT 激发能，与 Rehm–Weller 结合预测 E*；Marcus 理论算 SET 速率；自由基加成/环化能垒用 DFT（溶剂 SMD）；自旋密度分析验证自由基位点。近年进展：4CzIPN/有机超有机光催化剂替代贵金属、光-HAT-金属三重催化、双光子/上转换、电化学-光化学耦合（无计量氧化还原试剂）。综述见 Chem. Rev. 光氧化还原专号与 Acc. Chem. Res.。
