## 1. 反应概览

丰产金属（abundant metal）催化以 Fe、Co、Mn 替代 Pd/Ni/Rh 完成交叉偶联与 C–H 官能团化，兼顾成本、毒性和独特反应性（多价态单电子化学）。里程碑：Knochel 型 Fe 催化 Kumada 偶联（Fe(acac)₃/FeCl₃ + 格氏试剂 + 芳/烯基卤，−20~25 °C，无膦配体或微量配体，>100 种底物）、Co 催化（CoCl₂/联吡啶 + 格氏，cobaltbenzene 体系的自由基化学）、Mn 催化还原偶联（Mn⁰ 中介的偶联、Mn 催化 C–H）。机理与 Pd 的两电子循环根本不同：Fe/Co 走**多步单电子转移**（SET、自由基捕获、氧化加成的均裂），常伴纳米颗粒/低价簇参与（争议热点），对 sp³ 卤化物与官能团（酯、腈、酮）耐受性极佳。典型产率 60–95%；配体简单（甚至无配体）；是"可持续合成"与前沿机理研究的交汇点。

## 2. 主机理链：Fe 催化 Kumada 偶联（SET/自由基框架）

催化体系 Fe(acac)₃ 或 FeCl₃(痕量膦或无配体) + RMgBr（2 equiv）+ ArX（ArBr/ArCl，或杂芳基溴）。启动：格氏对 Fe(III) 多重转金属/还原，生成低价 Fe（Fe(0)/Fe(−II) 物种或 Fe 纳米簇，原位 TEM/Mössbauer 可观测）。活性物种对 ArX 单电子转移：ArX + Fe(II) → Ar• + X⁻ + Fe(III)（或经外球 SET 到 ArX 的 σ* 轨道），芳基自由基生成——自由基时钟（环丙基、烯丙基重排）实验支持该路径，与 Pd 的闭壳层氧化加成不同。Ar• 被低价 Fe 捕获生成 Ar–Fe(II/III)，再经转金属（R⁻ 从 Grignard 迁移）得 Ar–Fe–R，还原消除（或自由基-金属偶联）给出 Ar–R。Fe 的多价态（−2~+4）使单电子步热力学可行；配体（微量 dppp/吡啶或 NHC）调节聚集与选择性。

## 3. 主机理链：Co 催化与 cobaltbenzene 体系

Co 催化以 Co(II) 盐（CoCl₂、Co(acac)₂）+ 联吡啶/膦配体 + 格氏为特征。关键中间体"cobaltbenzene"（η⁶-芳烃 Co(0) 配合物，由 Co(I) + 芳烃 + 格氏还原生成）对芳基卤氧化加成/SET 给芳基-Co(III) 或芳基自由基，再与 R–Mg 转金属、还原消除。Co 的优势：对酰氯、氯代芳烃（低温活化）、烯基卤的高活性；sp³ 亲电试剂（烷基溴、KF 预活化的 silyl 硅烷）经自由基路径偶联。与 Fe 类似，Co 纳米簇可能真实参与（鬼催化风险：均相/异相边界需毒化实验与速率研究判别）。Mn 的角色：Mn⁰ 粉作为还原性转金属试剂（Kagan/Molander 型 Fe/Mn 协同、电化学 Fe/Mn），或 Mn 催化的 C–H 芳基化（与 Grignard/ArX）；Mn(I) 光催化剂（Mn(CO)₃Br 联吡啶）近十年用于光催化还原——丰产金属光化学的代表。

## 4. 主机理链：Fe/Co 的 C–H 活化变体

Fe/Co 的 C–H 官能团化与 Pd 的 CMD/ metallacycle 框架不同，主要路径：1) Fe/Co-氧/氮协同的氢原子转移（高价 Fe(IV)=O 仿生路径，与 HAT 催化交叠）；2) Co(III) 介导的 C–H（吲哚、吡啶定向的 C–H 芳基化，Shi 组 Co/O₂ 体系——走 Co(III)-C 或自由基路径）；3) Fe/Co 催化的 C–H/Mg（格氏的直接 C–H 金属化，碱性条件）；4) 电化学 Fe/Co C–H 氧化（无化学氧化剂）。以吲哚 C2 芳基化为例：Co(OAc)₂/联吡啶 + ArMgBr + O₂（终端氧化剂），吲哚 C2-H 去质子化与 Co–C 形成（可能经 SET 生成吲哚自由基），转金属/还原消除。选择性由底物电子与配位导向共同控制——富电子杂芳环的 C2 优先。

## 5. 关键条件：催化剂、格氏与温度

Fe：Fe(acac)₃ 1–5 mol%（对空气相对稳定）、FeCl₃、Fe(II) 草酸盐；无配体或 1–10 mol% 膦/吡啶/NHC；格氏 2–2.5 equiv（对 Fe 预还原 + 转金属需要）；THF/2-MeTHF 溶剂；−20 °C 至室温（低温抑制均偶联与异构化）；对空气/水敏感（Schlenk）。Co：CoCl₂/dppp 或 bpy，1–5 mol%；格氏或有机锌（官能团兼容更好）；−78 °C 至 25 °C 依体系。底物：ArBr > ArCl（Fe 可活化部分 ArCl）；烷基卤兼容（自由基路径不需氧化加成的立体电子要求）。添加剂：LiCl（活化格氏、纳米颗粒稳定）、TMSCl。Mn：Mn⁰ 粉（转金属/还原）、MnCl₂ 催化（光化学用 Mn(CO)₅Br/bpy）。安全：格氏试剂强放热、自燃风险；Fe/Co 粉体可燃。

## 6. 底物范围与局限

优势底物：芳基/杂芳基溴氯（吡啶、嘧啶、噻吩——Pd 苦手的杂环 Fe/Co 常优）、烯基卤（立体化学保留/翻转依机理）、酰氯、烷基溴/氯（sp³ 自由基路径）、对碱/膦敏感的官能团（游离 NH/OH 需保护，酯/腈耐受格氏的量需控制）。局限：1) 对水分/氧气极敏感（比 Pd/硼酸体系更苛刻）；2) 格氏化学对游离质子基团不容忍（需保护基）；3) 均相/异相机理不清——重现性依赖搅拌/粒径（纳米效应）；4) 对映选择性催化有限（手性 Fe/Co 配体催化仍在发展）；5) 多余的 Fe/Co 残留需除去（药物化学关注金属杂质限度）。

## 7. 副路径与抑制策略

副路径一：Wurtz 偶联/均偶联——格氏自身氧化为 R–R（乙烷、联苯），消耗有机金属。抑制：慢加格氏/底物、低温、控制 Fe 预还原时间、使用有机锌（活性更低）替代部分格氏。副路径二：还原脱卤（ArX → ArH）——低价金属向 ArX SET 后质子淬灭。抑制：无质子溶剂/无添加酸、提高 [R–M] 浓度使转金属快于质子化、避免醇溶剂。副路径三：芳基自由基副反应——Ar• 二聚（联苯）、歧化、夺氢（来自溶剂/格氏 β-H）。抑制：低温缩短自由基寿命、大位阻配体稳定金属捕获步、溶剂选择（THF 的 α-H 可被强亲电自由基夺取——注意溶剂夺氢竞争）。副路径四：纳米颗粒失控聚沉（催化剂失活、批次差异）。抑制：配体（bpy/膦）稳定分散、LiCl 添加、控制加料速度与搅拌。副路径五：格氏加成到羰基杂质——严格无羰基溶剂与底物纯度。

## 8. 选择性控制、计算化学衔接与进展

选择性：sp²/sp³ 亲电试剂的 chemoselectivity 由 SET 电位与自由基稳定性决定（三级烷基氯 > 二级 > 一级在自由基路径）；杂环选择性（Fe/Co 对吡啶耐受优于 Pd）；立体选择性在自由基捕获步部分保留/外消旋——手性配体（PyBox、唑啉）调控中等 ee。计算化学衔接：Fe/Co 多自旋态交叉（High-spin Fe(III)↔Low-spin）用 broken-symmetry DFT/CASSCF；SET 步的驱动力用 Rehm-Weller + DFT 电位；自由基捕获能垒与自旋密度面交叉（two-state reactivity）解释选择性；纳米簇模型 vs 分子模型的 DFT 能谱对比判别催化相。近年进展：Knochel/Neuville/송 等的 Fe 偶联规模化、Co 光催化（Mn(CO)₃ 光还原）、电化学 Fe/Co 偶联（替代格氏为电子）、C–H 活化的 Fe/Co 仿生氧化、机器学习格氏兼容性预测、Ni/Fe 双金属协同。综述见 Chem. Rev. 丰产金属偶联专号与 Acc. Chem. Res.。
