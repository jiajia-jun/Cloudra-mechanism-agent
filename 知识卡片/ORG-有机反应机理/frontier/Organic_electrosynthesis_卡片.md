## 1. 反应概览

有机电合成（organic electrosynthesis）以电子作为"试剂"，在电极上直接或经介体实现氧化/还原，替代化学计量氧化剂/还原剂，是绿色化学与近十年复兴最快的前沿领域之一。奠基：Shono 氧化（1970s，N-保护四氢吡啶/吡咯烷的阳极 α-C–H 甲氧基化→内酰胺）、Kolbe 脱羧偶联、电化学还原偶联。现代框架：1) 直接电解（底物在电极表面 SET）；2) 介体电解（TEMPO、I⁻/I₂、Fe/Co 配合物做电子梭，medator 均相催化）；3) paired electrolysis——阴、阳两极同时做有用功（一极氧化底物 A、一极还原底物 B，电子经济翻倍）。典型条件：恒电流/恒电位、未分隔或分隔电解池、惰性电极（石墨、玻碳、BDD、Ni 泡沫）、支持电解质（n-Bu₄NBF₄、LiClO₄）。产率受过电位、传质、电极钝化控制，流动电解槽解决放大瓶颈。

## 2. 主机理链：Shono 氧化（阳极 α-C–H 甲氧基化）

Shono 氧化是 C(sp³)–H 电化学官能团化的原型：N-Boc-哌啶/吡咯烷在甲醇溶液、支持电解质存在下，恒流电解（石墨阳极）。机理：底物在阳极经逐步/协同的 SET 失去一个电子生成胺自由基阳离子；α-C–H 酸性因正电荷增强，甲醇作碱去质子得到 α-氨基自由基；再一次 SET 失电子得亚胺离子等价物；甲醇亲核捕获生成 α-甲氧基氨基缩醛（aminal）。产物经后处理水解为内酰胺（N-Boc-2-哌啶酮/2-吡咯烷酮）或进一步衍生化。总变化：C(sp³)–H → C–OMe → C=O（两电子氧化），阳极提供 2 e⁻，阴极 2H⁺ 放电析 H₂（或溶剂还原）。电位窗口约 +0.6~+1.2 V vs SCE（依胺结构），选择性由 N-保护基（Boc/Cbz）调控——Boc 使胺更难过度氧化。

## 3. 主机理链：介体电解与 TEMPO 循环

直接电解常受过电位与电极钝化限制，介体（mediator）在溶液中均相 SET 于底物与电极之间接力：TEMPO（2,2,6,6-四甲基哌啶氧化物）在阳极氧化为 oxoammonium（TEMPO⁺），化学选择性氧化伯/仲醇为醛/酮，自身还原为 TEMPO·（羟胺），再在电极失一电子回到 TEMPO⁺——催化循环闭合。优点：低过电位、高 chemoselectivity（不碰 C=C/其他官能团）、对映选择性可用手性 TEMPO 类似物（有限）。碘介体（I⁻ → I₂/I₃⁻ → I⁺）用于环氧化、双键碘内酯化；Fe(bpy)₃²⁺/³⁺、Fc/Fc⁺ 做温和电子梭。阴极介体（如 Co(III)/Co(II) salen）用于还原脱卤/脱羧。

## 4. 主机理链：paired electrolysis 与还原侧反应

paired electrolysis 设计让两极各司其职：例 1——阳极 TEMPO 氧化醇为酮，阴极硝基苯还原为苯胺，一池完成一对氧化/还原产品；例 2——阳极 Kolbe 脱羧偶联（RCO₂⁻ → R• → R–R），阴极同时还原另一底物。关键挑战：两极电位窗口匹配、产物在对电极的再反应（需分隔膜或选择电位）、电流效率（CE）最大化。阴极侧典型还原：C–X 还原脱卤、烯烃/羰基还原、CO₂ 电还原偶联（前沿方向）、NAD⁺ 类辅酶再生。分隔池（阳离子交换膜）防止两极产物混溶；无膜池依赖配对底物的正交电位。

## 5. 关键条件：电极、电解质与电流控制

电极：阳极——石墨、玻碳、BDD（高电位窗口、抗钝化）、镍/不锈钢（Kolbe）；阴极——Hg（历史上）、Sn、Ni 泡沫、玻碳。过电位与法拉第效率是第一约束。支持电解质：n-Bu₄NBF₄（MeCN）、n-Bu₄NOTf、LiClO₄（MeOH）、NH₄Br（兼作 I⁻ 源）；浓度 0.1–0.5 M，需溶解底物且低欧姆降。溶剂：MeOH（Shono 亲核捕获剂）、MeCN、DMF、混合水-有机（阴极析氢兼容）。电流控制：恒电流（合成规模友好，CE 用库仑计监测）；恒电位（机理研究、选择性最大化，需三电极体系）；电流密度 5–50 mA/cm²。温度：0–25 °C 常见；流动池（H-cell、filter-电极、falling-film）用于放大。计量关系：n e⁻/底物分子由库仑数换算（1 F/mol = 1 电子/底物）。

## 6. 底物范围与局限

优势底物：N-杂环（Boc-哌啶、吡咯烷、四氢异喹啉——Shono 类 α-C–H）；伯/仲醇（TEMPO 介导）；羧酸（Kolbe 脱羧、阴极还原）；富电子芳烃（阳极氧化偶联，如酚）；活化烯烃（阴极还原为自由基阴离子偶联）。局限：1) 需要导电介质，非极性底物要加支持电解质（原子经济性下降，后续要去盐）；2) 电极钝化（聚合物膜覆盖阳极，尤其富电子底物）——BDD/周期换向电流缓解；3) 电位窗口外的溶剂分解（水的析氢/析氧竞争）；4) 规模放大受传质与欧姆加热限制（流动化学解决）；5) 分析监控难（在线 IR/库仑滴定）。

## 7. 副路径与抑制策略

副路径一：过度氧化——亚胺离子/α-甲氧基产物再失电子开环生成烯胺/内酰胺混合物或低聚物。抑制：控制通过电量（停在 ~2 F/mol）、低温、换 Boc→Cbz 调电位、用流动池即时移走产物。副路径二：溶剂/电解质阳极氧化（MeOH → 甲醛、BF₄⁻ 分解）与析氧竞争，降低 CE。抑制：提高底物浓度占满电极表面、降低电流密度、选高析氧过电位阳极（BDD）。副路径三：阴极侧产物再还原/氢化（如酮还原为醇，破坏 paired 设计）。抑制：分隔膜、选择电位、产物即时萃取。副路径四：电极钝化膜（聚噻吩类/胺氧化聚合物）。抑制：机械抛光/周期反向电解、添加剂（如 LiCl 调双电层）、避免过高阳极电位。副路径五：自由基二聚（Kolbe 中 R• 偶联 vs 歧化）——控制 R• 生成速率与浓度。

## 8. 选择性控制、计算化学衔接与进展

选择性：电位是终极化学选择性旋钮——CV 图上分离的氧化峰对应分步官能团化；介体（TEMPO、I₂）把电极反应"转译"为高选择性化学反应；paired 设计要求正交电位窗口。计算化学衔接：电极过程动力学用 DFT 算中间体氧化电位（再用 ΔG = −nFΔE 换算），与 CV 实测对照；溶剂化自由能（SMD）与离子对对电位的影响大；表面机理用恒电位 DFT（slab 模型）研究 Kolbe 等电极特异反应；BDD/Ni 电极的过电位与 DFT 氢吸附能相关。近年进展：Ni/Fe 电催化交叉偶联（电化学 Kumada、电还原偶联 RAE）、光电化学耦合（光阳极串联）、CO₂/CO 电还原为 C₂+ 产物、机器学习预测电位窗口、paired 电解的工业应用（药物中间体）。综述见 Chem. Rev. / J. Org. Chem. 电化学专号。
