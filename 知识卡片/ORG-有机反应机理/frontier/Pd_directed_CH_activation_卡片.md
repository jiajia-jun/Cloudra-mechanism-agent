## 1. 反应概览

导向基（directing group, DG）策略的 Pd 催化 C–H 活化是过去十余年最活跃的 C–H 官能团化范式之一。底物上的导向基（常用 2-吡啶基、酰胺、恶唑啉、羧酸、8-氨基喹啉等）先与 Pd 中心配位，把金属"拴"在目标 C–H 键附近，再经协同金属化-去质子化（CMD）或类似路径选择性断裂 C–H 键，生成五元或六元环钯金属环（metallacycle）。随后与烯烃、卤代烃、CO、有机金属试剂等偶联伙伴反应，经插入/转金属/还原消除得到官能团化产物。典型氧化 Heck、Carbohydrazide、Hiyama/Denmark 型芳基化等都属于此框架。产率通常 50–90%，位点选择性由导向基的螯合几何（五元环 > 六元环）与底物位阻共同决定。近十年进展包括瞬态导向基（可移除的弱配位导向基）、远端 γ/δ 位 C–H 活化（通过金属环扩张）与不对称版本（手性单保护氨基酸/单保护氨基酸衍生物作瞬态配体）。

## 2. 主机理链：导向基配位与金属环形成

第一步是导向基杂原子（N/O）与 Pd(II) 中心的配位（ligand exchange / chelation），把 Pd 预组织到邻近 C–H 键的轨道取向上，形成螯环前体。此配位是可逆的预平衡，导向基的给电子能力与空间位阻决定配位常数。常用 Pd 源为 Pd(OAc)2 或 Pd(OPiv)2；羧酸根配体既帮助配位也可能直接参与后续 CMD 的碱性组分。第二步 CMD：羧酸根（AcO⁻/PivO⁻/CsOPiv）作为内碱，协同地接受 C–H 质子，同时碳与 Pd 成键——C–H 断裂与 C–Pd 形成协同发生，避免高能的自由基或分离的碳正/负离子中间体。CMD 过渡态中 Pd···C 距离约 2.1–2.3 Å，是 DFT 机理研究的核心结构。产物为稳定的五元环钯金属环（如 2-苯基吡啶的环钯化）与 HOAc。氧化态全程保持 Pd(II)/Pd(0) 或 Pd(II)/Pd(IV) 循环中的 Pd(II) 段。

## 3. 主机理链：伙伴插入与还原消除

金属环形成后，C–Pd 键对偶联伙伴进行迁移插入：对烯烃（氧化 Heck 条件下）是 migratory_insertion 进 Pd–C 键，区域选择性由电子与位阻控制，生成新的 C–C 键与扩环/开环的烷基钯。对芳基卤的 Pd(II)/Pd(0) 循环则可能走转金属或经卤化试剂的氧化加成到 Pd(IV)（当使用高价氧化剂如 PhI(OAc)2 时进入 Pd(II)/Pd(IV) 循环）。最后 reductive_elimination 从 Pd 中心释放产物并降低氧化态：Pd(IV)→Pd(II) 或（在氧化剂存在下再氧化的循环中）Pd(II)→Pd(0)。产物脱附后催化剂再生。整个循环的决速步常为 CMD 或还原消除，依配体与底物而定；这两步也是 DFT 能垒计算的重点对象。

## 4. 主机理链：Pd(0) 再氧化与催化再生

在 Pd(II)/Pd(0) 氧化 Heck 类循环中，还原消除后得到 Pd(0)，必须被计量氧化剂再氧化为 Pd(II) 才能周转。常用氧化剂：AgOAc（温和、兼容性强）、Cu(OAc)2、O2（绿色但慢）、高价碘试剂（常进入 Pd(IV)）。再氧化可以是单电子转移（Ag⁺→Ag⁰）或配体交换后歧化。选择氧化剂时要兼顾：1) 电位足够氧化 Pd(0)；2) 不氧化底物或导向基；3) 阴离子（OAc⁻）供给 CMD 碱。在电合成或光氧化变体中，电极或光催化剂可替代化学计量氧化剂，实现"无外加氧化剂"的 C–H 活化（与前沿的电化学/光氧化还原领域衔接）。

## 5. 关键条件：配体、氧化剂与溶剂

催化剂：Pd(OAc)2、Pd(OPiv)2、PdCl2/羧酸体系；载量通常 2–10 mol%。导向基类型决定底物设计：弱配位（吡啶、酰胺）适合高温 CMD；强配位（8-氨基喹啉、羧酸）可在更温和条件实现单氮配位活化并支持后续镍共催化交叉偶联（Pd/Ni 双金属）。氧化剂：AgOAc（1–2 equiv）最通用；O₂ 需高压/鼓泡；PhI(OAc)2 倾向 Pd(IV) 路径。碱/酸添加剂：CsOPiv、KOAc 提供羧酸根并促进 CMD；催化量 PivOH/AcOH 作质子穿梭。溶剂：DMAc、DMF、t-AmOH/AcOH 混合溶剂；配位性溶剂会与导向基竞争 Pd 位点，需权衡。温度典型 80–120 °C；瞬态导向基体系可降至室温–60 °C。无水无氧对 Pd(0) 路径重要（Schlenk 或手套箱操作，或原位还原稳定 Pd 纳米簇）。

## 6. 底物范围与局限

良好底物：富电子/中性芳环与杂芳环的邻位 C(sp²)–H（芳基吡啶、苯甲酰胺、苯乙酸）；部分活化的 C(sp³)–H（8-氨基喹啉酰胺的 β/γ 位、羧酸的 β 位）可在配体辅助下实现。局限：1) 强配位导向基往往需要计量或后续移除步骤（瞬态导向基策略正是为解决此点）；2) 强配位基团（如游离胺、膦）毒化 Pd；3) 电中性 sp³ C–H 的本征反应性低，远端活化产率常 <50%；4) 杂芳环的配位 N 可能与导向基竞争；5) 位阻大的邻位取代基抑制 CMD 接近。对含酸性 C–H（如吲哚 N–H、丙二酸酯）会发生竞争去质子化。

## 7. 副路径与抑制策略

副路径一：质子解金属化（protodepalladation）——金属环被质子（HOAc/溶剂）打断，回收原料而非产物，是无氧化剂或氧化剂不足时的主要损耗。抑制：确保足量 AgOAc/Cu(OAc)2，加入 CsOPiv 提高碱度，降低反应浓度减少双分子猝灭。副路径二：β-氢消除异构化——插入后烷基钯发生 β-H 消除，生成烯烃异构化混合物或直链/支链错误产物（Heck 型）。抑制：选择低温、富电子配体加速还原消除压过 β-H 消除；底物设计避开可形成稳定烯丙基钯的结构；严格无水减少 HOAc 促进的副分解。副路径三：导向基配位的二聚/催化剂聚集——高浓度或高温下 Pd 聚集成黑沉淀。抑制：低载量、慢加底物、添加催化量单保护氨基酸配体。

## 8. 选择性控制、计算化学衔接与进展

选择性：区域选择由导向基螯合几何锁定（邻位/β 位优先）；不对称 C(sp³)–H 活化用手性单保护 α-氨基酸（MPAA）配体，ee 通常 70–95%；远端活化通过环扩张与配体控制实现 γ/δ 选择。计算化学衔接：CMD 步用 DFT（如 M06/def2-TZVP，Pd 用相对论赝势）搜索六元环 CMD 过渡态，能垒 20–30 kcal/mol 与实验温度窗口一致；金属环的构象分析与还原消除能垒决定对映选择性预测（ΔΔG‡ ≈ 1–2 kcal/mol 对应 ~90% ee）。溶剂模型（SMD/DMAc）与色散校正（GD3BJ）对能垒排序重要。近年进展：电/光介导的 Pd(II)/Pd(III) 单电子 C–H 活化、双金属 Pd/Ni 串联（8-氨基喹啉导向的芳基化）、机器学习预测位点选择性。综述见 Chem. Rev. / Acc. Chem. Res. 的 C–H 活化专号。
