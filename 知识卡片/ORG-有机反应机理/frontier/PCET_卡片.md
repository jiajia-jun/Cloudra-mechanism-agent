## 1. 反应概览

质子耦合电子转移（proton-coupled electron transfer, PCET）指电子转移与质子转移协同（concerted PCET，cPCET）或紧密耦合分步（sequential PT/ET 或 ET/PT）发生的基元过程。与分开的 HAT（氢原子同步转移）或单纯 SET（仅电子）不同，cPCET 的过渡态中质子位于供体-受体键的中间位置、电子已部分转移——避免了生成高能的完全电荷分离态（如胺阳离子自由基或烷氧负离子），从而显著降低驱动力需求。生物体系（光系统 II 的酪氨酸 Z、核黄素、细胞色素 c 氧化酶）广泛使用 PCET；有机合成中的应用由 Knowles（质子穿梭/铱协同的 N–H/O–H PCET）、Nicewicz（反 Markovnikov 氧化）、Miller（多氢键 PCET）等推动，近十年成为活化 O–H、N–H、C–H、B–H 键与实现选择性氧化/偶联的前沿工具。概念上 PCET 是 HAT 与 SET 的"广义父集"：cPCET 中质子与电子来源可以是不同分子（oxidant + base），这是其区别于 HAT 的本质。

## 2. 主机理链：协同 PCET（cPCET）与热力学

cPCET 的热力学描述：对 AH + B + e⁻/oxidant → A· + BH⁺（+ oxidant⁻），总自由能由 O–H BDE、氧化电位、碱 pKa、质子亲和能组合决定——Bordwell 方程 ΔG(H•) ≈ 1.37 pKa + 23.06 E + C 将均裂 BDE 与 pKa/E 关联，cPCET 允许沿此自由能面选择性到达"半路"的自由基态而不经过完全离子态。动力学上 cPCET 用 Marcus-Hush 框架扩展：内禀重组能包含 O–H···B 键的振动与溶剂重组；氢键预组织（hydrogen-bond precomplex）降低重组能、加速 cPCET。实验判据：动力学同位素效应 KIE 大（C–H/D 2–7，O–H/D 甚至更大，反映 H 运动在 TS 中心）；Hammett ρ 值显示电荷在 TS 中分散；与单纯 SET 的线性自由能关系偏离。金属-配体协同 PCET（MLCPET）：Ir(III)–配体对 N–H/O–H 底物同时做外球电子转移 + 配体碱攫取质子（Knowles 体系），用于不对称氢化与烯烃异构化的高对映选择性。

## 3. 主机理链：酚/胺的 PCET 氧化与自由基捕获

代表性合成模式（Knowlos 型 phenol-ene 氧化胺化/环化）：富电子酚（如 2,4-二叔丁基酚）与氢键受体（Ir 配体上的吡啶酮/酰胺或外加碱）形成氢键复合物；激发态 Ir(III)*（强氧化）对酚做 SET 的同时碱攫取 O–H 质子——协同 PCET 生成苯氧自由基 + Ir(II) + BH⁺。苯氧自由基对分子内/分子间烯烃（自由基加成，5-exo/6-endo 由 Baldwin 规则与构象控制）生成碳自由基，再经第二次 PCET/HAT（从酚或 Ir(II)/Hantzsch 酯）完成氧化环化产物并再生催化剂。净结果：脱氢 [n+1] 环化、氧化偶联、去芳构化，无需计量氧化剂（光作终端氧化还原驱动）。另一模式：N–H PCET 活化胺/酰胺生成氮自由基，用于氮中心自由基环化（aza-Prins、 Hofmann-Löffler 类反应的无卤素版本）。

## 4. 主机理链：分步 SET/PT 与 PCET 的边界

分步路径：先 ET 生成 AH⁺•（或 A⁻•）再快速 PT，或先 PT 生成 A⁻ 再 ET。两者何时竞争取决于驱动力与重组能：当 AH/A• 与 AH₂⁺/AH• 的 pKa 差大（~10 单位以上）、ET 热力学不利而 PT 有利时，cPCET 占优；若底物氧化电位很低（富电子芳胺），分步 SET 可能先发生。HAT 与 cPCET 的边界：HAT 是 H 原子（e⁻+H⁺ 同源同向）从同一原子转移；cPCET 的 e⁻ 与 H⁺ 来源分子可不同（分子间 e⁻/分子间 H⁺），TS 更"不对称"。实验区分：改变碱强度而不动 H 供体——只影响 cPCET/HAT（涉及碱）不影响纯 SET；KIE 与碱浓度级数。理论区分：IRC 沿质子坐标与电子布居的演化；完全 HAT 的 TS 质子坐标位移对称，cPCET 质子可偏靠碱侧。

## 5. 关键条件：氢键网络、碱与光催化剂

氢键给体/碱：吡啶酮、酰胺、脲、磷酸盐、羧酸盐——既做质子受体又预组织 TS（Miller 的手性双脲 PCET 催化对映选择性 HAT 先例）。Knowles 不对称 PCET：手性磷酸 + Ir 配体协同，ee 80–95%。光催化剂：Ir(ppy)₂(dtbbpy)⁺、4CzIPN（有机）、曙红（需更高激发态氧化力）；E* 需匹配底物 PCET 电位（比单纯 E 更"有效氧化力"因耦合质子转移）。溶剂：极性非质子（MeCN、DCE）利于氢键复合物稳定；质子性溶剂（MeOH）竞争氢键、破坏预组织——通常避免。温度：0–40 °C；流动光反应器。计量学：cPCET 常配光催化循环，终端氧化剂 O₂ 或光子；非光的热 PCET（如 DBU/氧化剂组合）用于 N–H 活化。

## 6. 底物范围与局限

适用：酚 O–H（pKa ~10–18，易 PCET）、烯醇/1,3-二羰基 C–H、酰胺/磺酰胺 N–H、吡啶/嘧啶 N（加质子后 PCET）、富电子胺 α-C–H（PCET 脱氢）。典型转化：酚-烯氧化环化、去芳构化、胺脱氢偶联、C–H 醚化/胺化（反 Markovnikov）。局限：1) 需要合适的 pKa/电位窗口——惰性 C–H（烷烃）PCET 仍难（BDE 高）；2) 氢键网络对水与质子性杂质极敏感；3) 光催化剂激发态寿命与猝灭竞争；4) 对映选择性 PCET 限于手性氢键/离子对环境；5) 机理表征难——cPCET 与分步 SET/PT 在稳态动力学中难区分（需超快光谱、同位素标记、变碱实验联合）。

## 7. 副路径与抑制策略

副路径一：分步 SET 主导——生成完全电荷分离的离子自由基，后续化学选择性下降（如胺阳离子自由基脱质子 vs 追踪 PCET 路径的错误产物）。抑制：调节碱的 pKa（强碱推动 cPCET）、选择氢键预组织催化剂、降温放慢分步 SET。副路径二：过度氧化/苯氧自由基二聚——酚氧化偶联生成联苯醌副产物（Scholl 型）。抑制：控制氧化当量、低温、使用取代酚阻断偶联位点、快速捕获（分子内烯烃环化优先）。副路径三：氢键催化剂质子化失活（酸积累）——碱被完全质子化后 cPCET 停止。抑制：缓冲当量碱、连续流移除质子副产物、催化量碱再生设计。副路径四：光催化剂被氢键碱猝灭（非生产性猝灭）——调整 PC 结构与碱的空间位阻。副路径五：溶剂参与的 HAT（MeOH/DCM 被苯氧自由基抽氢）——换惰性溶剂（CF₃-苯、氟苯）。

## 8. 选择性控制、计算化学衔接与进展

选择性：pKa/电位匹配实现"只活化目标 X–H"（化学选择性）；手性双脲/磷酸口袋控制 H 面选择性（对映选择性）；构象锁定底物控制环化区域（Baldwin）。计算化学衔接：cPCET 的势能面用 DFT + 约束最小能量路径（质子坐标扫描）；Marcus 理论参数（重组能 λ、电子耦合 H_DA）从连续介质模型+QM/MM 提取；KIE 用 SCT/ATC 模型（small-polaron tunneling）从路径积分或 Wigner 校正计算；pKa 与 E° 的联合热力学循环（Bordwell 图）用 SMD 溶剂化自由能。多参考态（TS 自旋密度在 H 上）用 CASSCF 判别。近年进展：不对称 MLCPET 氢化（Knowles, Science 2019+）、PCET 活化酰胺 C–N、电化学 PCET（无光）、PCET 介导的 C–H/C–H 偶联、超快光谱与计算联用解析 cPCET 动力学、生物光系统 II 仿生水分解催化剂设计。PCET 已成为"能量守恒自由基化学"的统一语言。
