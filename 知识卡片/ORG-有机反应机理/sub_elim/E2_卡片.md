## 1. 反应概览

E2（bimolecular elimination）是碱协同夺取 β-H、离去基团同时离开、一步生成烯烃的双分子过程。速率 = k[RX][B]。与 SN2 竞争于同一底物；三级底物 + 强碱时 E2 几乎独占。立体电子要求严格：**β-H 与离去基 anti-periplanar（二面角 180°）**最有利；syn-periplanar 在特定环系/构象也可反应但能垒更高。典型产率 60–95%（条件优化后）。区域选择性由碱强度与底物结构共同决定：强碱/无 β-支化 → Zaitsev；大位阻碱（t-BuOK、LiTMP）→ Hofmann。Saytzeff（1875）与 Hofmann 经典规则均源于 E2 体系。

## 2. 协同过渡态与轨道

E2 TS：B···H–Cβ···Cα···LG 四中心排列，C–H 与 C–LG 键断裂与 C=C π 键形成同步。TS 可滑移：强碱/好离去基 → 早期 TS（C–H 断为主）；弱碱/差离去基 → 晚期 TS（C–LG 断为主、部分碳正离子特征）。E1cb 与 E2 是此连续谱两端：β-H 酸性极高（EWG 取代）或离去基极差时插入 E1cb 两步机理。同位素效应：E2 的 kH/kD 显著（2–7），是与 SN2 的诊断区别（SN2 的 α-KIE≈1）。二级动力学同位素效应与烯烃几何分析可量化 TS 位置。

## 3. 碱与离去基团选择

碱强度决定区域选择性与是否发生 E2：HO⁻/EtO⁻/MeO⁻ → Zaitsev 为主；t-BuOK、LDA、LiHMDS、KTrit → Hofmann（动力学去质子位阻最小的 β-H）。相转移条件（Bu₄NOH）在两相体系有效。离去基团能力与 SN2 相同序列；OTs/OMs 甚至可让一级底物在中等碱下也走 E2。溶剂：极性非质子加速阴离子碱的去质子，但可能改变离子对聚集态；质子溶剂碱被溶剂化、E2 速率下降，有时改有利于 SN1/E1（三级底物）。

## 4. 底物范围

一级：需强碱才显著 E2，否则 SN2 主导。二级：E2/SN2 拉锯，强碱位阻化 → E2 选择性↑。三级：强碱 → 纯 E2；弱碱/溶剂解 → E1+SN1。环己烷体系：anti-periplanar 要求意味着离去基与 β-H 都必须直立键（a,a-排列）——用构象分析可预测哪颗 β-H 可消除、哪颗不行；这是环己烷立体电子效应教科书核心。桥头氢无 anti-H 时 E2 受阻（Bredt 相关）。乙烯基卤不走 E2；偕二卤可双脱卤得炔（特殊 E2 型）。

## 5. 区域选择性：Zaitsev vs Hofmann

Zaitsev：生成更取代、热力学更稳的烯烃（超共轭 + 烷基给电子）。Hofmann：少取代烯烃，出现在（a）大位阻碱动力学去质子最易接近的 β-H；（b）β-支化底物；（c）离去基为 NR₃⁺/SR₂⁺ 等特殊基团。共轭烯烃（与 C=O、Ar 共轭）即使少取代也常主导——热力学压倒动力学。实验控制：换碱即换选择性，是 E2 最实用的把手。计算预测：比较不同 β-H 去质子 TS 的 ΔG‡。

## 6. 立体选择性与环系

开链底物：anti-periplanar 给 E-烯烃为主（两个大基 gauche 排布最低能量的 TS）；若唯一 anti-H 几何强制，则可得 Z-烯烃——立体专一性 E2 是合成特定几何烯烃的手段。环己烷：反式-2-卤代环己烷（卤直立）可 anti 消除；顺式异构体若无 a,a-排布则 E2 慢，可能改走 E1 或 SN1。norbornyl 等刚性环系的区域/立体选择性完全由几何锁定。与 anti-SN2 的几何要求竞争：同一构象下背面进攻与 anti-H 夺取不可兼得于同一碳，但不同构象异构体可分配到不同通道。

## 7. 副路径与抑制：SN2 与 E1cb

SN2 竞争：用大位阻碱、升高温度、降低亲核试剂亲核性可压制。E1cb 渗流：β 位有 EWG（COR、CN、NO₂、SO₂R）时碳负离子中间体可分离或动力学可见——强吸电子 + 弱离去基组合。脱卤化氢过度可得二烯/炔；控制化学计量与温度。醚/醇作副亲核体生成烷氧基取代产物。抑制策略汇总：选碱（强度/位阻）、选溶剂、选温度、预设构象（环系或底物设计锁定 anti-H）。

## 8. 计算化学衔接

E2 是双分子 TS 理论基准：M06-2X、ωB97X-D、DLPNO-CCSD(T) 均有文献；溶剂效应显著（SMD）。对称性问题：TS 近似 C_s 时可作对称性约束初猜。D 置换实验的 KIE 可用频率计算的 Ubbelohde/热力学校正预测，与实验对照验证 TS 位置。环己烷 E2：必须做构象搜索（直立/平伏离去基异构体）再找 TS，单构象结果会错。E1cb 与 E2 分界可用中间体相对 TS 的深度判定——若碳负离子极小点存在且第二步 TS 更低则为 E1cb。反应能剖面扫描 Cβ–H 与 Cα–LG 二维势能面可可视化同步性。工程上：Cloudra 工作流可用 xtb 力场/半经验预优化 TS，再 B3LYP-D3/def2-SVP 优化 + 频率 + IRC，SMD 单点。
