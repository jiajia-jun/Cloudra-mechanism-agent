# 基于氨基酸序列构建小肽三维结构工具 — 知识卡片

## 1. IUPAC原子命名规范对结构处理的重要性

计算化学工具生成的pdb结构文件中，只有原子名符合IUPAC规范时，才能被VMD正常显示二级结构或被GROMACS的pdb2gmx处理产生拓扑文件。若原子名不规范，骨架重原子名不满足要求，则后续软件无法正确识别结构信息。

---

## 2. ProBuilder在线工具构建小肽

ProBuilder是一个在线程序（网址 https://www.ddl.unimi.it/vegaol/probuilder.htm），用户输入氨基酸序列并指定phi、psi、omega角度即可生成结构文件。该程序支持多种格式，包括符合IUPAC命名规范的pdb文件，但带侧链的结构未自动优化，往往存在严重重叠。

---

## 3. GaussView生物分子库建模

GaussView提供生物分子片段库，用户可选择链中间、N端、C端的氨基酸残基片段，通过点击肽键末端逐步构建肽链。此方法可精细修改结构，但无法一次性将长序列转化为三维结构，且保存的pdb文件原子名仅含元素名，不满足IUPAC规范，也无残基名和直接的二级结构角度设置。

---

## 4. Avogadro构建并优化小肽

免费程序Avogadro（网址 http://avogadro.cc）通过Build - Insert - Peptide界面，可构建特定二级结构和序列的小肽，并保存为原子名和残基名符合IUPAC规范的pdb文件。该程序支持GAFF、MMFF94等力场进行几何优化，可消除建模后侧链的不合理接触。

---

## 5. gabedit构建多肽结构

免费程序gabedit（网址 http://gabedit.sourceforge.net）通过菜单Geometry - Draw - Build - PolyPeptide界面，可点击氨基酸按钮逐步生成特定二级结构的指定序列小肽。构建完成后可通过右键save as保存，支持包括满足IUPAC原子名和残基名规范的pdb格式。

---

## 6. AmberTools中leap构建线型小肽

AmberTools程序中的leap可根据氨基酸序列产生线型小肽三维结构并保存为符合IUPAC命名规范的pdb文件。操作命令为：输入`tleap -f leaprc.protein.ff14SB`启动并载入库，使用`TC5b = sequence { NASN LEU TYR ILE CGLN }`定义序列（其中N结尾和C开头代表端基残基），最后运行`savepdb TC5b /sob/TC5b_linear.pdb`保存结构。

---

## 7. PeptideBuilder Python库构建小肽

PeptideBuilder是一个基于Python的轻量级构建库（网址 https://github.com/clauswilke/PeptideBuilder，见PeerJ, 1, e80 (2013)），通过脚本可指定psi和phi角度及残基构建小肽。该库仅产生重原子坐标（无氢），生成的pdb文件符合IUPAC命名规范，安装命令为`pip install PeptideBuilder`。

---

## 8. PeptideBuilder构建多肽的脚本示例

使用PeptideBuilder构建含有6个谷氨酰胺的yohane.pdb文件的脚本示例如下：运行`python createQ6.py`，脚本内容为`from PeptideBuilder import Geometry; import PeptideBuilder; geo = Geometry.geometry("Q"); geo.phi = -60; geo.psi_im1 = -40; structure = PeptideBuilder.initialize_res(geo); for i in range(5): PeptideBuilder.add_residue(structure, geo); PeptideBuilder.add_terminal_OXT(structure); import Bio.PDB; out = Bio.PDB.PDBIO(); out.set_structure(structure); out.save("yohane.pdb")`。

---

## 9. CappedPeptideBuilder生成封端短肽

基于PeptideBuilder的扩展程序CappedPeptideBuilder.py（见计算化学公社帖子）可生成N端加Fmoc或ACE封闭、C端加NME封闭的pdb文件。使用方法：运行`python CappedPeptideBuilder.py -s KEYIN -p test`，会在test目录下生成ACE_KEYIN.pdb（序列为KEYIN，无氢）。

---

## 10. Tinker命令protein构建蛋白质结构

动力学模拟程序Tinker提供了根据序列建立蛋白质三维结构的命令protein，相关使用方法可参考计算化学公社论坛帖子（链接 http://bbs.keinsci.com/forum.php?mod=redirect&goto=findpost&ptid=11478&pid=79011&fromuid=1）。
