# VMD程序连接关系判断与设置 — 知识卡片

## 1. VMD自动判断连接关系的规则

当VMD载入pdb、xyz、gro等格式的结构文件时，程序会自动根据两个原子间距离以及这两个原子半径之和来判断连接关系。具体来说，若原子间距离小于两个原子半径之和的0.6倍就会被VMD视为成键。原子半径是VMD内置的，大部分是Bondi范德华半径。
- 引用：《谈谈原子间是否成键的判断问题》（http://sobereva.com/414）

## VMD内置原子半径的修改
元素的默认半径没法在VMD图形界面里或配置文件里改，但载入结构后可以通过命令行改特定原子的半径。
- 注意事项：本文内容对应于VMD正式版1.9.3

## VMD中鼠标手动添加或删除键
如果两个原子间没有被判断为成键，希望让它们之间显示键，就选择Mouse - Add/Remove Bonds，然后点击这两个原子的正中心，它们就连上了。如果你点击两个已经成键的原子，它们之间的键就会被去掉。
- 操作步骤：Mouse - Add/Remove Bonds，点击两个原子的正中心

## VMD中原子标签的隐藏与删除
在你点击原子时，VMD会自动给你点击的原子加上标签并显示在图上，如果不想显示，就按键盘上的1键，再点击有标签的原子，标签就被隐藏了。如果要把一批标签都隐去或者彻底删掉，就进入Graphics - Labels，按住鼠标左键选中一批，然后点Hide按钮就可以隐藏，点Delete按钮就可以删掉。

## 批量删除VMD原子标签的快捷命令
对于Windows版VMD，可以在VMD目录下的vmd.rc里加入如下内容，启动VMD后，随时可以在文本窗口里输入自定义命令da来删除所有原子标签。
- 代码：
```tcl
 proc da {} {
  label delete Atoms all
  }
```

## 使用DynamicBonds方式实时判断成键
如果有很多同类的键连接关系判断不符合要求，可以在Graphics - Representation界面里把Drawing Method改为DynamicBonds，这代表基于当前结构实时判断成键并显示，判断阈值可以用旁边的Distance Cutoff控件来修改。
- 缺点：不显示原子球，而只显示键，且键是空心的

## DynamicBonds配合VDW显示原子球
为了让原子球也显示出来，可以在使用DynamicBonds的同时，点Add Rep增加一个Representation，把Drawing Method设成VDW，并且把Sphere Scale改小到合适。
- 操作步骤：Add Rep -> Drawing Method设为VDW -> Sphere Scale改小

## 针对不同区域设置不同连接关系显示
有时调节Distance Cutoff会让部分连接满足要求但另一部分不符，此时需要灵活变通，多设几个Representation。每个Representation都用恰当的选择语句选定绘制的区域，并用恰当的Drawing Method和参数设定，从而让显示出的效果叠加起来正好满足要求。
- 参考：《VMD里原子选择语句的语法和例子》（http://sobereva.com/504）

## 利用AMBER/NAMD拓扑文件确定连接关系
AMBER、NAMD的拓扑文件都可以被VMD载入，载入的时候就相当于提供了连接关系了，之后再往这个ID里载入结构文件或轨迹时也因此都是按照拓扑文件里的连接关系来显示。

## 利用插件载入GROMACS tpr文件获取连接关系
VMD虽然不能载入GROMACS的拓扑文件，但是如果安装了提供的tpr插件（http://bbs.keinsci.com/thread-37839-1-1.html），载入GROMACS的tpr时也会从中读取正确的连接关系。

## 利用mol2文件自带的连接关系信息
mol2格式文件带了连接关系段落，VMD载入mol2格式文件的时候，不会自动根据结构来判断连接关系，而是直接用文件里的连接关系。用文本编辑器打开它，会看到@<TRIPOS>BOND字段，这部分记录的是键的形式，诸如5 3 27 2就代表这是第5号键，对应3与27原子间的双键。
- 参考：《谈谈记录化学体系结构的mol2文件》（http://sobereva.com/655）

## VMD对pdb文件CONECT字段的处理
pdb格式里有个CONECT字段记录连接关系，但是VMD并不会采用这里的连接关系。如果想让VMD直接利用这里的连接关系，需参考《使VMD根据pdb文件中的CONECT字段设定原子连接关系》（http://sobereva.com/121）。
- 注意事项：mol格式也有连接关系，但VMD不能载入

## 借助GaussView生成符合预期的mol2文件
GaussView可以保存mol2格式的文件，里面的连接关系信息正对应于你在GaussView图形界面里当前看到的。因此，可以先让GaussView正确显示出你期望的连接关系，保存成mol2文件，再用VMD读取，此时VMD里显示的连接关系就和GaussView里精确一致了。

## VMD中多重键的显示限制
VMD里没法以GaussView的风格来显示双键、三键等成键形式。载入记录了双键的mol2文件时，在VMD的Line、CPK、Licorice显示风格下看起来和单键一样。VMD的Bonds显示风格能区分形式键级，但双键和三键分别是以两个、三个套筒形式显示的，非常难看。

## 保存VMD修改后的连接关系为mol2文件
你在VMD里通过Add/Remove bonds把连接关系改合适后，可以通过File - Save coordinate功能保存成mol2文件，以便以后再次显示时免得再修改一遍。

## 动力学轨迹播放时连接关系错乱的原因
载入动力学轨迹后播放时成键方式可能连得乱七八糟，甚至跨越盒子。这是因为连接关系要么是从拓扑文件里读取的，要么是载入结构文件时自动判断的，或者是根据轨迹文件的第一帧结构判断的，之后再载入轨迹或播放轨迹时都不会改变连接关系。由于动力学过程中分子解离、异构化或周期边界条件，内存里的连接关系列表可能对于轨迹的某些帧并不适用。

## 使用DynamicBonds解决轨迹显示连接问题
像轨迹播放时连接关系错乱的情况，可以用DynamicBonds显示方式，这样就会按照当前帧的坐标实时判断成键并显示。
- 注意：并不会改写内存里的连接关系列表

## 轨迹播放中实时更新内存连接关系
如果在播放轨迹时想用其它显示方式（非DynamicBonds），就得让VMD根据当前这一帧的结构重新判断连接关系并改写内存里的连接关系列表，做法是在文本窗口输入命令。
- 命令：**mol bondsrecalc all; topo retypebonds**

## 显示当前内存中的连接关系列表
如果你想把当前内存里的连接关系列表以文本方式显示出来，就在文本窗口输入命令。输出的信息是个列表，里面共有对应体系原子总数的成员，体现的是连接关系，而非键级。
- 命令：[atomselect top all] getbonds

## 从自定义列表读取连接关系
连接关系也可以从自行提供的列表里读取，通过运行命令把当前体系的连接关系改成列表所定义的。
- 命令示例：[atomselect top all] setbonds {{1 2 3 4 7} 0 0 0 {5 6 7 0} 4 4 {4 0}}
