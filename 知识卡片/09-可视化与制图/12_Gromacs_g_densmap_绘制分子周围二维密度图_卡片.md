# Gromacs_g_densmap_绘制分子周围二维密度图 — 知识卡片

## 1. g_densmap生成平面投影密度图

Gromacs的g_densmap工具可以将体系中某个组粒子的出现密度投影到一个平面上。使用-aver参数设定投影轴（默认为z，可选x或y），投影面即垂直于该轴的平面。参数-xmin和-xmax用于设定该轴上的指定坐标范围，仅将该范围内的粒子投影到平面上，最终生成.xpm格式的图。

---

## 2. g_densmap生成轴向-径向密度分布图

g_densmap可以制作轴向-径向密度分布图，需用-rmax定义径向最大距离，-amax定义轴向最大范围。操作中需定义三个组，第一组质心指向第二组质心的方向作为轴方向，两者中点为零点；第三组为求密度的组。结果xpm图的横坐标为轴向位置，纵坐标为径向距离，颜色代表密度，即不同高度位置垂直于轴的平面的径向分布函数。

---

## 3. 计算分子周围二维密度的旋转预处理方法

g_densmap仅能沿x、y、z轴投影，不能自定义方向。为了获得平行于苯环平面的密度图（如磷酸化酪氨酸附近钠离子密度），需在轨迹拟合前旋转分子。使用VMD的mouse-move-residue功能，按住shift拖动鼠标旋转分子，使苯环与某两个坐标轴组成的平面（如yz平面）平行，然后保存为新的pdb文件。

---

## 4. VMD绘制空间坐标轴辅助对齐

在VMD中旋转分子时难以通过左下角坐标轴判断对齐情况，可在控制台运行绘图命令生成自定义参考轴。命令示例包括：draw color red; draw cylinder { 0 0 0 } { 80 0 0 }; draw cone { 80 0 0 } { 85 0 0 } radius 4 resolution 20。绘制出的xyz轴0点即为真实空间0点，也可改至分子附近位置。

---

## 5. 轨迹拟合与坐标范围设定

使用trjconv将轨迹向旋转后的结构进行拟合，以目标分子（如磷酸化酪氨酸）组作为参考组。运行g_densmap前需用VMD估算合适的坐标范围，例如苯环平面上下几埃区域。运行命令示例：g_densmap -f A.xtc -s A.pdb -aver x -xmin 4.2 -xmax 4.8，组分别选择钠离子和磷酸化酪氨酸。

---

## 6. 叠加密度图与分子结构

为了在钠离子密度分布图上定位分子位置，需同时生成磷酸化酪氨酸组的密度分布图。使用xpm2ps将两个.xpm图转换为.eps格式，再用Photoshop等软件将两张图叠加。调整磷酸化酪氨酸结构图的大小，使其苯环部分与密度图中的位置重合，从而实现分子结构在密度图上的可视化定位。
