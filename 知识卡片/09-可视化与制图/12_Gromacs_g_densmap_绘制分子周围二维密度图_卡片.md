# Gromacs_g_densmap_绘制分子周围二维密度图 — 知识卡片

## 1. g_densmap生成轴向-径向密度分布图

g_densmap可以制作轴向-径向密度分布图。需使用-rmax定义径向最大距离，-amax定义轴向最大范围。需要定义三个组，前两个组的质心确定轴的方向（第一组指向第二组），中间点为零点，第三个组为求密度的组。输出xpm图的横坐标为轴位置，纵坐标为径向距离，颜色代表密度。
## VMD绘制XYZ坐标轴辅助对齐
VMD左下角坐标轴不易对照，可在控制台运行命令绘制自定义坐标轴。命令包括绘制红、绿、蓝三色圆柱体和圆锥体，起点为{0 0 0}，终点分别为{80 0 0}、{0 80 0}、{0 0 80}，圆锥半径4，分辨率20。这有助于在旋转分子时判断是否与坐标轴平面平行。
## 分子旋转与坐标系对齐操作步骤
若需将粒子密度投影到分子（如苯环）平面，需先将分子旋转至与坐标轴平面平行。在VMD中使用mouse-move-residue模式，按住shift拖动鼠标旋转分子（例如使苯环与yz平面平行）。旋转完成后使用save coordinate保存为新pdb文件。
## g_densmap计算指定坐标范围的二维密度
g_densmap可将粒子密度投影到垂直于特定轴的平面上，-aver设定轴（默认z，可选x、y），-xmin和-xmax设定该轴上的投影坐标范围。对轨迹fit后，运行g_densmap -f A.xtc -s A.pdb -aver x -xmin 4.2 -xmax 4.8，并分别选择钠离子组和磷酸化酪氨酸组计算密度。
## 密度分布图与分子结构叠加定位
将钠离子和磷酸化酪氨酸的密度分布图分别由xpm2ps转为.eps格式。使用Photoshop等软件打开两张图并叠加，以磷酸化酪氨酸密度图为定位参考。将磷酸化酪氨酸分子结构图复制过来，调整大小使苯环与密度图中的苯环位置重合，从而得到分子周围粒子的二维密度分布。
