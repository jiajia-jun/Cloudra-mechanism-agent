## 1. VMD分子质心连线绘制脚本原理
该脚本首先计算体系中唯一的残基数量，随后遍历每个残基计算其质心坐标并存储在数组中，同时在质心位置绘制圆球。脚本接着循环遍历每一对残基，如果两者的质心距离小于设定的阈值，则调用draw cylinder命令在两个质心之间绘制圆柱进行连线。
- 脚本包含两个主要循环：第一个循环计算质心并画球，第二个循环判断距离并画圆柱。

---

## 2. 计算质心并绘制圆球的代码段
使用`measure center $sel weight mass`命令计算残基的质心，并将x、y、z坐标分别存入数组，同时在质心位置使用`draw sphere`命令绘制圆球。
```tcl
set nres [llength [lsort -unique [[atomselect top all] get residue]]]
for { set ires 1 } { $ires <= $nres } { incr ires } {
set sel [atomselect top "resid $ires"]
set COM [measure center $sel weight mass]
set x($ires) [lindex $COM 0]
set y($ires) [lindex $COM 1]
set z($ires) [lindex $COM 2]
draw sphere "$x($ires) $y($ires) $z($ires)" radius 1.5
$sel delete

---

## 3. 判断距离阈值并绘制连线的代码段
通过双重循环计算不同残基质心间的欧几里得距离，若距离小于变量`crit`的值，则使用`draw cylinder`命令在两个质心坐标点之间绘制圆柱。
```tcl
set crit 10
for { set ires 1 } { $ires <= $nres } { incr ires } {
for { set jres [expr $ires+1] } { $jres <= $nres } { incr jres } {
set dx2 [expr ($x($ires)-$x($jres))**2]
set dy2 [expr ($y($ires)-$y($jres))**2]
set dz2 [expr ($z($ires)-$z($jres))**2]
set dist [expr sqrt($dx2+$dy2+$dz2)]
if { $dist<$crit } {
draw cylinder "$x($ires) $y($ires) $z($ires)" "$x($jres) $y($jres) $z($jres)" radius 0.5

---

## 4. 脚本参数自定义方法
连线阈值默认为10埃，可通过修改`set crit`后的数值进行调整；若不显示圆球，需在`draw sphere`行首添加#号注释掉；圆球和圆柱的半径分别通过`draw sphere`和`draw cylinder`命令末尾的`radius`参数控制，颜色通过命令上方的`draw color`后的颜色名控制。
- 重新执行修改后的脚本会自动删除之前的图形并按当前帧结构重新绘制。
