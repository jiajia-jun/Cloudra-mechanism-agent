## 2. VMD脚本alignbond的定义
在VMD控制台中定义alignbond过程，该过程接收两个原子序号作为参数，通过计算这两个原子的坐标差值得到矢量，然后利用transvecinv函数将整个分子体系移动，使连接这两个原子的矢量平行于X轴。
proc alignbond {ind1 ind2} {
set atm1 [atomselect top "serial $ind1"]
set atm2 [atomselect top "serial $ind2"]
set vecx [expr [$atm2 get x] - [$atm1 get x]]
set vecy [expr [$atm2 get y] - [$atm1 get y]]
set vecz [expr [$atm2 get z] - [$atm1 get z]]
set sel [atomselect top all]
$sel move [transvecinv "$vecx $vecy $vecz"]

---

## 3. VMD脚本alignbond的使用方法
执行alignbond脚本后，在VMD控制台输入alignbond加上两个原子序号（例如alignbond 4 9），即可让4号和9号原子定义的键或连线平行于X轴，操作完成后通过file-save coordinate菜单保存坐标文件。
- 示例命令：alignbond 4 9
- 原子说明：这两个原子可以没有实际成键，仅用于定义连线的矢量

---

## 4. VMD中绕坐标轴旋转分子
如果需要让键平行于Y轴或Z轴，先使用alignbond将其平行于X轴，然后选中所有原子并执行绕轴旋转命令；例如输入`$sel move [transaxis z 90]`可让体系绕Z轴旋转90度，通过改变轴名和角度可调整键的最终方向。
- 旋转命令格式：`$sel move [transaxis x/y/z 角度]`
- 示例命令：`set sel [atomselect top all]`，`$sel move [transaxis z 90]`
