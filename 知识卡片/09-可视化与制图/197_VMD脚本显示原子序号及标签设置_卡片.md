## 1. 手动显示原子序号的操作步骤
按数字键1依次点击打算显示原子编号的原子，进入Graphics-Labels选中所有条目，点击Properties标签页，在Format框里面输入%i。标签位置可通过拖动Properties标签页里Offset里的十字进行调整。
- 在Global Properties标签页里可以设文字大小和粗细
- 在Graphics-Colors里的Categories选择Labels，Names选择Atoms，再选择一种颜色可修改文字颜色

---

## 2. 批量显示原子序号的脚本命令
proc atmlab {range id} {
set sel [atomselect $id $range]
set k 0
foreach i [$sel list] {
label add Atoms $id/$i
label textformat Atoms $k { %i }
label textoffset Atoms $k { -0.11 -0.0055 }
incr k
$sel delete
label textsize 1.2
- 若想让所有ID为3的体系的原子编号都显示，输入atmlab all 3
- 若想让只有在34号原子的5埃范围以内的原子的标签显示，输入atmlab "within 5 of index 34" 3

---

## 4. 自定义原子标签显示格式
如果想让元素名和原子编号同时显示，则把%i改为%e%i。如果想让原子编号从1开始而非从0开始，把%i改为%1i。

---

## 5. 快捷显示顶层分子原子序号的命令
proc lab {} {
atmlab all [molinfo top]
运行lab就会把top的体系的原子编号都显示。

---

## 6. 显示原子序号的功能限制
虽然用如上方法可以显示出原子编号，但是如果用CPK之类方式显示，就会把原子标签给覆盖掉。而且标签大小没法随视角的远近变化自动缩放。
