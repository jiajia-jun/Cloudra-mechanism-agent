## 1. 修改 Gaussian cube 文件中原子坐标

有时出于特定需求，需要修改 cube 文件中的分子几何结构（原子坐标）。利用 Python 脚本可以将指定的坐标替换到现有的 cube 文件中，从而生成新的 cube 文件。

---

## 2. 修改 cube 文件的准备步骤

修改 cube 文件前需要准备两个核心文件：包含待修改数据的源 cube 文件（例如命名为 abc.cub）和包含目标分子结构的 Gaussian 输入文件（例如命名为 xyz.gjf）。这两个文件将作为脚本运行的输入。

---

## 3. 修改 cube 文件的工具文件位置

必须将脚资料件 modcube.py 与上述的 cube 文件（abc.cub）及 Gaussian 输入文件（xyz.gjf）放置在同一个目录下，以确保脚本能够正确读取和写入文件。

---

## 4. 修改 cube 文件的命令行操作

执行该操作需要预先安装 Python 并将 Python 添加到系统环境变量中。在命令行中运行以下命令即可完成坐标修改：
- python modcube.py abc.cub xyz.gjf

---

## 5. 修改 cube 文件的输出结果

脚本运行成功后，会生成一个名为 output.cube 的文件。该文件即为包含了新原子坐标的修改后 cube 文件。
