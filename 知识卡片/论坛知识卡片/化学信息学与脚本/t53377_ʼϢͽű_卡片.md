## 1. PBS与Slurm作业状态通知问题

在PBS或Slurm调度系统中，作业何时开始和结束通常通过邮件通知，但邮件系统配置限制常导致通知发送失败。推送通知平台如Gotify、Bark等可替代邮件系统，实现移动端实时接收作业状态信息。不同平台的通知机制类似，只需在脚本中修改对应的curl命令和API地址即可。

---

## 2. Gotify通知平台简介

Gotify是一个自托管的通知平台，配合Android客户端使用，适合自行搭建消息推送服务。若不熟悉服务器搭建，可使用Docker平台如ClawCloud进行一键部署。

---

## 3. 其他推送通知平台选择

除Gotify外，PushPlus可将消息发送至微信，每天有免费额度；Pushover、Server Chan、ntfy等平台也提供丰富功能。使用不同平台时，需修改脚本中的curl命令以匹配对应的API接口。

---

## 4. PBS作业脚本集成通知代码

在PBS作业脚本中，通过执行外部脚本获取起始时间，并在主任务执行后调用完成通知脚本，传入起始时间和任务退出状态码。
- start_time=$(bash start_inform.sh)
- # === 文件执行 ======================
- g16 < DME-opt.gjf > DME-opt.log
- # ========================================
- bash complete_inform.sh $start_time $?

---

## 5. Gotify作业开始通知脚本

start_inform.sh脚本用于记录作业开始时间，并通过curl命令向Gotify服务器发送包含作业ID和开始时间的JSON格式通知。使用前需修改脚本中的服务器地址和token参数。
- curl -X POST "https://gotify.your_server.com/message?token=your_token" \
- -H "Content-Type: application/json" \
- --data '{
- "title": "PBS Job started",
- "message": "'"Job ID: ${PBS_JOBID}\n开始时间: ${start_time_str}"'",
- "priority": 3
- }' >>/dev/null 2>&1

---

## 6. Gotify作业完成通知脚本

complete_inform.sh脚本接收作业退出码和起始时间，计算持续时长，判断任务执行状态（成功或异常），并调用curl命令发送详细通知。使用前需修改服务器地址和token参数。
- if [ $job_exit_code -eq 0 ]; then
- status="✅ 正常结束"
- else
- status="❌ 异常退出(exit code: $job_exit_code）"
- fi
- curl -X POST "https://gotify.your_server.com/message?token=Your_token" \
- -H "Content-Type: application/json" \
- --data '{
- "title": "PBS Job Completed",
- "message": "'"Job ID: ${PBS_JOBID}\n状态: ${status}\n开始时间: ${start_time_str}\n结束时间: ${end_time_str}\n耗时: ${duration_fmt}"'",
- "priority": 3
- }'

## 7. Bark App通知平台简介

Bark App适用于iOS生态系统，可将通知推送到iPhone，方便在移动端接收计算任务状态。

---

## 8. Bark作业开始通知脚本

针对iOS的Bark平台，start_inform.sh脚本通过curl发送POST请求，包含作业ID和开始时间。使用前需修改服务器地址和device_key参数。
- curl -X POST \
- -H "Content-Type: application/json" \
- -d '{
- "title": "PBS Job Started ",
- "body": "'"Job ID: ${PBS_JOBID} \n开始时间: ${start_time_str} "'",
- "device_key": "your_key",
- "badge": 1,
- "sound": "minuet.caf",
- "icon": "https://example.com/icon.png"
- }' \
- "https://bark.your_server.com/push" >>/dev/null 2>&1

---

## 9. Bark作业完成通知脚本

针对iOS的Bark平台，complete_inform.sh脚本计算任务耗时并判断状态，通过curl命令将包含状态、时间和耗时的详细信息推送到设备。使用前需修改服务器地址和device_key参数。
- curl -X POST \
- -H "Content-Type: application/json" \
- -d '{
- "title": "PBS Job Completed ",
- "body": "'"Job ID: ${PBS_JOBID}\n状态: ${status}\n开始时间: ${start_time_str}\n结束时间: ${end_time_str}\n耗时: ${duration_fmt}"'",
- "device_key": "your_key",
- "badge": 1,
- "sound": "minuet.caf",
- "icon": "https://example.com/icon.png"
- }' \
- "https://bark.your_server.com/push"
