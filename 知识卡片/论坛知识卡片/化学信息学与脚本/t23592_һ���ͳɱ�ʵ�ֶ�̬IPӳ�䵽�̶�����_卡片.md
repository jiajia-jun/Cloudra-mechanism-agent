## 1. DDNS 定义与作用

DDNS (Dynamic DNS) 是一种将动态变化的公网 IP 地址映射到一个固定域名的服务机制。当公网 IP 发生变化时，DDNS 服务会自动更新解析记录，确保通过固定的域名即可访问设备。通常家用或实验室网络的公网 IP 是动态的，会随重启或时间推移而改变，而静态 IP 则不会变化且价格较高。

---

## 2. 脚本语言与运行环境要求

该 DDNS 更新脚本使用 Python 3 编写。脚本已在 Python 3.7.1、3.7.5 和 3.7.9 版本下测试通过，建议使用 3.x 系列版本。

---

## 3. 操作系统与硬件要求

脚本需在一台安装有 CentOS 系统且能够 7x24 小时开机运行的服务器上执行。虽然脚本基于 CentOS 的计划任务编写，但在其他 Linux 发行版上也可兼容使用，仅需根据实际情况调整部分命令。服务器必须处于内网环境，且仅能针对内网中的 IP 进行操作。

---

## 4. 必需的 Python 依赖包

使用脚本前需安装阿里云 DNS 相关的 Python SDK。安装命令为 `pip3 install aliyun-python-sdk-alidns` 和 `pip3 install aliyun-python-sdk-core-v3`。

---

## 5. 准备公网 IP 与路由器设置

实现 DDNS 的前提是拥有一个公网 IP。若当前网络环境无公网 IP，可联系网络运营商（如电信、联通）申请开通公网 IP（可能称为“公网IP”或“动态公网IP”）。若路由器使用 PPPoE 拨号，建议直接在路由器上进行拨号，这通常比在电脑上拨号更稳定，且便于后续配置端口映射。

---

## 6. 路由器端口映射配置

需在路由器后台设置端口映射（虚拟服务器），将路由器的公网 IP 及特定端口（如 80、22）映射到内网服务器的 IP 及对应端口。配置完成后，可通过 `公网IP:端口` 的方式访问内网服务。Linux 用户可使用 Xshell 等工具连接，Windows 用户可使用 Microsoft Remote Desktop 进行远程连接测试。

---

## 7. 查看本机 IP 地址

在 Linux 终端下可使用 `ifconfig` 命令查看当前的网络接口信息，包括内网 IP（如 192.168.1.xxx）和网关地址（如 192.168.1.1）。

---

## 8. 获取域名解析记录 ID

首先在阿里云域名解析控制台添加或找到需要更新的 A 记录（如 www），记录类型为 A，记录值填写一个初始 IP。随后访问阿里云 API 调试页面，输入参数 DomainName（域名）和 RRKeyWord（主机记录，如 www），点击发起请求。在返回的 JSON 格式数据中查找 `"RecordId"` 字段对应的数值并记录。

---

## 9. 获取阿里云 AccessKey

访问阿里云 AccessKey 管理页面创建 AccessKey。系统会进行安全提示，确认后即可查看并记录 `accessKeyId` 和 `accessSecret`，这两个参数是脚本调用 API 的凭证。

---

## 10. 脚本参数配置与执行

使用文本编辑器（如 vi）打开 `updateip.py` 文件，需修改其中的关键参数：第一行路径改为服务器上 python3 的实际路径（可通过 `which python3` 查询）；第 11 行 `accessKey` 列表填入获取的 ID 和 Secret；第 12 行 `RecordId` 填入解析记录 ID；第 13 行 `RR` 填入主机记录（如 www）。配置完成后保存并将文件上传至服务器。

---

## 11. 设置计划任务（每分钟执行）

使用 `crontab -e` 命令编辑系统计划任务。添加一行任务 `*/1 * * * * /usr/local/anaconda3/bin/python3 /your_path/updateip.py`，其中第一个路径为 python3 可执行文件路径，第二个路径为脚资料件路径。此设置表示每分钟执行一次脚本。

---

## 12. 检查任务运行状态与日志

计划任务运行后，可通过查看当前用户的邮件日志来确认脚本是否报错。使用命令 `vi /var/spool/mail/当前用户` 打开日志文件，检查是否有错误信息输出。

---

## 13. 优化计划任务频率与日志屏蔽

为避免每分钟执行产生大量邮件日志，可将执行频率调整为 5 分钟一次，并将输出重定向到 `/dev/null` 以屏蔽邮件通知。修改后的计划任务命令为 `*/5 * * * * /usr/local/anaconda3/bin/python3 /your_path/your_file.py >/dev/null 2>&1`。
