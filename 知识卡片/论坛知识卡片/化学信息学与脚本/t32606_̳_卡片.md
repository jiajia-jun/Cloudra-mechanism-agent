## 3. 目标函数定义与数据采样示例

教程以 Python 编写余弦函数 `func(x) = cos(x` 为例演示模型训练。数据采样区间设定为 `[0, 4]` 和 `[6, 8]`，数据点数量 `data_num` 设定为 500。由于取步长时通常只能获取 499 个数据点，该数量差异对后续参数优化影响较小。

# 先定义x的区间为0-4和6-8，然后将在这些区间上均匀采样
intervals = [[0, 4], [6, 8]]

## 5. 训练过程与损失函数原理

训练过程涉及 n 个训练数据，每个数据包含 x 值和对应的 y_label 值 (即 `y_label = func(x)`)。模型接收 n 个 x 输入后输出 n 个 y_model_output，通过计算 y_label 与 y_model_output 之间的平均平方误差得到 Loss 值。利用反向传播计算梯度公式，将误差传递回模型参数，使模型通过学习不断调整参数，从而使模型输出逐渐逼近真实标签。

## 7. 模型泛化能力测试

为了测试模型的泛化能力，在 `[0, 8]` 范围内重新生成 100 个 x 值作为测试输入。将模型预测值与真实 `func` 函数值进行对比可视化。结果显示，在训练数据覆盖的区域 `[0, 4]` 和 `[6, 8]` 上，模型预测值与真实值吻合度很高；而在未被训练数据覆盖的区域 `[4, 6]` 上，预测结果出现明显偏差，准确度低于训练覆盖区域。

## 8. 模型参数调整经验

尝试替换 `func` 函数或改变训练参数时，可以通过调整模型的 width (宽度) 和 depth (深度) 来优化结果。调整的总体目标是使 loss 值尽可能低。
调整经验如下：
1. **batch_size**：每次迭代使用的样本数。通常该值越大，训练效果和模型效果越好。但 batch_size 越大，占用的内存/显存越多，可能导致内存溢出 (OOM)。
2. **网络规模**：函数越复杂，通常需要越大的 width 和 depth (即网络参数量越大)，需要的训练时间也越长。对于一般训练任务，width 设为 2~40，depth 设为 2~4 已经足够。
3. **优化策略**：当 loss 无法下降时，应首先考虑增加训练数据，其次再考虑增加模型规模。
4. **训练停止判断**：实际应用中通常将数据集分为训练集和验证集 (本示例未实现)。若训练集和验证集上的 loss 均不再下降，可视为模型训练完成。

## 9. 计算化学数据转换原理

在将机器学习应用于量子化学或深势函数模型时，可以将体系的图像 (如分子构型图片、分子类别) 转换为向量数据，或者将位置、种类等信息直接作为模型输入，从而实现向量化转换。Deepmd-kit 将原子的局域环境作为特征描述符，输出量包括体系 energy、每个原子的 force 和体系的 virial。不同于传统第一性原理 (DFT) 计算必须基于整个体系进行，Deepmd-kit 仅基于原子局域环境计算性质，因此可以通过计算单个原子的能量来叠加得到整个体系的能量。在保证精度的前提下，利用 Deepmd-kit 计算大规模体系时，计算量远低于直接使用 DFT 方法计算。

---

## 10. 数据集覆盖的重要性与自动化生成工具

实际应用中观察到，模型在训练集覆盖的数据范围内 (如 `[0, 4]` 和 `[6, 8]`) 表现良好，但在未覆盖区域 (如 `[4, 6]`) 性能会显著下降。因此，训练模型时非常重要的一点是准备一个局部足够稠密且覆盖范围广泛的数据集，以确保模型在整个构型空间内都能保持良好的精度。Deepmd-kit 生态中有一个名为 dpgen 的工具，可以自动寻找模型未覆盖的构型区域并生成补充数据。后续教程将详细介绍这些工具的原理与使用方法。
