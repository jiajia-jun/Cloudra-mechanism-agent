## 1. Schrödinger 与 Multiwfn 联用生成 RESP 原子电荷

结合 Schrödinger 软件包中的 Jaguar 模块和 Multiwfn 程序的 RESP 电荷生成功能，可以编写脚本实现 RESP 原子电荷的自动化计算流程。该流程包含结构优化、波函数分析以及后续的 ESP 拟合和电荷对称性等效处理等步骤，能够无需手动指定原子的限制和约束条件。此脚本利用相关软件的命令行接口完成从输入结构到最终 RESP 电荷的连续计算。
- 需参照相关教程或说明文档进行脚本的具体部署与运行。
- 涉及工具：Jaguar, Multiwfn

## 2. 环境模块加载命令

在安装了 Lmod 模块系统的计算集群环境中，可以使用 module load 命令加载所需的软件环境。
- `module load schrodinger multiwfn`
- 该命令用于将 Schrödinger 和 Multiwfn 软件添加至当前用户环境路径中。

## 3. 联用脚本运行语法

执行名为 run_jaguar_resp.py 的自定义 Python 脚本，需要提供分子结构文件、结构文件名以及使用的 CPU 核心数作为输入参数。运行时需调用 Schrödinger 软件包中的 run 命令作为前缀。
- `run ./run_jaguar_resp.py h2o.sdf 1`
- run：Schrodinger 软件包中的启动命令。
- run_jaguar_resp.py：编写的自动化脚资料件名。
- h2o.sdf：输入的分子结构文件（SDF 格式）。
- 1：计算时使用的 CPU 线程数。

## 4. RESP 原子电荷计算的前置要求

使用该脚本进行 RESP 原子电荷计算之前，必须确保输入的分子结构已经完成了几何构型优化。未优化的结构可能会导致计算结果不准确或流程报错，因此需要在运行脚本前针对特定体系进行专业的结构优化处理。
- 建议使用专门的量子化学计算模块进行前期的几何优化。
