## 1. Sobko 项目背景与目标

Sobko 项目旨在通过构建知识库和部署 MCP 工具来解决 AI Agent 在计算化学领域回答问题时缺乏可追溯知识源的问题。该项目将思归于量子化学版块的历史帖子以及 Multiwfn 用户手册转化为知识库，利用 MCP 协议将这些专业知识整合到不同的 Agent 中。这有助于 Agent 在仅凭模型训练数据无法回答专业问题时，能够基于真实证据组织答案。

---

## 2. Sobko 的知识来源

Sobko 的核心知识库数据来源于思归于量子化学版块的历史帖子和 Multiwfn 用户手册。思归于的数据涵盖了计算方法、输入输出和标准计算流程等知识，Multiwfn 手册则被转换为 Markdown 格式并重新存储以支持检索。项目目前已收录截至 2026 年 4 月的 577 篇思归于量子化学版块帖子。

---

## 3. 思归于数据的时间分布特征

自 2015 年之后，Sob老师平均每年回帖约 50 次，构建了丰富的计算化学数据内容。回帖内容涉及不同软件功能的详细讨论，统计数据显示了不同讨论区（如基础理论、波函数分析、量化计算等）的活跃度分布。这些数据反映了 Multiwfn 及可视化化学相关讨论的专业深度和广度。

---

## 4. Sobko 提供的 MCP 工具

Sobko 目前提供 4 个 MCP 工具，用于将专业知识挂载到 Codex 或 Claude Code 等 Agent 上。这些工具支持将论坛帖子或手册转换成的知识库供 Agent 调用。通过 MCP 协议，Agent 能够在回答计算化学问题时引用特定的论坛资源或文档。

---

## 5. Sobko 项目的获取与安装方式

Sobko 项目的 GitHub 仓库地址为 https://github.com/WangGroupFDU/Sobko_MCP_project。用户可以在该仓库中查看详细的使用方法，也可以让本地的 Agent 自动进行安装。项目文档提供了配置 MCP 工具的具体步骤和示例。
