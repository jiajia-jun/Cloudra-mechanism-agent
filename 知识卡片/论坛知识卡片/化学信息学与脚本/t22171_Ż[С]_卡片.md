## 1. ztop脚本的主要功能

ztop 是一个用于力场参数化与拓扑文件生成的脚本工具。该工具整合了 Multiwfn、AmberTools 等程序，支持通过多种流程生成 GROMACS、Amber、CHARMM 和 DL_POLY 格式的拓扑文件。它支持通过全息片段或结构匹配将小分子拓扑参数转移至大分子，并提供自动参数生成功能。此外，脚本还包含对键长、键角以及二面角参数的优化功能。

---

## 2. 脚本规划中的功能

开发者计划为 ztop 增加多项新功能以拓展其能力。计划中的功能包括整合 libpargen 以支持 OPLS-AA 和 OpenFF 力场，整合 intermol 以支持 LAMMPS 和 Desmond 格式，以及整合 chargemol 以支持 DDEC 电荷计算。其他规划功能包括支持全元素 LJ 参数生成及全元素拓扑文件编写、增加基于硬件加速的并行计算支持、基于结构生成拓扑文件以及从坐标生成拓扑文件。

---

## 3. 运行环境要求

ztop 脚本的运行环境需要满足特定的系统和库依赖。该脚本目前仅在 Linux 系统下运行，必须预先安装 AmberTools 和 Libpargen。Python 环境需为 Python 3，并安装 networkx（图论）、openmm（分子力学）、parmed（文件 IO 与转换）、pandas、numpy（数据处理）和 matplotlib（绘图）等库。

---

## 4. 依赖软件的安装

安装 ztop 前需准备 Multiwfn、AmberTools、Gaussian 和 Libpargen（临时使用）。Multiwfn 的安装可参考相关安装教程，AmberTools 的安装则建议参考 Amber14 的安装指南，普通用户也可直接使用 conda 安装 AmberTools19。Libpargen 根据具体使用需求进行安装。

---

## 5. 使用 Conda 创建独立环境

为了避免不同程序之间的版本冲突，建议创建一个独立的 Conda 环境专门用于运行 ztop 脚本。首先更新 conda，然后创建一个名为 ztop 的环境并安装所需依赖包。创建环境的命令为 `conda create -n ztop -c conda-forge networkx pandas numpy matplotlib parmed ambertools openmm`。

---

## 6. 激活与退出 Conda 环境

在使用 ztop 脚本之前，需要先激活名为 ztop 的 Conda 环境。激活命令为 `conda activate ztop`，使用完毕后可通过 `conda deactivate` 命令退出环境。

---

## 7. networkx 版本兼容性问题

若 networkx 版本过低，在运行脚本时可能会提示 "No module named 'networkx.algorithms.graph_hashing'" 错误。解决方法是指定安装 networkx 2.5.1 版本，命令为 `conda install networkx=2.5.1`，或者直接使用 pip 安装，命令为 `pip install networkx`。

---

## 8. OpenMM 符号错误修复

当 --checkenv 检测到 OpenMM 时，若出现 "undefined symbol: omp_get_num_procs" 错误，需要进行特定的包更新或安装修复。解决方案包括从 conda-forge 渠道安装 llvm-openmp，以及更新 intel-openmp，对应的命令分别为 `conda install --channel conda-forge llvm-openmp` 和 `conda update intel-openmp`。

---

## 9. OpenMM 版本要求

ztop 目前仅支持 OpenMM 7.6 及以上版本。若脚本检测到 OpenMM 版本过低，会建议用户更新 OpenMM；如果未安装 OpenMM，脚本则会提示安装。更新命令为 `conda update -c conda-forge openmm`。

---

## 10. 脚本下载与更新

ztop 脚本托管在 Gitee 上，推荐使用 git 方式克隆以便后续更新。下载命令为 `git clone https://gitee.com/coordmagic/coordmagic.git`。若需要更新脚本，需进入 coordmagic 文件夹并执行 `git pull origin master`。

---

## 11. 环境检查命令

在运行 ztop.py 之前，建议使用内置命令检查 Python 及相关依赖的配置状态。检查命令为 `ztop.py --checkenv`，该命令会列出当前环境的配置情况及潜在问题。

---

## 12. 生成拓扑文件：从 Gaussian 输出生成 GROMACS 文件

ztop 可以直接利用 Gaussian 计算得到的 log 和 fchk 文件生成 GROMACS 格式的拓扑文件（gaff2-resp 方法）。基本命令为 `ztop.py -g "DON.log" -o DON.top,DON.gro`，其中 -g 开启生成模式，-o 指定输出文件名和格式。

---

## 13. 生成拓扑文件：从 mol2 生成 Amber 文件

从 mol2 文件出发，结合 AM1-BCC 电荷和 GAFF 力场，可生成 Amber 格式的 prmtop 和 inpcrd 文件。命令为 `ztop.py -g "DON.mol2;q=am1-bcc;ff=gaff" -o DON.prmtop,DON.inpcrd`，此过程依赖 antechamber 和 sqm 进行电荷计算。

---

## 14. 生成拓扑文件：中断式 RESP2 流程

使用 mol2 文件生成 GAFF2-RESP2 拓扑文件时，若缺少 fchk 文件，脚本会在当前目录生成用于计算的 gjf 文件（DON_gas.gjf 和 DON_sol.gjf）。用户需手动提交 Gaussian 计算任务，计算完成后将 log 和 fchk 文件放回当前目录，再次运行相同命令即可生成结果。

---

## 15. 自定义 Gaussian 输入文件参数

在中断式流程生成 gjf 文件时，可以使用 `--gjf` 选项自定义计算参数。例如命令 `ztop.py -g "DON.mol2;q=resp2;ff=gaff2" --gjf "nproc:20;mem:20GB;opt:0;solvent:chloroform;method:PBE1PBE;basis:def2TZVP"`，其中 `opt:0` 表示不进行结构优化。

---

## 16. 指定 RESP2 变体方法

默认情况下 RESP2 使用 resp2-0.5 方法，若需使用 resp2-0.6 方法，可以在命令中通过 q 参数指定。例如使用 Gaussian 生成的 log 文件进行后续处理时，命令为 `ztop.py -g "DON_gas.log;q=resp2-0.6;ff=gaff2"`。

---

## 17. 仅计算电荷功能

如果只需要利用 Multiwfn 计算电荷而不生成完整拓扑文件，可以使用特定命令。例如计算 CM5 电荷的命令为 `ztop.py -g "DON.log;q=cm5;charge_only"`，计算结果会乘以 1.2 并保存在当前目录的 chg 文件中。

---

## 18. 参数优化背景与原理

小分子的力场参数（如键长、键角、VDW 参数）通常基于简化的模型结构，可能与实际复杂环境中的分子结构存在偏差。为了提高 MD 模拟的准确性，ztop 提供了根据量子力学计算结果优化拓扑文件中参数的功能，旨在修正标准力场参数与特定分子实际性质之间的差异。

---

## 19. 优化拓扑文件中的键长和键角参数

使用 ztop 可以基于 Gaussian 输出文件优化拓扑文件中的键长和键角参数。命令示例为 `ztop.py -p DON.top -x DON.gro -r e -o DON_rf.top`，其中 -p 指定拓扑文件，-x 指定坐标文件，-r e 开启键长键角优化模式。

---

## 20. 指定优化用的 Log 文件

如果用于优化的 log 文件不是默认名称（如 DON.log），则需要通过 -r 参数显式指定。例如，若 log 文件名为 xyz.log，命令应修改为 `ztop.py -p DON.top -x DON.gro -r "e=xyz.log" -o DON_rf.top`。

---

## 21. 一键生成与优化

可以将拓扑文件生成与参数优化步骤合并，直接从 Gaussian 计算结果生成优化后的拓扑文件。命令为 `ztop.py -g "DON.log" -r e -o DON.top,DON.gro`，该命令会同时完成生成和优化过程。

---

## 22. 优化拓扑文件中的键角力常数

ztop 支持基于 Hessian 矩阵投影到键和键角上的 modified Seminario 方法来优化键角力常数。开启该功能的命令是在 -r 参数中添加 k，例如 `ztop.py -g DON.log -r "e;k" -o DON.top,DON.gro`。

---

## 23. 指定力常数计算文件

若需分别指定优化键长键角和计算力常数的文件，可以在 -r 参数中分别设置。例如命令 `ztop.py -p DON.top -x DON.log -r "e=DON.log;k=DON.fchk" -o DON.prmtop,DON.inpcrd`，分别指定了结构和力常数来源文件。

---

## 24. 使用原始 Seminario 方法

除了 modified Seminario 方法外，ztop 还保留了原始的 Seminario 方法供用户选择。通过在 -r 参数中添加 origin 关键字即可启用，例如命令 `ztop.py -g DON.log -r "e;k;origin" -o DON.top,DON.gro`。

---

## 25. 小分子拓扑拼接功能

ztop 具备将小分子拓扑文件拼接成大分子拓扑文件的功能，该模块被称为 residuecomposer。该功能允许基于已有的小分子参数构建更为复杂的体系拓扑。

---

## 26. 自动拟合二面角参数

ztop 包含一个 torsionfit 模块，用于自动拟合和优化二面角参数。该功能允许用户针对特定分子的二面角旋转能面进行精确的力场参数化。
