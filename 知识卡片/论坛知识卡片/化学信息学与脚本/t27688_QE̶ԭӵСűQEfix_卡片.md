## 1. QEfix.sh 脚本功能

QEfix.sh 是一个用于 Quantum Espresso (QE) 输入文件的 Bash 脚本，旨在自动向特定原子行添加固定约束参数。该脚本支持以单数字或范围形式（如 1,5,9-12）指定原子序号，并能统一添加用户定义的 `if_pos` 值（例如 0 0 0）到文件末尾，从而实现原子坐标的固定。

---

## 2. 脚本使用准备与输入文件生成

在使用脚本前，需通过图形界面工具（如 gview 或 pwgui）准备初始结构。通过 gview 的 `tools -> atom selection` 功能可以直观地查看并确定需要固定的原子序号，随后利用 pwgui 生成结构优化输入文件（如 rutile.relax.in），脚本将对该文件进行修改。

---

## 3. 脚本执行流程与用户交互

执行脚本命令为 `./QEfix.sh rutile.relax.in`。运行后，脚本会提示用户输入需要固定的原子索引（例如 1,5,9-12,14-18）以及 `if_pos(i)` 参数（例如 0 0 0，表示同时固定 x、y、z 方向），输入完成后脚本会自动处理文件。

---

## 4. 原子序号范围解析逻辑

脚本使用 `awk` 以逗号为分隔符拆分输入的原子序号字符串。通过正则表达式 `^[0-9]+$` 判断字段是纯数字还是范围（含减号）；若为范围（如 4-10），则利用 `awk` 提取最小值和最大值，并使用 `seq` 命令生成该范围内的所有数字，最终将所有待处理序号存入临时文件。

---

## 5. if_pos 参数写入原理

脚本首先通过 `grep` 定位输入文件中 `ATOMIC_POSITIONS` 关键词的行号。随后计算每个待固定原子在文件中的实际行号（原子序号 + `ATOMIC_POSITIONS` 行号），最后使用 `sed` 命令 `${i}s/$/ ${if_pos}/g` 在对应行的行尾追加输入的 `if_pos` 参数值，完成原子固定设置。
