## 1. 解决旧版Windows无法打开高版本Material Studio文件的问题

Material Studio 文件存在版本兼容性限制，旧版本 Windows 环境下的 MS 无法直接打开高版本创建的文件。可通过修改文件内部版本号信息来实现版本兼容。

---

## 2. 跨平台版本切换脚本的运行环境

执行版本修改脚本需要确保文件存放路径在 Linux 环境下，或者在 Windows 下使用 WSL、Git Bash、Cygwin 等类 Linux 终端环境。

---

## 3. 批量修改文件版本号的 sed 命令

使用 sed 命令批量替换当前目录下文件中的版本字符串，可将高版本号改为低版本号以解决兼容性问题。命令示例如下：`for i in *.*; do sed -i "s/\"20.1\"/\"17.1\"/" "${i}"; done`。

---

## 4. Material Studio 版本号对应关系

脚本中的版本号字符串需与实际软件版本对应，其中 "20.1" 代表 MS2020，"17.1" 代表 MS2017。

---

## 5. 封装脚本的使用方法

将核心操作逻辑封装为脚资料件，需将其添加至 PATH 环境变量并赋予可执行权限，随后即可通过命令行调用。执行命令格式为：`msver.sh 20.1 17.1`。
