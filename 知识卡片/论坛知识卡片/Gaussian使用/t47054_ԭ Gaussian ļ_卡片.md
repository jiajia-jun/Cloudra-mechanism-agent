## 1. LogProcessorGUI 软件概述

LogProcessorGUI 是一款基于 Python 开发的开源工具，用于从 Gaussian 输出文件（.log 或 .out）中提取数据。该工具提供图形用户界面（GUI），旨在辅助计算化学数据处理工作。
- 该软件代码托管于 GitHub 平台，项目名称为 LogProcessorGUI。

---

## 2. 坐标提取功能

该工具支持将输出文件中的原子坐标按指定格式导出为文本。提取的坐标类型包含笛卡尔坐标，满足后续分析或输入文件构建的需求。
- 此功能可将计算结果中的结构信息整理并输出。

---

## 3. 能量数据提取

工具具备提取计算过程中能量数据的能力。用户可获取输出文件内记录的各步能量数值。
- 该功能用于监控反应路径或优化过程中的能量变化。

---

## 4. NMR 屏蔽张量提取

该工具支持提取核磁共振（NMR）相关计算结果，包括 SCF GIAO 屏蔽张量数据。用户可获取各向同性值等具体参数。
- 此功能适用于分析分子的磁屏蔽性质。
