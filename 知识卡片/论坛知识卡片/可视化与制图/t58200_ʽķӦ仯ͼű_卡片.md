## 1. 版本更新与功能介绍

EnergyCurvePlot v1.2 版本更新，新增了多项功能优化，包括参数保存、数据导入导出及绘图样式调整。该工具主要用于绘制反应进程能量变化图。

---

## 2. Save Config 与 Load Config 功能

工具新增 Save Config 和 Load Config 选项，支持将页面设置好的参数直接保存为 json 文件。该功能允许用户再次打开软件时一键读取之前保存的配置。

---

## 3. 数据导入导出格式

工具支持将数据导出和保存为 xlsx 或 csv 文件格式，同时也支持从这两种格式的文件中读取数据。

---

## 4. cdxml 文件保存与编辑

工具支持保存 cdxml 格式文件，该格式包含原子位置信息。生成的文件可在 ChemDraw 中打开并进行进一步编辑，例如调整直线或增加注释。

---

## 5. ChemDraw 文件读取与样式加载

新增读取 ChemDraw 文件的功能，使用 Load CDXML Style 选项可以读取并应用 ChemDraw 文件中的样式。读取 cdxml 文件时也可应用同样的样式，且样式设置会被记录。

---

## 6. Show Numbers 与 Show Targets 选项

Show Numbers 和 Show Targets 选项用于控制图中数字和标签的显示。在图形界面上开启或关闭这些显示不会影响最终保存的 cdxml 文件。

---

## 7. 表格高亮与颜色功能

工具使用 tksheet 编写了表格显示组件，支持自定义背景颜色。表格背景颜色用于展示当前选中内容的颜色。

---

## 8. Line Style 线条样式选项

Line Style 选项允许用户自定义每一行的线条连接方式，可设置为虚线或实线。

---

## 9. Pick Color 取色功能

提供取色功能，选中某个元素后，点击右键菜单的 Pick Color 选项会弹出取色面板。用户可直接从屏幕上任意位置吸取颜色，左上角会实时显示当前选中的颜色。

---

## 10. base curve 参数设置与绘图

将 base curve 参数设置为 0 可以绘制直线，该功能适用于绘制反应能垒图。生成的直线与数据点分离，且可以在 ChemDraw 中编辑该直线。

---
