## 1. EnergyDiagramDraw 简介

EnergyDiagramDraw 是一个基于 Python 编写的用于绘制能级图的程序，能够自动生成能级图并支持调整配色。该项目提供了现成的绘图解决方案，用户可以通过 GitHub issue 或直接回复的方式提供反馈。

---

## 2. 环境依赖

运行 EnergyDiagramDraw 需要 Python 3.9 环境。若要查看生成的图像，推荐使用 ChemDraw 软件。

---

## 3. 基本使用方法

执行程序时，需指定输入文件路径，输入文件的后缀名建议使用 .edf（EnergyDiagramFile）。若不指定输出文件名，程序会自动生成与输入文件同名但后缀为 .cdxml 的文件；若指定了输出文件名，则程序将忽略输入文件的后缀名，直接使用指定的输出文件名。

---

## 5. EDF 文件格式结构

.edf 文件主要由设置、数据和标签以及注释部分组成，其格式设计参考了 Gaussian 的 .gjf 格式。文件结构包括：Link0 行（以 % 开头，用于设置能级图选项）、标题行、Route 行（以 # 开头，用于设置每个能级的文本）、分子系、标签（可选）、多个分子系数据块（以空行分隔）以及终止符。

---

## 6. 配置行设置规则

配置行用于修改能级图的属性，每行配置必须以 % 符号开头。配置项的书写顺序即为生效顺序，若省略某项配置，程序将使用默认值。
