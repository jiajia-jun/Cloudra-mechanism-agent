# 谈谈与计算化学有关的作图的图像清晰问题 — 知识卡片

## 1. 提高图片分辨率

图片不清晰可能源于图片分辨率（即像素）过低，解决方法是让产生图片的程序输出更高分辨率的图像。Multiwfn 程序通过 settings.ini 文件里的 graph1Dsize、graph2Dsize、graph3Dsize 参数分别控制一维、二维、三维图像的保存分辨率。GaussView 通过 File - Save Image 保存图片时，其像素由界面上的 Enlarge Width and Height by 参数控制（如设为 3x 则像素扩大 3 倍）。VMD 使用 File - Render 保存图片时，若选用 Snapshot 或 Tachyon (internal, in-memory rendering) 渲染器，图片像素与 OpenGL 窗口一致；若需更高像素，可放大窗口或在使用 POV-Ray 及独立 Tachyon 渲染器时直接指定像素。对于只能截图的程序，应最大化窗口并放大体系后截图，或使用高分辨率屏幕进行截图。

---

## 2. 避免有损压缩格式

JPG 是一种有损压缩的图像格式，保存时若质量参数设置过低，会导致图像模糊及色彩失真。在 Photoshop、IrfanView 等软件中保存 JPG 时可选择质量参数，设置越高图像质量越好但文件越大。对于科研绘图，特别是用于发表的图片，建议使用 PNG 格式，这是一种无损压缩格式，不会降低图像质量，且文件体积比 BMP 和 TIF 更小。

---

## 3. 图像放大的清晰度问题

在保存或生成图片时若像素不高，插入文档后手动拉大尺寸会导致图像模糊。PS、EPS、WMF 等矢量图格式可以无损缩放，而 PNG、BMP、TIF、JPG 等位图格式一旦放大必然会出现模糊。

---

## 4. 软件自动压缩图像

PowerPoint 等软件在保存文件时可能会根据 PPI 设置自动压缩图像。在 PowerPoint 的“选项”-“高级”-“图像大小和质量”中，若未勾选“不压缩文件中的图像”，高 PPI 图片会被自动压缩；若图片被缩小后保存，像素数会降低，再次拉大时就会模糊。勾选“不压缩文件中的图像”可避免此问题，其他软件也需检查类似的自动压缩设置。

---

## 5. 使用保存功能而非截图

部分可视化程序为提高显示速度，屏幕显示时图像质量较低，保存图片时才会使用高质量设置。因此，只要可视化程序具备专门的保存图片功能，就应优先使用该功能而非直接截图。对于 Multiwfn 显示的三维分子结构图和等值面图，特别是使用 mesh 或 solid face+mesh 风格时，建议保存为高像素图片后再缩放，这比直接截图质量更好且具有抗锯齿效果。

---

## 6. 根据图像类型选择保存格式

应根据图像内容选择矢量图或位图格式以获得最佳效果。由线条、文字和离散颜色构成的图（如光谱图、等值线图）适合保存为 PDF 等矢量格式，可无损缩放且线条平滑。具有连续色彩过渡的图（如等值面图、填色图）适合保存为 PNG 等位图格式；若将连续色彩图存为矢量图会出现难看的色阶，而将线条图存为位图则线条不如矢量图平滑。

---

## 7. 投稿系统对图像质量的影响

期刊投稿系统在提交前生成的预览 PDF 文件通常会对图像进行自动处理（如降低分辨率、有损压缩）以减小文件体积。这种处理可能导致预览 PDF 中的图片清晰度下降或变糊，但这通常无法避免且不影响审稿，预览清晰度与最终出版清晰度无直接关系。

---

## 8. 开启抗锯齿功能

显示 3D 物体时若未开启抗锯齿，物体边缘会显得毛糙，可能被理解为不清晰。大多数可视化程序都有抗锯齿选项，开启后可减轻边缘锯齿感；若无此选项，可在显卡驱动中强制设定抗锯齿。另一种人工抗锯齿的方法是保存高像素图像，然后使用 Photoshop 或 IrfanView 等软件缩小图像，通过重采样实现平滑效果。

---

## 9. 关闭或调整雾化效果

许多 3D 程序默认开启雾化效果以体现深度，如 VMD 默认开启 Depth cueing，导致物体变黑或呈现雾蒙蒙的感觉。VMD 的默认雾化衰减设置不理想，可能影响近距离物体的显示。建议在 VMD 中关闭 Depth cueing，或在 Display - Display Settings 中恰当设置 Cue Mode，使雾化效果仅作用于中远距离物体。

---

## 10. 设置等值面绘制的格点间距

绘制等值面图需要基于三维空间格点数据，格点间距越大，等值面越粗糙、有棱角甚至不连续。提高等值面质量的方法是减小格点间距，但这会增加计算格点数和耗时。Multiwfn 等程序提供了灵活设定格点的方式以平衡质量与效率。

---

## 11. 调整光源设置

显示 3D 物体时，光源设置不当可能导致局部过暗，从而产生不清晰的感觉。在 VMD 1.9.3 中可以在 Display 菜单中切换四个光源的开闭，并通过 Mouse - Move Light 拖动鼠标调节光源位置。在 Multiwfn 中，可以通过菜单 Other settings - Set lightings 来选择开启或关闭特定的光源。

---

## 12. 合理设置显示风格

可视化程序的显示风格设置不合理可能导致图像看起来不清晰。VMD 1.9.3 默认使用 line 方式且线宽仅为 1.0，导致单个原子显示为一个像素点，难以看清。将显示方式改为 CPK 或 Licorice，或增大 line 风格的线宽（如设为 2.0），可以显著改善显示清晰度。
