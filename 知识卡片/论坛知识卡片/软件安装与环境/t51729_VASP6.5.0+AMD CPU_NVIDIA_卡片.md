# VASP6.5.0+AMD CPU/NVIDIA A100 GPU���� — 知识卡片

## 1. VASP 6.5.0 在 AMD EPYC 和 NVIDIA A100 硬件环境下的编译适用性

VASP 6.5.0 支持在 AMD EPYC CPU 和 NVIDIA A100 GPU 的硬件环境下进行编译与使用。该编译过程涉及 HPE Cray 系统、双路 AMD EPYC-Milan 7713 CPU (128核/节点)、NVIDIA A100 40 GB GPU 以及 RHEL 8.4 操作系统。在 HPE Cray 环境中，编译器包装命令分别为 Fortran 编译器 `ftn`、C 编译器 `cc` (小写) 和 C++ 编译器 `CC` (大写)。

---

## 2. HPE Cray 环境模块管理基础

HPE Cray 环境使用 module 模块管理系统，基础编程环境通过 `PrgEnv-xxx` 模块切换，其中 `xxx` 可为 cray、intel、gnu、aocc 或 nvhpc。系统默认加载的编程环境为 `PrgEnv-cray`，用户在编译 VASP 前需根据目标编译器链加载相应的环境模块。

---

## 3. AMD CPU + Intel OneAPI 版本编译环境配置步骤

配置基于 Intel OneAPI 的编译环境需依次加载特定模块：`module swap PrgEnv-cray PrgEnv-intel`、`module swap craype-x86-rome craype-x86-milan`、`module load mkl/2024.0`、`module load cray-hdf5-parallel`，并移除 `cray-libsci` 模块。该环境包括 Intel OneAPI 2024.0 编译器、Intel MKL 数学库、Cray MPICH 8.1.15 MPI 库以及 Intel 编译的并行 HDF5 (版本 1.12.1.1)。

---

## 4. Intel OneAPI 版本 makefile.include 的关键修改

使用 `arch/makefile.include.oneapi_omp` 模板时，需修改编译选项：将 `-DHOST` 值改为 `AMDIFC`，添加 `-Duse_bse_te` 以支持 BSE triplet excitation，将 Fortran 编译器 `FC` 和链接器 `FCL` 设置为 `ftn` 并添加 `-diag-disable=10448` 选项。此外，需将 `CC_LIB` 设置为 `cc`，`CXX_PARS` 设置为 `CC`，并注释掉或修改 `VASP_TARGET_CPU` 选项，将 `-xHOST` 改为 `-march=core-avx2` 以兼容 AMD CPU。

---

## 5. Intel OneAPI 编译中的 HDF5 配置与注意事项

在 Intel OneAPI 环境下启用 HDF5 支持需取消注释 HDF5 相关配置行，并确保 `HDF5_ROOT` 环境变量指向正确的安装路径。需注意 HDF5 库必须由 Intel 编译器构建，若使用 GCC 编译的 HDF5 或混用不同编译器版本构建的 HDF5 与 VASP，会导致运行时报错。配置中需添加 `CPP_OPTIONS+= -DVASP_HDF5`、`LLIBS` 链接路径及 `INCS` 包含路径。

---

## 6. VASP Intel OneAPI 版本的编译命令

在登录节点上执行编译命令时，建议使用 `make DEPS=1 -j4 all`，其中 `DEPS=1` 指定处理依赖文件，`-j4` 指定并行编译任务数为 4。编译成功后，`bin/` 目录下将生成 `vasp_gam`、`vasp_ncl` 和 `vasp_std` 可执行文件。

---

## 7. AMD CPU + NVIDIA A100 GPU 版本编译环境配置步骤

配置 GPU 版本编译环境需使用 NVHPC 工具链：依次执行 `module swap PrgEnv-cray PrgEnv-nvhpc`、`module swap craype-x86-rome craype-x86-milan`、`module load craype-accel-nvidia80`、`module swap nvhpc nvhpc/23.7`、`module swap cuda cuda/11.8.0`。数学库加载 Intel OneAPI 2024.0 MKL (`module load mkl/2024.0`)，I/O 库加载与 NVHPC 兼容的 HDF5 (`module load hdf5/1.12.1-nvhpc`)，并移除 `cray-libsci` 以避免冲突。

---

## 8. GPU 版本 makefile.include 的编译器与 GPU 架构设置

使用 `arch/makefile.include.nvhpc_ompi_mkl_omp_acc` 模板时，需将 `-DHOST` 值改为 `LinuxNVGPU` 并添加 `-Duse_bse_te`。C 编译器 `CC` 需设置为 `cc`，Fortran 编译器 `FC` 和链接器 `FCL` 需设置为 `ftn`，且必须根据 GPU 架构和 CUDA 版本添加编译选项，例如针对 NVIDIA A100 (计算能力 cc80) 和 CUDA 11.8，需添加 `-gpu=cc80,cuda11.8`。

---

## 9. GPU 版本 makefile.include 的 MKL 与 C++ 解析器设置

在 GPU 版本的配置文件中，需将 C++ 解析器 `CXX_PARS` 设置为 `CC`。对于 MKL 库的链接，需注释掉原始 `MKLLIBS` 定义，重新定义 `LLIBS_MKL` 为 `-Mmkl -L$(MKLROOT)/lib/intel64 -lmkl_scalapack_lp64 -lmkl_blacs_intelmpi_lp64`，确保使用 `intelmpi` 版本的 BLACS 库而非 `openmpi` 版本，以避免出现 `undefined reference` 错误。

---

## 10. GPU 版本编译的节点选择与执行流程

由于 GPU 版本编译过程需要调用 GPU 硬件，若在无 GPU 的登录节点编译会导致 `libcuda.so.1 not found` 错误。建议先在 CPU 登录节点进行预编译，随后通过交互式作业 (如 `qsub -I`) 登录到 GPU 计算节点，加载相同的编译环境模块，并执行 `make DEPS=1 -j16 all` 完成最终编译。

---

## 11. GPU 版本编译时 OpenACC 与 NVCUDA 相关错误的修复

若编译过程中因 `MPIX_Query_cuda_support` 报错并指向特定文件行号，需手动注释报错文件中相关接口的 4 行代码。报错文件位于 `./build/{gam,std,ncl}/{openacc,nvcuda}.f90` (或 `.F`)，需使用 `vim +行号 文件名` 打开文件，将以 `INTERFACE` 开头的标准声明块注释掉。

---

## 12. 不同 NVIDIA GPU 架构对应的 -gpu= 编译参数

在使用 NVHPC 编译 VASP GPU 版本时，`-gpu=` 参数必须与硬件架构匹配：Pascal 架构 (如 P100) 使用 `cc60`，Volta 架构 (如 V100) 使用 `cc70`，Turing 架构 (如 RTX 2080) 使用 `cc75`，Ampere 架构 (如 A100, RTX 3080) 使用 `cc80`。

---

## 13. MPIX_Query_cuda_support 函数未定义引用的解决方案

在部分情况下，直接调用 `MPIX_Query_cuda_support()` 可能会导致报错 "undefined reference to MPIX_Query_cuda_support"。此时应将源代码中的判断条件 `CUDA_AWARE_SUPPORT = MPIX_Query_cuda_support() == 1` 直接修改为 `CUDA_AWARE_SUPPORT = .TRUE.`。该操作可以规避函数未定义的链接错误，强制启用 CUDA AWARE 支持。

---

## 14. VASP 石墨烯体系 INCAR 参数配置

计算石墨烯体系时，推荐设置 `SYSTEM = graphene`，`ENCUT = 520`，`PREC = Accurate`，`ISMEAR = -5`，`SIGMA = 0.05`，`ALGO = Fast`，`EDIFF = 1E-7`，`EDIFFG = -0.01`，`LCHARG = .TRUE.`，`LWAVE = .TRUE.`，`LORBIT = 11`，`LREAL = .FALSE.`，`ISYM = 1`，`NELM = 200`。结构优化未开启（`NSW = 0`），并使用 DFT-D2 方法处理范德华作用。

---

## 15. VASP 石墨烯体系 KPOINTS 设置

使用 Gamma-Centered 模式生成 K 点网格。对于石墨烯体系，建议设置网格参数为 25 25 1，偏移量为 0 0 0。

---

## 16. VASP 石墨烯体系 POSCAR 结构参数

POSCAR 文件中定义了石墨烯的晶胞参数，缩放因子为 1.00000000000000。晶格向量分别为 2.4677557588200547 0.0000000001951262 -0.0000000000000000、-1.2338785942720587 2.1371404153443971 -0.0000000000000000、0.0000000000000000 0.0000000000000000 14.9975103391044442，包含 2 个碳原子，其直角坐标位置为 0.3333328829999971 0.6666671669999999 0.2000000060000033 和 0.6666671540000024 0.3333328579999986 0.2000000060000033。

---

## 17. VASP GPU 运行环境设置与执行命令

在单节点上使用 1 个 MPI 进程和 16 个 OpenMP 线程运行 VASP，需先设置环境变量 `export OMP_NUM_THREADS=16`。执行命令为 `mpirun -np 1 --cpu-bind depth -d $OMP_NUM_THREADS vasp_std | tee vasp_run.out`。

---

## 18. VASP GPU 计算输出日志解读

运行日志显示检测到 1 个 GPU ("Offloading initialized ... 1 GPUs detected")，使用的 FFT 网格规划包括 GRIDC、GRID_SOFT 和 GRID。 scaLAPACK 将选择性地在 CPU 上运行，输出文件包括 OUTCAR、WAVECAR 和 CHARGE。

## 20. HPE Cray 环境下 VASP 编译注意事项

在 HPE Cray 计算环境下，统一使用 `ftn`、`cc`、`CC` 作为 Fortran、C 和 C++ 的编译器命令。关于 module 的链接方式应参考之前的说明进行配置，针对 VASP 6.5.0 + Intel CPU + NVIDIA A40 GPU 的编译经验可作为参考。
