# QE 6.8��װ��¼ — 知识卡片

## 1. QE 6.8 与 pslibrary 1.0.0 的软件版本组合

Quantum Espresso 6.8 可配合 pslibrary 1.0.0 使用以生成对应的赝势文件。
- 下载 QE 6.8 可访问 GitHub 的 QEF/q-e/releases 页面。
- 下载 pslibrary 1.0.0 可访问 GitHub 的 dalcorso/pslibrary 页面。
- 此组合适用于 CentOS Linux release 7.6.1810 系统。

---

## 2. 基于 Intel Parallel Studio XE 2015 的环境变量配置

在安装 QE 6.8 前，需加载 Intel 编译器及数学库的环境变量。
- 依次执行 `source /opt/intel2015/bin/compilervars.sh intel64`。
- 依次执行 `source /opt/intel2015/mkl/bin/mklvars.sh intel64`。
- 依次执行 `source /opt/intel2015/impi/5.0.3.049/intel64/bin/mpivars.sh`。
- 上述路径假设 Intel Parallel Studio XE 2015 安装于 `/opt/intel2015`。

---

## 3. QE 6.8 的配置与安装命令

配置安装参数并执行编译安装需使用特定命令。
- 配置命令为 `./configure --prefix=/home/qe`。
- 安装命令为 `make all install`。
- 安装目标路径设定为 `/home/qe`。
- 配置成功后终端会提示 "Parallel environment detected successfully." 和 "Configured for compilation of parallel executables."。

---

## 4. 使用 Intel 编译器套件时的 make.inc 变量设置

若使用 Intel 编译器套件，make.inc 文件中的变量需设置为特定值。
- 变量 `MPIF90` 设置为 `mpiifort`。
- 变量 `F90` 设置为 `ifort`。
- 变量 `CC` 设置为 `icc`。

---

## 5. pslibrary 1.0.0 生成赝势文件的步骤

利用 pslibrary 1.0.0 生成 QE 对应赝势文件需修改路径配置并执行脚本。
- 修改 pslibrary 目录下的 QE_path 文件，将其中的 QE 路径改为实际安装路径（如 `/home/qe`）。
- 执行 `./make_all_ps` 命令生成赝势文件。
- 可使用 `./make_all_test` 命令进行测试。

---

## 6. pslibrary 赝势文件的兼容性说明

使用 pslibrary 1.0.0 生成的赝势文件存在兼容性限制。
- 若使用非资料提供的方法（如 原作者.com/562 提供的参数）安装 qe-6.6，生成的赝势文件可能无法使用。
- 建议严格按照配套方法安装以确保生成的赝势文件可用。

---

## 7. 使用 OpenMPI + GCC 组合时的 make.inc 配置

若使用 OpenMPI 3.1.4 配合 GCC 工具链安装 QE 6.8，make.inc 文件参数需进行特定配置。
- 变量 `MPIF90` 设置为 `mpif90`。
- 变量 `F90` 设置为 `gfortran`。
- 变量 `CC` 设置为 `gcc`。
- 仅链接 MKL 库时，需设置 `BLAS_LIBS = -lmkl_gf_lp64 -lmkl_sequential -lmkl_core`。
- 需设置 `SCALAPACK_LIBS = -lmkl_scalapack_lp64 -lmkl_blacs_openmpi_lp64`。

---

## 8. 不同编译器组合生成的程序兼容性差异

在同一台计算节点上，使用不同编译器组合生成的可执行程序存在兼容性问题。
- 使用 IntelMPI + icc + ifort + intel_mkl 编译生成的执行程序可能无法运行。
- 使用 OpenMPI + gcc + gfortran + intel_mkl 编译生成的 `pw.x` 程序则可正常运行。
