# Ubuntu 20.04 ��װ Orca 5.03 — 知识卡片

## 1. ORCA 5.03 在 Ubuntu 20.04 上的安装环境

ORCA 5.03 版本可以在 Ubuntu 20.04 系统上成功安装。该安装方案已在多种 CPU 架构平台上验证，包括 AMD Ryzen 9 5950X、Intel Xeon E5-2675 v3、Intel Xeon Silver 4210R 以及 Intel Xeon Gold 6161。

---

## 2. 配置 Ubuntu 软件源以提高下载速度

修改 `/etc/apt/sources.list` 文件可以更换软件源以提升下载速度。需要将原内容全部删除，并替换为阿里云镜像源配置，然后执行更新命令。
- `sudo vim /etc/apt/sources.list`
- `deb http://mirrors.aliyun.com/ubuntu/ focal main restricted universe multiverse`
- `deb-src http://mirrors.aliyun.com/ubuntu/ focal main restricted universe multiverse`
- `deb http://mirrors.aliyun.com/ubuntu/ focal-updates main restricted universe multiverse`
- `sudo apt-get update`

---

## 3. 使用 tmux 防止远程连接中断导致任务中止

安装并使用 tmux 终端复用工具可以确保计算任务在后台持续运行，避免因网络断开或关闭窗口导致进程中止。建立名为 orca 的 tmux 会话可以使用以下命令，若需退出或分离会话可查阅相关教程。
- `sudo apt-get install tmux -y`
- `tmux new -s orca`

---

## 4. 安装编译基础工具链

安装 `build-essential`、`gfortran` 和 `wget` 等基础工具是为了后续编译 OpenMPI 及其他依赖项做准备。
- `sudo apt-get install build-essential gfortran wget -y`

---

## 5. ORCA 安装包的准备与解压

ORCA 官方提供的 Shared OpenMPI 版本安装包体积较小，推荐下载该版本而非包含完整日志的巨大文件。下载完成后需将压缩包解压至用户主目录，并建议将解压后的文件夹重命名。
- `echo "$HOME"`
- `tar -xvf orca_5_0_3_linux_x86-64_shared_openmpi411.tar.xz&&mv orca_5_0_3_linux_x86-64_shared_openmpi411 orcashare`

---

## 6. 配置 ORCA 用户环境变量

将 ORCA 的可执行文件路径和库文件路径添加至 `.bashrc` 文件中，并设置别名以便直接调用。执行命令后需确保环境变量生效。
- `echo -e '\n#orca\nexport PATH=$PATH:$HOME/orcashare' >> $HOME/.bashrc;`
- `echo 'export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:$HOME/orcashare' >> $HOME/.bashrc;`
- `echo "alias orca='$HOME/orcashare/orca'" >> $HOME/.bashrc`

---

## 7. 下载并解压 OpenMPI 源码

为了兼容 ORCA 的并行计算，建议手动编译安装 OpenMPI 4.1.1。可以使用 wget 命令直接下载源码包并解压，同时创建安装目录。
- `cd $HOME && wget -c https://www.open-mpi.org/software/ompi/v4.1/downloads/openmpi-4.1.1.tar.gz && tar -xvf openmpi-4.1.1.tar.gz && cd $HOME/openmpi-4.1.1 && mkdir $HOME/openmpi`

---

## 8. 编译与安装 OpenMPI

编译 OpenMPI 的过程较长，建议在 tmux 会话中进行以防止断线。配置安装路径后，使用多核编译命令加速构建过程，最后执行安装。
- `cd $HOME/openmpi-4.1.1 && ./configure --prefix=$HOME/openmpi`
- `make -j `cat /proc/cpuinfo |grep 'processor'|sort -u|wc -l``
- `make install`

---

## 9. 配置 OpenMPI 用户环境变量

将 OpenMPI 的 bin 目录和 lib 目录分别添加到 PATH 和 LD_LIBRARY_PATH 环境变量中。配置完成后执行 source 命令使更改立即生效。
- `echo -e '\n#openmpi\nexport PATH=$PATH:$HOME/openmpi/bin' >> $HOME/.bashrc`
- `echo 'export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:$HOME/openmpi/lib' >> $HOME/.bashrc&&source $HOME/.bashrc`

---

## 10. 验证 OpenMPI 安装

执行 `ompi_info` 命令可以查看 OpenMPI 的详细信息，从而验证软件是否安装成功。如果输出正常的版本和配置信息，则说明安装无误。
- `ompi_info`

---

## 11. 解决 OpenMPI 插槽数不足报错

当 ORCA 请求的 CPU 核心数超过系统默认可用插槽数时，会报错提示可用插槽数不足。可以通过修改默认 hostfile 文件，将 localhost 的插槽数设置为系统的实际逻辑核心数来解决此问题。
- `echo "localhost slots=`cat /proc/cpuinfo |grep 'processor'|sort -u|wc -l`" >> $HOME/openmpi/etc/openmpi-default-hostfile`

---

## 12. 编写 ORCA 计算输入文件

创建一个输入文件（如 orcaTest.inp），在其中通过 `%pal nprocs 30 end` 指定并行核心数。计算任务类型、方法和基组在行首用感叹号标注，分子坐标以 XYZ 格式书写在 `* xyz 0 1` 与 `*` 之间。
```
%pal nprocs 30 end
! RHF OPT FREQ def2-TZVPP
* xyz 0 1
...
*
```

---

## 13. 查询系统 CPU 逻辑核心数

使用 grep 和 wc 命令组合可以统计系统当前的 CPU 逻辑核心数。该数值可用于设置输入文件中的并行进程数或 OpenMPI 的插槽数。
- `cat /proc/cpuinfo |grep 'processor'|sort -u|wc -l`

---

## 14. 提交 ORCA 后台计算任务

使用 ORCA 命令执行输入文件，并将标准输出重定向到输出文件中。在命令末尾添加 `&` 符号可将任务放入后台运行，即使关闭终端窗口也不会中断计算。
- `orca orcaTest.inp > orcaTest.out &`
