# AMD77532+Fedora34 ����Castep_19.11 — 知识卡片

## 1. AMD Zen3架构下CASTEP编译环境选择

在AMD Zen3架构CPU和Fedora 34操作系统环境下编译CASTEP，使用Intel MKL数学库可能存在不便，推荐采用OpenBLAS作为数学库解决方案。系统自带的GCC-11.3.1版本过高可能导致兼容性问题，建议通过Conda安装GCC 9.x版本。该编译环境仅验证通过CASTEP 19.11版本的编译，更高版本可能存在兼容性未知数。

---

## 2. 编译依赖缺失文件的处理方法

在编译FFTW等依赖库过程中，若出现链接器报错提示缺少`xxx-xxx-gcc`等文件，需手动检查`~/anaconda3/envs/xxcastepxx/bin`目录。利用`ln -s`命令创建符号链接，将缺失的文件名指向实际存在的编译器可执行文件，以解决链接错误。

---

## 3. CASTEP并行运行中断排查

CASTEP并行计算任务在运行中突然停止，通常是由于OpenMPI配置不正确或版本冲突引起的。在使用`mpirun -np 20/30`启动任务时，需确保MPI进程数与计算资源相匹配。经过测试，将进程数调整为32个并重新执行`mpirun`命令，任务可正常运行。

---

## 4. Anaconda环境与编译器安装

首先安装Anaconda3（如Anaconda3-2022.05-Linux-x86_64.sh），创建Conda环境并指定Python版本（`conda create -n xxnamexx python=3`）。添加conda-forge频道（`conda config --add channels conda-forge`）后，安装指定版本的GCC和G++（`conda install -c conda-forge cxx-compiler=1.3.0`），通过`conda list`确认版本为gcc-9.5.0。

---

## 5. GFortran与Make工具安装

在Conda环境中安装Fortran编译器（`conda install -c conda-forge fortran-compiler`），执行`gfortran --version`确认安装成功且版本为9.5.0。接着安装Make构建工具（`conda install -c conda-forge make=4.2.1`），使用`make --version`检查版本号是否为4.2.1。

---

## 6. OpenMPI安装与验证

通过Conda安装OpenMPI（`conda install -c conda-forge openmpi=4.0.2`），安装完成后使用`mpirun --version`命令验证OpenMPI是否安装成功及版本信息。

---

## 7. FFTW源码编译安装

下载FFTW源码包（fftw-3.3.6-pl2.tar.gz），执行配置命令指定编译器和MPI支持：`./configure CC=gcc F77=gfortran MPICC=mpicc --prefix=/where/is/your/lib/path --enable-mpi`。随后运行`make && make install`进行编译和安装，生成的库文件将存放在指定的`/where/is/your/lib/path`目录下。

---

## 8. OpenBLAS源码编译安装

下载OpenBLAS源码（OpenBLAS-0.3.12.tar.gz），使用`make -j2`进行编译，接着运行`make PREFIX=/where/is/your/lib/path install`将库安装到指定路径。安装完成后，库文件位于`/where/is/your/lib/path`目录中。

---

## 9. CASTEP编译命令与配置

进入CASTEP源码目录（CASTEP-19.11），执行编译命令`make MATHLIBS=openblas FFT=fftw3 COMMS_ARCH=mpi SUBARCH=mpi`，并需正确指定OpenBLAS和FFTW3的库文件路径。该命令将自动编译所有组件，完成后执行安装及工具安装命令：`make MATHLIBS=openblas FFT=fftw3 COMMS_ARCH=mpi SUBARCH=mpi install install-tools`。

---

## 10. CASTEP可执行文件位置与测试

CASTEP安装完成后，可执行文件存储在`bin/linux_xxxx--mpi`路径下。运行`make MATHLIBS=openblas FFT=fftw3 COMMS_ARCH=mpi SUBARCH=mpi check`执行默认的自动化测试，若无报错信息，则表明CASTEP编译安装成功。
