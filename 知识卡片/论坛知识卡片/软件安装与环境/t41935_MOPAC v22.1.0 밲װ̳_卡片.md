## 1. MOPAC 版本选择与安装说明

MOPAC 2016 年以前的旧版本已停止维护，建议使用开源的新版本进行编译安装。官方代码库位于 GitHub，采用 LGPL 协议，可通过下载 Release 包或克隆源码仓库获取源代码。

---

## 2. MOPAC 源码获取方式

用户可前往 GitHub Release 页面下载所需版本的安装包或源码包。若需从源码安装，可下载对应的源码压缩包，或通过 Git 克隆仓库并 check out 到特定版本。

---

## 3. MOPAC 编译环境要求

MOPAC 使用 cmake 构建系统，支持 GNU 编译器套件和 Intel oneAPI 基础工具包。编译前需确保系统已安装 cmake，且 cmake 能够找到相应的编译器和 BLAS 库。

---

## 4. MOPAC 配置与编译命令

使用 gfortran 编译时，需在 build 目录下执行配置命令指定安装路径。编译时使用 `-j` 参数指定并行任务数，数值应不超过 CPU 核心数。
- $ FC=gfortran cmake .. -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/path/to/mopac
- $ make -j 16

---

## 5. MOPAC 环境变量配置

编译安装完成后，需将 MOPAC 的可执行文件路径添加到系统环境变量 PATH 中。若使用 Intel oneAPI 编译器编译的版本，需确保正确加载相关模块。
- export PATH=/path/to/mopac/bin:$PATH

---

## 6. PM6-D3H4 方法输入文件设置

使用 PM6-D3H4 方法进行几何优化时，输入文件需包含特定关键词和电荷设置。坐标部分需注明为笛卡尔坐标格式。
- PM6-D3H4 EF PRNT=2 CHARGE=0
- GC Pair
- All coordinates are Cartesian

---

## 7. MOPAC 任务运行与可视化

通过命令行执行 `mopac` 命令运行输入文件，优化完成后可使用 `mopac2xyz` 转换轨迹。生成的轨迹文件可用 VMD 打开，用于查看和检查几何优化过程及动画。
- $ mopac GC-Pair.mop
