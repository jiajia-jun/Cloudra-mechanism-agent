## 1. CUDA Toolkit 安装

VASP 官方 Wiki 提供了基于 Linux Debian 10、11 及 Ubuntu 22 的 Toolchains 安装指南。CUDA Toolkit 推荐使用 12.5 版本，可直接参考 NVIDIA 官方文档进行安装，安装过程中通常全程使用默认选项即可。若当前用户环境中尚未安装 CUDA，需先行安装。

---

## 2. NVIDIA HPC SDK 安装

安装 NVIDIA HPC SDK 时应根据 CUDA 版本选择对应的版本，如 CUDA 12.5 对应 HPC SDK 24.5。下载后需按照官方文档进行默认安装，并配置相关的环境变量以将编译器路径加入系统 PATH 中。

---

## 3. NVIDIA HPC SDK 环境变量配置

安装 NVIDIA HPC SDK 后需设置以下环境变量，并建议将其写入 `bashrc` 文件中以持久化生效。这包括设置架构变量、编译器根目录、Man 路径以及将 24.5 版本的编译器和 OpenMPI 路径加入 PATH。
- `NVARCH=`uname -s`_`uname -m`; export NVARCH`
- `NVCOMPILERS=/opt/nvidia/hpc_sdk; export NVCOMPILERS`
- `export PATH=/opt/nvidia/hpc_sdk/Linux_x86_64/24.5/compilers/bin:$PATH`
- `export PATH=/opt/nvidia/hpc_sdk/Linux_x86_64/24.5/comm_libs/openmpi/openmpi-3.1.5/bin:$PATH`

---

## 4. FFTW 安装

FFTW 推荐使用 3.3.10 版本，下载并解压后运行 configure 进行配置。由于 VASP 6.4 默认依赖 `libfftw3_omp.a` 库，配置时必须启用 OpenMP 选项，随后执行 `make && make install` 进行编译安装。
- `./configure --enable-shared --enable-threads --enable-openmp --prefix=/install-path`

---

## 5. OpenMPI 与依赖库配置

Toolchain 构建中可使用 OpenMPI 4.1.6 或 NVIDIA HPC SDK 自带的 3.1.5 版本，两者差异不大。为了提升性能，官方建议同时配置 UCX (OpenUCX) 和 gdrcopy，并在编译 UCX 时指定 CUDA 和 gdrcopy 的路径。
- `./configure --prefix=/path/to/ucx-cuda-install --with-cuda=/usr/local/cuda --with-gdrcopy=/gdrcopy_path`

---

## 6. VASP 编译准备

完成依赖库安装及用户环境配置后，开始 VASP 编译。首先需复制适用于 NVIDIA HPC SDK 的 makefile 模板到源码根目录。
- `cp arch/makefile.include.nvhpc_omp_acc ./makefile.include`

---

## 7. VASP makefile.include 核心参数修改

在 `makefile.include` 文件中需针对 CUDA 版本、MPI 路径及 CPU 架构进行修改。需设置编译器（CC/FC/FCL）启用 OpenMP 和 ACC 加速，指定 GPU 架构为 cc60, cc70, cc80 及 CUDA 12.4，并定义 QD 库和 FFTW 的路径。
- `CC = mpicc -acc -gpu=cc60,cc70,cc80,cuda12.4 -mp`
- `FC = mpif90 -acc -gpu=cc60,cc70,cc80,cuda12.4 -mp`
- `FCL = mpif90 -acc -gpu=cc60,cc70,cc80,cuda12.4 -mp -c++libs`
- `QD ?= /opt/nvidia/hpc_sdk/Linux_x86_64/24.5/compilers/extras/qd`
- `FFTW_ROOT ?= /opt/install_fftw-3.3.10-omp`

---

## 8. VASP 编译优化选项

在 `makefile.include` 中添加特定的编译优化选项可解决 Infiniband 相关问题并提升性能。使用 NV HPC SDK 21.11 及以上版本和 CUDA 11.2 以上时，建议设置特定的优化宏和标志。
- `-DMPI_BLOCK=8000 -DCACHE_SIZE=4000`
- `OFLAG_IN = -fast -Mwarperf`
- `SOURCE_IN := nonlr.o`

---

## 9. CPU 类型与 tp 选项

在编译配置中需注意 `-tp` 选项的设置，应根据实际 CPU 型号选择对应的参数。具体的 CPU 类型对应关系可查阅 NVIDIA HPC Compiler Reference Manual。
- `VASP_TARGET_CPU ?= -tp px`

---

## 10. 运行环境配置与提交脚本

运行 VASP 前需设置 LD_LIBRARY_PATH 以包含 QD 库路径，并根据实际安装路径修改 VASP 和 MPI 的可执行文件位置。使用 mpirun 启动任务时需指定正确的 MPI 路径和核数。
- `export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/opt/nvidia/hpc_sdk/Linux_x86_64/24.5/compilers/extras/qd/lib`
- `$mpi_path/mpirun -n 1 $vasp_path/vasp_std > vasp.log`
