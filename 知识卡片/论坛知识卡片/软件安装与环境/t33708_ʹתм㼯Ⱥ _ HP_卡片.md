## 2. 系统访问兼容性

该计算平台支持多种操作系统和浏览器环境进行访问。
- 微信环境下可直接使用默认的 Edge 浏览器，无需任何安装配置，点击链接即可登录。
- 兼容系统包括 Windows 11 + Edge、Mac + Safari/Firefox/Chrome 以及 Ubuntu Xfce + Firefox/Chrome。
- 旧版 IE 浏览器无法使用；360 浏览器未进行验证。

---

## 3. 平台核心功能

该 Web 平台提供文件管理、作业监控、图形界面及终端访问功能。
- 支持文件管理器功能，可直接在线查看、编辑、下载文件或拖拽上传。
- Active Jobs 功能允许用户查看作业运行状态。
- 作业提交需选择商业脚本模板，上传指定输入文件，并支持直接跳转至工作路径查看结果。
- 提供图形界面应用（如 VMD 等），基于 Linux 原生运行环境，可直接点击使用。
- 支持终端连接功能，满足命令行操作需求。

---

## 4. 软件使用示例

演示视频中展示了不同计算化学软件在平台上的具体操作流程。
- VASP 需指定输入文件目录，并通过脚本指定 CPU 核心数；若节点核心数超过预设值，需进行相应修改。
- Gaussian 和 ORCA 等软件需在脚本中设置输入文件、CPU 核心数及内存大小。
- 图形界面软件如 GaussView 可直接打开使用。

---

## 5. 资源分配策略

平台采用单用户资源配额策略，以最大化用户并发数量。
- 以 96 核服务器为例，若限制每个用户使用 1 核 CPU + 1GB 内存，Xfce 环境下可支持 96 个用户同时使用。
- 根据计算化学任务特点，单用户内存需求通常不大，按 96 核 × 256MB 分配共 24GB 内存即可满足需求。
- 用户登录后仅拥有一个账号权限。
- 资源目录顺序对 Windows、Mac 和 Linux 系统保持一致。

---

## 6. 技术架构细节

平台 Web 前端基于 Open OnDemand 实现，涉及多项关键技术组件。
- 技术栈包括 Ruby、http(s)、nginx、SSL/TSL 以及 FQDN（完全限定域名）。
- 若上述关键组件（如文件系统/网络）配置无误，可参照 Open OnDemand Manual 进行部署。
- 集群搭建使用 hpc4you_toolkit 实现，仅需提供 IP 地址和 root 密码即可完成自动化部署。
- 对于普通用户，无需了解 root 用户、IP 地址、操作系统版本或服务器配置等底层细节。

---

## 7. 用户交互体验

Open OnDemand 为普通用户和资深用户提供了差异化的操作方式。
- 普通用户无需掌握复杂命令，通过鼠标点击即可完成文件操作、作业提交及图形界面交互。
- 资深用户可选择继续使用 SSH 命令行登录进行操作。
- 参考案例包括上海交通大学等机构的化学化工计算平台，均采用 Open OnDemand 配合 SJTU-HPC 的定制度。

## 9. 安装与部署建议

使用 hpc4you_toolkit 搭建集群后，部署 Open OnDemand 前端可发挥最大效能。
- 建议参考提供的参考链接进行独立搭建，或寻找志同道合的用户协作。
- Open OnDemand 可将高性能计算集群转化为 Web 前端，其 Web 端与管理员使用的工具用户关联一致。

---

## 10. 管理与扩展工具

除了基础 Web 前端，平台还可集成多种管理工具以增强功能。
- 集群管理可配合使用 ColdFront。
- 数据分析可配合使用 Open XDMoD。
- 这些工具可从任何原始安装来源添加，但需确保当前状态稳定后再安装额外对象。
- 使用这些工具需要识别集群类型及硬件详细信息。

---

## 11. 使用场景评估

不同技术背景的用户应根据自身情况选择操作界面。
- 对于初学者或习惯图形界面的用户，Open OnDemand 是非常合适的选择。
- 对于资深集群用户，图形界面可能效率较低，建议继续使用命令行。
- 不建议强制资深用户安装图形界面。
