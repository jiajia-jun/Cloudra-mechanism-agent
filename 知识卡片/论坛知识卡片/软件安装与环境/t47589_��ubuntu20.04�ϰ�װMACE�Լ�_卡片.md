## 1. MACE 模型简介

MACE 是一种基于机器学习的原子间势函数，能够提供高精度的原子模拟结果，并包含高阶的缺陷信息数据。

---

## 2. 计算环境配置示例

配置计算环境的硬件示例包括 AMD 7950X 处理器和 NVIDIA 4090 显卡，软件环境要求安装 CUDA 11.8、Anaconda、MKL 以及 550.67 版本的 NVIDIA 显卡驱动。

---

## 3. 创建 Conda 虚拟环境

使用 Conda 创建一个名为 `mace_env` 的虚拟环境，用于隔离 MACE 的相关依赖。

---

## 4. 激活 Conda 虚拟环境

通过 Conda 激活名为 `mace_env` 的虚拟环境，以便在该环境中安装后续软件包。

---

## 5. 安装 PyTorch 及 CUDA 依赖

在 Conda 环境中安装 PyTorch 及相关库，并指定 CUDA 版本为 11.6，安装命令包含 `pytorch torchvision torchaudio pytorch-cuda=11.6`，源指定为 `-c pytorch -c nvidia`。

---

## 6. 安装 MACE 基础依赖库

使用 Conda 安装 MACE 运行所需的第三方库，列表包括 `numpy scipy matplotlib ase opt_einsum prettytable pandas e3nn`。

---

## 7. 克隆 MACE 源码仓库

通过 Git 命令克隆 MACE 的官方 GitHub 仓库，地址为 `git@github.com:ACEsuit/mace.git`。

---

## 8. 安装 MACE 模块

使用 Pip 安装本地下载的 MACE 源码目录，命令为 `pip install ./mace`。

---

## 9. 克隆 LAMMPS MACE 分支

从 GitHub 克隆 LAMMPS 源码的 MACE 分支，使用 `--branch=mace` 和 `--depth=1` 参数，地址为 `https://github.com/ACEsuit/lammps`。

---

## 10. 下载 LibTorch 共享库

下载适用于 CUDA 11.8 的 LibTorch 共享依赖库，指定版本为 2.3.0，下载地址为 `https://download.pytorch.org/libtorch/cu118/libtorch-shared-with-deps-2.3.0%2Bcu118.zip`。

---

## 11. 解压并重命名 LibTorch

解压下载的 LibTorch 压缩包，并将生成的文件夹重命名为 `libtorch-gpu`，操作命令为 `unzip` 和 `mv`。

---

## 12. LAMMPS 编译准备

进入 LAMMPS 源码目录并创建 build 子目录，为使用 CMake 编译做准备。

---

## 13. LAMMPS 编译 CMake 配置

在 build 目录下执行 CMake 配置命令，启用 MPI、Kokkos、CUDA 及 MACE 包，并设置编译器标准为 C++17，指定 LibTorch 路径及 GPU 架构参数 `Kokkos_ARCH_ADA89`。

---

## 14. LAMMPS 编译与安装

执行 `make -j 32` 进行多线程编译，随后运行 `make install` 完成安装，过程中需确保 MKL 等前置依赖已就绪。
