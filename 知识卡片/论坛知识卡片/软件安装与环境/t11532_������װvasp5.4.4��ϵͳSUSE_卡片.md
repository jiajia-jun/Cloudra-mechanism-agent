## 1. Intel 环境配置

VASP 编译可直接使用 Intel 编译器、Intel MPI 和 Intel MKL，无需额外安装 OpenMPI 或 FFTW，该配置步骤较少且计算效率较高。在 SUSE 12 SP3 系统下安装 Intel_Parallel_Studio_XE_2019_Linux 可完成 VASP 5.4.4 的编译环境准备。需依次 source Intel 编译器环境变量、MKL 环境变量、设置 MKL_HOME 路径、动态库路径 LD_LIBRARY_PATH 以及 MPI 环境变量。
```bash
source /opt/intel/compilers_and_libraries_2019.0.117/linux/bin/compilervars.sh intel64
source /opt/intel/compilers_and_libraries_2019.0.117/linux/mkl/bin/mklvars.sh intel64
export MKL_HOME=/opt/intel/compilers_and_libraries_2019.0.117/linux/mkl
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/opt/intel/compilers_and_libraries_2019.0.117/linux/mkl/lib/intel64
source /opt/intel/impi/2019.0.117/intel64/bin/mpivars.sh
```

---

## 2. 编译 Intel FFTW 接口库

使用 Intel FFTW3 接口库文件 $(MKLROOT)/interfaces/fftw3xf/libfftw3xf_intel.a 需在相应目录下进行编译。进入 `~/.../interfaces/fftw3xf` 目录并执行 make 命令，指定编译器架构为 intel64。
```bash
cd ~/.../interfaces/fftw3xf
make libintel64 compiler=intel64
```

---

## 3. VASP 补丁应用

编译 VASP 5.4.4 前需应用补丁文件 `patch.5.4.4.16052018.gz`。操作步骤包括解压补丁包，进入 VASP 源码目录，并使用 patch 命令应用补丁。
```bash
gunzip patch.5.4.4.16052018.gz
cd vasp.5.4.4
patch -p0 < ../patch.5.4.4.16052018
```

---

## 4. Makefile 配置

以 `arch/makefile.include.linux_intel` 为模板修改 `makefile.include` 文件，需根据实际安装路径设置 MKLROOT 变量。推荐将优化选项 OFLAG 设置为 `-O2 -xhost`。
```makefile
OFLAG = -O2 -xhost
MKLROOT =/opt/intel/compilers_and_libraries_2019.0.117/linux/mkl
```

---

## 5. 编译执行与生成文件

执行 `make all` 命令开始编译 VASP。编译完成后，在 build 目录下会生成对应版本的可执行程序，包括 `vasp_gam`、`vasp_ncl` 和 `vasp_std`。

---

## 6. 环境变量配置

编译完成后，可直接将 `vasp_std` 复制到 `/bin` 目录下，或在 `~/.bashrc` 中添加相应路径以使程序全局可用。

---

## 7. 版本兼容性注意事项

若先安装 Intel 2019 版本，再安装 openmpi-1.6.5/2.02/3.13/4.0.0 等版本进行编译，需注意链接库设置，如使用 `BLACS = -lmkl_blacs_openmpi_lp64`。若先安装 Intel 2015 版本，后续安装上述版本的 OpenMPI 再编译 VASP，也可能会遇到相关问题。
