## 1. 准备工作与工具

安装 GAMESS 需准备 MobaXterm 终端模拟器及 GAMESS 安装包。MobaXterm 集成了 sftp 和 ssh 功能，支持 X11 转发，适合作为远程连接和文件传输工具。
- 下载地址: https://mobaxterm.mobatek.net/download.html
- GAMESS 安装包: https://ougrk-my.sharepoint.com/:u:/g/personal/task_ougrk_onmicrosoft_com/ERUiToNFBxxKvWL_qJPTH7gBkuJJTEY63LXdkCNMq8ephQ?e=rUjU1m

## 2. 修改 Ubuntu 源

修改 Ubuntu 源列表为阿里云镜像可提升下载速度。操作步骤为编辑 `/etc/apt/sources.list` 文件，删除原有内容并替换为镜像地址，最后执行更新命令。
- 替换内容:
  - deb http://mirrors.aliyun.com/ubuntu/ focal main restricted universe multiverse
  - deb-src http://mirrors.aliyun.com/ubuntu/ focal main restricted universe multiverse
  - deb http://mirrors.aliyun.com/ubuntu/ focal-updates main restricted universe multiverse
- 更新命令: `sudo apt-get update`

---

## 3. 安装系统依赖

安装 `build-essential`, `csh`, `gfortran`, `wget` 等基础软件包是编译 GAMESS 的必要条件。同时建议安装 `tmux` 以防止网络中断导致编译或安装过程中断。
- 安装命令: `sudo apt-get install build-essential csh gfortran wget -y`
- 安装 tmux: `sudo apt-get install tmux -y`
- 新建 tmux 会话: `tmux new -s gamess`

---

## 4. Intel MKL 安装

Intel MKL 数学库为 GAMESS 编译提供支持。需下载 Intel BaseKit 安装包并执行脚本进行安装。
- 下载命令: `cd $HOME;mkdir mkl;cd mkl;wget https://registrationcenter-download.intel.com/akdlm/irc_nas/18487/l_BaseKit_p_2022.1.2.146_offline.sh`
- 安装命令: `sudo bash l_BaseKit_p_2022.1.2.146_offline.sh`

---

## 5. GAMESS 解压与配置

解压 GAMESS 源码包后需运行 `config` 脚本进行配置。配置过程中需指定机器类型、编译器、数学库路径等关键参数。
- 解压命令: `cd $HOME;tar -xvf gamess-current.tar.gz`
- 配置命令: `cd $HOME/gamess;./config`
- 关键配置参数:
  - Machine type: linux64
  - Version: 00
  - FORTRAN compiler: gfortran
  - GFORTRAN version: 9.4
  - Standard math library: mkl
  - MKL 路径示例: /opt/intel/oneapi/mkl/2022.0.2
  - Comunication library: sockets

---

## 6. 编译 DDI 与主程序

编译前需在 `ddi/compddi` 文件中根据 CPU 核心数调整 `MAXCPUS` 参数，随后依次编译 DDI、模块和主程序。
- 修改 DDI 配置: `vi $HOME/gamess/ddi/compddi` (修改第 99 行 set MAXCPUS=128)
- 编译 DDI: `cd $HOME/gamess;make ddi`
- 编译模块: `make modules`
- 编译主程序: `make -j 64 gamess` (64 对应 CPU 核心数)

---

## 7. 配置系统共享内存

GAMESS 运行需要较大的共享内存，需修改 `/etc/sysctl.conf` 文件设置 `kernel.shmmax` 参数。该值应设置为物理内存大小乘以 1024 的三次方。
- 编辑文件: `sudo vi /etc/sysctl.conf`
- 添加内容: `# gamess shmem` \n `kernel.shmmax=N` (N 为计算得出的数值)

---

## 8. 配置运行脚本 rungms

运行脚本 `rungms` 需根据系统环境修改默认设置，包括删除临时目录的命令、默认 CPU 核心数以及主机名匹配逻辑。
- 编辑脚本: `cd $HOME/gamess;vi rungms`
- 修改点:
  - 第一行回车后添加: `rm -rf $HOME/gamess/restart`
  - 第 154 行: 将 NCPUS 默认值 1 改为实际核心数
  - 第 449 行: 将 `case master:` 中的 `master` 替换为实际主机名（通过 `hostname` 命令获取）

---

## 9. 解决可执行文件权限问题

若运行测试时提示找不到可执行文件或链接权限错误，需修改 gamess 目录下所有文件的权限以确保可执行。
- 修改权限命令: `sudo chmod 777 $HOME/gamess/*`

---

## 10. 执行标准测试

GAMESS 提供标准测试用例以验证安装是否成功。通过运行 `runall` 脚本执行测试，并使用 `checktst` 脚本检查 48 个测试案例是否全部通过。
- 运行测试: `cd $HOME/gamess;./runall 00`
- 检查结果: `cd $HOME/gamess;./tests/standard/checktst`

---

## 11. 测试常见错误处理

测试过程中若出现 901 号错误及 DDI Process 0 error code 911，通常由环境配置或资源限制引起。排查方向包括当前用户设置、共享内存配置、运行脚本参数及是否开启多线程。
- 错误代码: DDI Process 0: error code 911
- 排查项: 当前用户设置、共享内存设置、rungms 脚本参数、多线程开启状态

---

## 12. 配置并行测试参数

若需进行并行测试，需修改 `runall` 脚本中的主机名判断逻辑和运行命令参数。
- 编辑文件: `cd $HOME/gamess;vi runall`
- 修改点:
  - 将 `if (`hostname` == master)` 中的 `master` 替换为实际主机名
  - 将 `./rungms exam$NUM $VERNO 1 >& exam$NUM.log` 中的 `1` 替换为实际使用的核心数

---

## 13. 配置环境变量与别名

为方便使用 GAMESS，可在 `.bashrc` 文件中设置环境变量 `GMS` 和命令别名 `gms`。配置完成后需重新加载终端。
- 编辑文件: `cd $HOME;vi .bashrc`
- 添加内容:
  - `# gamess`
  - `export GMS=$HOME/gamess/rungms`
  - `alias gms='$HOME/gamess/rungms'`
- 使用方法: `gms name.inp 00 >& name.gms &` (name 为输入文件名)
