## 1. OSX APFS 文件系统大小写敏感性要求

Gaussian 16 在运行时对文件系统的目录大小写敏感。OSX 默认的 APFS 文件系统通常不区分大小写，而 Gaussian 16 需要在区分大小写的文件系统环境中运行。解决方法是在 Disk Utility 中创建一个新的 APFS 卷（Volume），并在格式化时选择 "APFS (Case-sensitive)"。

---

## 2. 创建大小写敏感的 Gaussian 安装卷

在 Disk Utility 中，选中主硬盘（如 Macintosh HD）所在的容器，点击加号添加新的 APFS Volume。将此卷命名为 Gaussian，格式选择 "APFS (Case-sensitive)"，完成后该挂载卷即可用于 Gaussian 的安装和运行。

---

## 3. PGI Compilers 版本要求与安装

Gaussian 16 编译需要安装 PGI Compilers，推荐使用社区版（community edition）。安装时需记住具体的版本号，例如文中使用的版本为 19.4，该版本号后续将用于配置文件的路径匹配。

---

## 4. PGI 编译器环境配置

PGI Compilers 安装完成后，其文件通常位于 `/opt/pgi/` 目录下。通过双击该目录下的 `PGI.terminal` 文件可以启动 PGI 的终端环境，以便进行后续的 Gaussian 编译操作。

---

## 5. Gaussian 16 编译前的环境变量设置

在开始编译前，需设置 `g16root` 环境变量指向 Gaussian 源码目录（如 `/Volumes/Gaussian/g16`），并进入该目录执行初始化授权命令 `bsd/install`。操作指令如下：
```bash
export g16root=/Volumes/Gaussian/g16
cd $g16root
cd g16
bsd/install
```

---

## 6. 修改 g16.login 以支持 OSX 和 PGI 版本

需修改 `$g16root/g16/bsd/g16.login` 文件中的 `PGIDIR` 检测逻辑。在 `foreach y` 列表中添加 `osx86-64`，并在 `foreach x` 版本号列表中添加实际的 PGI 版本（如 `19.4`），以确保系统能正确找到编译器路径。

---

## 7. 修改 setup-make 强制指定架构

为避免自动检测架构失败，需修改 `$g16root/g16/bsd/setup-make` 文件。将 `set mach = `gau-hname`` 这一行修改为强制指定架构：
```bash
set mach = "i386-mac64"
```

---

## 8. Gaussian 16 编译命令

完成环境变量和配置文件修改后，需重新加载配置文件并执行编译命令。切换到 csh 环境，source 配置文件后运行构建命令：
```bash
/bin/csh
source $g16root/g16/bsd/g16.login
bsd/bldg16 all
```

---

## 9. 修改 g16.profile 移除 ulimit 限制

编译完成后，需修改 `$g16root/g16/bsd/g16.profile` 文件，删除其中的 `ulimit -n hard` 设置。这步操作是为了调整系统资源限制，防止运行 Gaussian 时出现错误。

---

## 10. Gaussian 16 运行环境配置

每次运行 Gaussian 16 前，需要在终端中设置环境变量并加载配置文件：
```bash
export g16root=/Volumes/Gaussian/g16
source $g16root/g16/bsd/g16.profile
```
为方便使用，可将上述命令添加到用户的 `.profile` 或 `.bash_profile` 中实现自动加载。

---

## 11. GaussView 6 OSX 版安装与启动

GaussView 6 (gv6) 的文件需放置在 `/Volumes/Gaussian/g16` 目录下，并确保已完成授权设定。启动 GaussView 6 可直接在终端执行脚本：
```bash
/Volumes/Gaussian/g16/gv/gview.sh
```
