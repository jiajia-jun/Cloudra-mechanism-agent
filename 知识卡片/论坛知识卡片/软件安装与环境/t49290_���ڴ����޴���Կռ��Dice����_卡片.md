## 1. Dice 依赖库 HDF5 编译安装

HDF5 是 Dice 运行所需的依赖库之一，需从官网下载源代码进行编译安装。配置时需指定安装路径，随后执行 make 多线程编译及安装命令。
- wget https://www.hdfgroup.org/downloads/hdf5/source-code/ (需访问官网获取下载链接)
- ./configure --prefix=/data/home/drwg/hdf5
- make -j
- make install

---

## 2. Dice 依赖库 Boost 编译安装

Boost 库是 Dice 的依赖项，安装过程包括运行引导脚本和修改配置文件以启用 MPI 支持。编译时需生成静态和动态链接库。
- ./bootstrap.sh
- 在 project-config.jam 中添加 using mpi ;
- ./b2 -j6 --target=shared,static

---

## 3. Dice 编译配置参数设置

编译 Dice 前需在 Makefile 中设置环境变量和库路径，以适配 Intel 编译器及相关依赖库。关键配置包括启用 Intel 和 AVX2 指令集，以及指定 Boost、Eigen、HDF5 和 MKL 的路径与链接参数。
- USE_INTEL = yes
- HAS_AVX2 = yes
- BOOST=/data/home/drwg/boost_1_71_0
- EIGEN=./eigen/
- HDF5=/data/home/drwg/hdf5
- MKL=/data/app/intel/oneapi/mkl/latest
- LIB_MKL = -L$(MKL)/lib/intel64/ -lmkl_intel_ilp64 -lmkl_gnu_thread -lmkl_core
- LIB_BOOST = -L$(BOOST)/stage/lib
- LIB_HDF5 = -L$(HDF5)/lib -lhdf5

---

## 4. Dice 编译与基础测试

执行 make 命令进行多线程编译，并在 tests 目录下修改测试脚本以适配 Python 3 和指定 MPI 进程数。测试过程包含 FCIQMC 和 SHCI 功能验证，其中 FCIQMC 测试可能出现 Hubbard 模型能量偏差。
- make -j
- sed -i 's/python2/python3/g' *sh
- sed -i 's/np 4/np 28/g' *sh
- sh runTests.sh

---

## 5. SHCI 功能模块测试

Dice 中的 SHCI 模块测试需要进入 SHCI 目录，修改脚本解释器为 Python 3 并调整 MPI 进程数。运行测试脚本可验证 SHCI 功能是否正常。
- cd SHCI
- sed -i 's/python/python3/g' *sh
- sed -i 's/np 4/np 28/g' *sh
- sh runTests.sh

## 6. PySCF 接口 pyscf-shciscf 安装

通过 pip 安装 pyscf-shciscf 包以建立 PySCF 与 Dice 的连接。安装包托管在 GitHub 上，需使用 git+ 协议进行用户级安装。
- pip3 install git+https://github.com/pyscf/shciscf --user

---

## 7. PySCF-SHCISCF 接口配置

安装 pyscf-shciscf 后，需修改其配置文件 settings.py 以指定 Dice 可执行文件路径、运行目录及 MPI 命令前缀。此步骤确保 PySCF 能正确调用 Dice 后端进行计算。
- SHCIEXE = '/data/home/drwg/Dice-master/bin/Dice'
- SHCISCRATCHDIR = "."
- SHCIRUNTIMEDIR = '.'
- MPIPREFIX = 'mpirun -np 28'

---

## 8. 环境变量设置

为正确运行 Dice 及其依赖库，需在终端脚本中加载 Intel 环境变量并添加 Boost 和 HDF5 的库路径至 LD_LIBRARY_PATH。PATH 环境变量也需包含 Boost 目录。
- source /data/app/intel/oneapi/setvars.sh
- export PATH=$PATH:/data/home/drwg/boost_1_71_0
- export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/data/home/drwg/boost_1_71_0/stage/lib
- export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/data/home/drwg/hdf5/lib

## 9. PySCF 调用 Dice 进行 CASSCF 计算示例

在 PySCF 中构建 C2 分子模型并进行 RHF 计算后，可利用 SHCISCF 模块调用 Dice 进行变分优化。计算设置需指定活性空间大小、MPI 进程数、随机迭代参数及截断阈值，最终执行 mc1step 方法获得能量。
- from pyscf.shciscf import shci
- mch = shci.SHCISCF( mf, norb, nelec )
- mch.fcisolver.mpiprefix = 'mpirun -np 2'
- mch.fcisolver.stochastic = True
- mch.fcisolver.sweep_epsilon = [ 5e-3, 1e-3 ]
- e_shci = mch.mc1step()[0]
