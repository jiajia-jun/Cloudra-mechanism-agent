## 1. IPMI 接口物理连接

IPMI 接口通常位于服务器主板或机箱后部，需使用网线将其接入到路由器或交换机中以便进行网络通信。

---

## 2. IPMI 功能概述

IPMI（智能平台管理接口）是一项独立于操作系统和硬件底层的管理标准，可在操作系统不可见或无响应时实现远程电源控制及重启等操作。

---

## 3. IPMI 网络配置

IPMI 设备支持通过静态 IP 地址或 DHCP 获取网络地址，连接至与主机相同的局域网后，可通过 IP 地址进行访问。示例中 IPMI 的 IP 地址为 192.168.31.252。

---

## 4. IPMI 默认登录凭证

IPMI 登录通常需要用户名和密码进行验证，部分微服务器的默认用户名为 ADMIN。用户可通过 Web 页面登录管理后台以查看和配置系统信息。

---

## 5. ipmitool 安装

ipmitool 是一款用于在 Linux 系统下管理 IPMI 平台的工具。在 Ubuntu 系统中，可使用命令 `sudo apt install ipmitool -y` 进行安装。

---

## 6. 服务器散热模式配置

微服务器提供多种预设的散热控制模式（如静音、全速等），这些模式可通过 IPMI 的 Web 管理后台进行设置和切换。
