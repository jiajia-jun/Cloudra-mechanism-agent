## 1. CP2K Intel全工具链编译方案概述

CP2K官方文档提供了详细的Toolchain安装说明，但对于Intel全环境编译，手动配置依赖库可获得更多定制化功能。手动安装过程较为繁琐，但能确保所有组件（如ELPA、Libint、Libxc等）均使用Intel编译器构建，从而最大化性能。在使用Intel编译器编译CP2K时，链接的库也建议使用Intel版本以避免兼容性问题。

---

## 2. 编译安装elpa-2020.11.001

安装ELPA Eigenvalue Solvers时，需加载conda、gcc和intel模块。配置命令需指定安装路径、开启OpenMP支持，并设置Intel编译器及优化参数（-O3 -xHost），同时正确配置SCALAPACK的链接标志和编译标志，指向MKL库路径。
```bash
module load conda gcc intel
./configure --prefix=/opt/package_cp2k/elpa-2020.11.001 --enable-openmp FC=mpiifort FCFLAGS="-O3 -xHost" CC=mpiicc CFLAGS="-O3 -xHost" SCALAPACK_LDFLAGS="-L$MKLROOT/lib/intel64 -lmkl_scalapack_lp64 -lmkl_gf_lp64 -lmkl_sequential -lmkl_core -lmkl_blacs_intelmpi_lp64 -lpthread -lm -Wl,-rpath,$MKLROOT/lib/intel64" SCALAPACK_FCFLAGS="-L$MKLROOT/lib/intel64 -lmkl_scalapack_lp64 -lmkl_gf_lp64 -lmkl_sequential -lmkl_core -lmkl_blacs_intelmpi_lp64 -lpthread -lm -I$MKLROOT/lib/intel64/lp64" > configure.log 2>&1
make install -j
```

## 3. 编译安装libxc-5.1.7

Libxc是一个交换关联泛函库，编译时推荐使用Intel编译器开启共享库支持。配置过程需指定CC和FC为Intel编译器，并添加-O3 -xHost优化选项。
```bash
./configure --prefix=/opt/libxc-5.1.7 --enable-shared CC=icc FC=ifort CFLAGS="-O3 -xHost" FCFLAGS="-O3 -xHost"> configure.log 2>&1
make install -j
```

## 4. 编译安装gsl-2.6

GSL（GNU Scientific Library）的编译配置较为简单，需指定使用Intel C编译器及优化参数。
```bash
./configure --prefix=/opt/gsl-2.6 CC=icc CFLAGS="-O3 -xHost" > configure.log 2>&1
make -j
make install
```

## 5. 编译安装libint-v2.6.0-cp2k-lmax-5

Libint用于计算电子排斥积分，CP2K特供版需要开启Fortran支持。推荐使用CMake而非configure进行配置，因为直接使用configure配合--enable-fortran可能在install阶段报错。CMake配置时需指定Boost头文件路径及安装前缀。
```bash
module load cmake gcc intel/2020u2 conda
export CC=mpiicc CXX=mpiicpc FC=mpiifort
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=/opt/package_cp2k/libint-v2.6.0-cp2k-lmax-5 -DENABLE_FORTRAN=ON -DBoost_INCLUDE_DIR=/opt/package_cp2k/boost-1.78.0/include
cmake --build . 
cmake --build . --target install
```

## 6. 编译安装plumed-2.6.2依赖（ncurses与vim）

Plumed的安装依赖于vim中的xxd工具，若系统未预装则需要手动编译ncurses和vim。首先配置ncurses，指定使用Intel编译器及ncurses共享库支持；随后配置vim，指定ncurses的库路径。
```bash
./configure --prefix=/opt/ncurses-6.3 CC=icc CXX=icpc CFLAGS="-O3 -xHost" CXXFLAGS="-O3 -xHost" --with-shared
make
make install

./configure --prefix=/opt/vim-8.2 CC=icc CFLAGS="-O3 -xHost" --with-tlib=ncurses LDFLAGS=-L/opt/ncurses-6.3/lib
make
make install
```

## 8. 编译安装spglib-1.16.0

Spglib用于空间群对称性识别，使用CMake构建时需导出Intel编译器环境变量。安装完成后，需手动创建include/spglib子目录并将头文件拷贝进去，以确保CP2K能正确找到头文件。
```bash
mkdir build && cd build
export CC=icc
export FC=ifort
cmake .. -DCMAKE_INSTALL_PREFIX=/opt/package_cp2k/spglib-1.16.0
make -j
make install
mkdir /opt/package_cp2k/spglib-1.16.0/include/spglib
cp /opt/package_cp2k/spglib-1.16.0/include/spglib.h /opt/package_cp2k/spglib-1.16.0/include/spglib/
```

## 9. 编译安装libxsmm-1.16.1

Libxsmm提供小矩阵乘法加速，其Makefile直接支持指定编译器和安装前缀。编译时需设置MALLOC=0并指定Intel C++/C/Fortran编译器。
```bash
make -j MALLOC=0 CXX=icpc CC=icc FC=ifort PREFIX=/opt/package_cp2k/libxsmm-1.16.1
make -j MALLOC=0 CXX=icpc CC=icc FC=ifort PREFIX=/opt/package_cp2k/libxsmm-1.16.1 install
```

## 10. 编译安装libvori-210412

Libvori是用于Voronoi分析的库，使用CMake构建时需导出icpc作为CXX编译器。配置时建议开启CMAKE_INSTALL_RPATH_USE_LINK_PATH以处理运行时库路径问题。
```bash
mkdir build && cd build
export CXX=icpc
cmake .. -DCMAKE_INSTALL_PREFIX=/opt/package_cp2k/libvori-210412 -DCMAKE_INSTALL_RPATH_USE_LINK_PATH=TRUE
cmake --build .
cmake --build . --target install
```

## 11. 编译安装SpFFT-1.0.5

SpFFT是稀疏FFT库，CMake配置时需开启OpenMP和MPI支持（DSPFFT_OMP=ON, DSPFFT_MPI=ON）。注意编译过程中使用了-O2优化参数，也可根据需要改为-O3。
```bash
mkdir build && cd build
export CXX=icpc
cmake .. -DCMAKE_INSTALL_PREFIX=/opt/package_cp2k/SpFFT-1.0.5 -DSPFFT_OMP=ON -DSPFFT_MPI=ON -DSPFFT_INSTALL=ON
make install
```

## 12. CP2K编译配置文件arch文件编写

参考Linux-x86-64-intel-regtest.psmp文件，创建本地编译配置文件如local.psmp。文件需定义编译器（CC=mpiicc, FC=mpiifort）、依赖库路径及头文件路径，并设置DFLAGS以开启ELPA、LIBINT、LIBXC、PLUMED等支持。注意需包含Plumed的静态链接配置文件。
```makefile
include /opt/package_cp2k/plumed-2.6.2/lib/plumed/src/lib/Plumed.inc.static
DFLAGS = -D__ELPA -D__FFTW3 -D__GSL -D__LIBINT -D__LIBVORI -D__LIBXC -D__LIBXSMM -D__MAX_CONTR=4 -D__MKL -D__MPI_VERSION=3 -D__PLUMED2 -D__SPGLIB -D__parallel -D__SCALAPACK -D__CHECK_DIAG
```

## 13. CP2K编译优化与特殊规则

编译选项中CFLAGS和FCFLAGS使用-O2级别优化（若需更高性能可尝试-O3），并开启了xHost、OpenMP及SIMD指令。针对mp2_optimize_ri_basis.F文件，由于高优化级别可能导致内存泄漏，需要单独编写规则使用-O0级别编译该文件。
```makefile
mp2_optimize_ri_basis.o: mp2_optimize_ri_basis.F
    $(FC) -c $(subst O2,O0,$(FCFLAGS)) $<
```

## 14. CP2K编译与测试命令

配置好arch文件后，使用make命令启动编译，ARCH参数指定配置文件名，VERSION指定版本（psmp表示并行+MPI+OpenMP）。编译完成后可运行regtest进行测试，全Intel编译版本在Intel Xeon E5-2640 v2 (16核) 上完成全套测试耗时约54分钟。
```bash
make -j ARCH=local VERSION=psmp
make -j ARCH=local VERSION=psmp test
```

## 15. Intel全工具链与GCC-OpenMPI-MKL性能对比

在对比测试中，针对COF体系（case1）和特定输入文件（case2），全Intel编译版本的CP2K运行速度明显优于GCC-OpenMPI-IntelMKL版本。测试结果显示，全Intel版本的运行速度比GCC-OpenMPI-IntelMKL版本快约20%~30%。
