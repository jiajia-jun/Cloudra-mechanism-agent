## 1. 网络访问受限场景下的文件传输问题

在服务器 B 需要下载资源但无法直接连接外网的情况下，通常需要将文件下载到本地计算机 A 后再手动上传至服务器。手动上传过程繁琐，且涉及 API 密钥等敏感信息时直接传输存在安全风险，管理 GitHub 项目等操作也因频繁上传变得不便。

---

## 2. SSH 端口转发的基本原理

SSH 端口转发利用充当“快递员”角色的转发机制，将服务器 B 发出的网络请求转发至具有公网访问权限的计算机 A。计算机 A 代表服务器 B 访问目标网络资源，并将获取的数据通过 SSH 隧道回传给服务器 B，从而实现服务器 B 间接访问外网的目的。

---

## 3. SOCKS 代理在 SSH 隧道中的应用

通过在服务器 B 上配置 SSH 端口转发，可以将发出的网络数据重定向至本地（如 1080）端口，建立 SOCKS 代理通道。SOCKS 代理支持多种底层协议的应用程序流量转发，能够解决特定网络环境下的连接限制问题。
