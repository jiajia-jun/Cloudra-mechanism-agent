## 1. Gromacs 2024.6 GPU Windows 编译环境

该版本的 Gromacs 2024.6 GPU Windows 编译环境包含 x64 Native Tools Command Prompt for VS2022、fftw 3.3.10 以及 cuda toolkit 11.8。此编译版本支持 RTX 50 系显卡。原文参考了 Huschein 提供的 GROMACS 2023 Windows 编译方法及相关修改源码方案。

## 2. 编译源码参考来源
