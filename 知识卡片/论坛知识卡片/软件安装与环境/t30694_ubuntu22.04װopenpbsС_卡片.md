## 1. OpenPBS 在 Ubuntu 22 上的编译依赖

在 Ubuntu 22 系统上安装 OpenPBS 时可能会遇到编译错误。排查后发现，该系统的环境与 CentOS 8 不同，需要特定版本的编译工具链。
- 经验证，OpenPBS 对 Python 版本有要求，默认 Python 3.8 无法通过编译，降级至 Python 3.6 后问题解决。
- 同时，GCC 版本需保持在 8 或 9（Ubuntu 22 默认为 11），安装 GCC-9 可确保 OpenPBS-master 编译通过。

---

## 2. OpenPBS 编译工具链版本匹配

成功编译 OpenPBS-master 需要严格匹配依赖软件的版本，建议直接参考源码包中的 INSTALL 文件进行配置。
- 关键依赖版本要求为：Python 3.6 以及 GCC 8-9。
- 只要环境变量和依赖版本符合要求，按照源码中的 INSTALL 文档操作通常可以顺利完成安装。

---

## 3. OpenPBS 计算节点添加方法

完成 OpenPBS 的安装和配置后，需要手动将计算节点添加到服务器配置中才能进行任务调度。
- 具体操作可使用 `qmgr` 命令执行：`qmgr -c 'create node host_name'`。
- 此步骤需要在服务端执行，将 host_name 替换为实际计算节点的主机名。

---

## 4. OpenPBS 与 Torque 的安装对比

相较于 Torque，新版 OpenPBS 的安装流程被描述为更为简单。
- OpenPBS 的安装过程对用户较为友好。
- 这种简便性有利于用户快速搭建和管理集群环境。
