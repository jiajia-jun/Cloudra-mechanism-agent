## 1. CPMD 软件简介

CPMD (Car-Parrinello Molecular Dynamics) 是一款基于平面波赝势方法的从头算分子动力学模拟软件包，由 IBM 公司与 Max-Planck 研究所共同开发。该软件适用于对分子、原子和凝聚态物质的研究，广泛应用于学术界和工业界。CPMD 能够处理有限体系（如分子）和周期性体系（如晶体、固体、表面及聚合物），支持结构优化和寻找化学反应过渡态。它提供源代码，主要运行在 Unix/Linux 系统的高性能并行计算平台上。

---

## 2. CPMD 许可证申请与源码下载

CPMD 为非免费软件，用户需通过官方网站提交申请以获取下载权限。提交申请后，通常在约 2 个工作日内会收到包含下载链接的邮件通知。获取的源码包通常包含主程序 `cpmd-v4.3.tar.gz`、测试包 `cpmd-test.tar.gz`、赝势文件 `pseudo_std.tar.gz` 以及 Goedecker 赝势包 `Goedecker.tar.gz`。

---

## 3. CPMD 编译依赖环境

编译 CPMD 需要预先配置 MPI 并行环境、数学库 BLAS/LAPACK（可使用 MKL）以及 FFTW3。推荐的编译环境组合为 Intel 编译器（Intel C++/Fortran）、Intel MPI、FFTW3 和 Intel MKL。

---

## 4. Intel 工具链环境变量配置

在使用 Intel 编译器、MPI 和 MKL 编译 CPMD 前，需设置相关的环境变量。这包括加载编译器变量、Intel MPI 路径以及 MKL 路径，具体示例如下：
```bash
source /public/home/jinnzh/intel/bin/compilervars.sh intel64
export PATH=/public/home/jinnzh/intel/bin:$PATH
export LD_LIBRARY_PATH=/public/home/jinnzh/intel/lib/intel64:$LD_LIBRARY_PATH
export INCLUDE=/public/home/jinnzh/intel/include:$INCLUDE
###### impi ####
export PATH=/public/home/jinnzh/intel/impi/2019.5.281/intel64/bin:$PATH
export LD_LIBRARY_PATH=/public/home/jinnzh/intel/impi/2019.5.281/intel64/lib:$LD_LIBRARY_PATH
export INCLUDE=/public/home/jinnzh/intel/impi/2019.5.281/intel64/include:$INCLUDE
###### intel MKL ######
export PATH=/public/home/jinnzh/intel/mkl/bin:$PATH
export LD_LIBRARY_PATH=/public/home/jinnzh/intel/mkl/lib/intel64:$LD_LIBRARY_TATH
export INCLUDE=/public/home/jinnzh/intel/mkl/include:$INCLUDE
```

## 5. FFTW3 编译配置

下载 `fftw-3.3.8.tar.gz` 并解压后，需使用 `icc` 和 `mpiicc` 进行编译配置以生成支持 MPI 和 OpenMP 的双精度版本。配置命令示例如下：
```bash
./configure --prefix=/public/home/jinnzh/fftw3/intelmpiicc-double --enable-threads --enable-mpi CC=icc MPICC=mpiicc F77=mpiifort --enable-openmp --enable-avx2 --enable-shared
make
make install
```
编译完成后，需将 FFTW3 的 `bin`、`include` 和 `lib` 路径添加至环境变量中。

---

## 6. CPMD 构建配置与 Makefile 修改

进入 CPMD 源码目录，运行 `./configure.sh LINUX-X86_64-INTEL-IMPI-FFTW` 生成 Makefile。随后需编辑 `Makefile`，重点修改 `LFLAGS` 变量，显式指定 FFTW3 的库文件路径（例如 `-L/public/home/jinnzh/fftw3/intelmpiicc-double/lib`），以确保链接时能正确找到 `libfftw3_mpi`。

---

## 7. CPMD 执行编译

在完成 Makefile 的修改后，在 CPMD 源码根目录下执行 `make` 命令进行编译。编译成功后，会在源码目录下生成 `bin` 和 `lib` 文件夹，其中 `bin` 文件夹包含可执行文件 `cpmd.x`，`lib` 文件夹包含目标文件 `libcpmd.a`。

---

## 8. CPMD 可执行文件环境变量配置

编译完成后，建议将 CPMD 可执行文件所在的 `bin` 目录添加到系统 PATH 环境变量中，以便全局调用。可通过在 `.bashrc` 文件中添加如下语句实现：
```bash
export PATH=/public/home/jinnzh/sourcecode/cpmd/CPMD/bin:$PATH
```

---

## 9. CPMD 安装测试验证

安装完成后，可使用官方提供的测试包 `cpmd-test.tar.gz` 进行验证。解压测试包并进入测试用例目录（如 `CPMD-test/std/c120/`），使用 MPI 运行测试任务，例如：
```bash
mpirun -np 18 cpmd.x inp-1 > test1.log
```
计算结束后，需将生成的输出文件与测试包提供的标准结果文件（如 `out-1`）进行比对。若电子梯度、总能量、动能及静电能等关键数值与标准结果基本一致，则表明软件安装正确。
