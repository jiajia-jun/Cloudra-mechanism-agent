## 1. 使用 Singularity 构建 CP2K 镜像

通过 Singularity 直接构建基于 Docker 的 CP2K 镜像文件。
- 执行命令 `singularity build cp2k-9.1.SIF docker://cp2k/cp2k:9.1` 可完成构建。
- 构建过程需要等待一段时间，最终将生成名为 cp2k-9.1.SIF 的文件。

---

## 2. CP2K 镜像文件的安装配置

将生成的 SIF 镜像文件移动至用户目录下以便使用。
- 创建目录 `mkdir $HOME/bin`。
- 执行命令 `mv cp2k-9.1.SIF $HOME/bin/cp2k-v9.1.exe` 将镜像文件移动并重命名。

---

## 3. 运行修改版 CP2K 镜像

无需安装 MPI 即可直接调用修改后的 CP2K 镜像文件进行计算。
- 运行命令格式为 `cp2k-v9.1.exe <线程数> <输入文件> > logfile &`。
- 使用 8 线程运行示例：`cp2k-v9.1.exe 8 H2O-128.inp > logfile &`。

---

## 4. 修改版镜像的运行特征

该修改版 CP2K 镜像在运行时会自动开启多线程。
- 进程监控中会出现 8 个 cp2k.psmp 进程。
- 每个 CPU 核心的占用率约为 200%。

---

## 5. 运行环境要求

使用此修改版 CP2K 镜像对系统环境有特定要求。
- 系统中无需安装任何 MPI。
- 不需要加载任何 module。
- 不需要在 ~/.bashrc 中进行任何 MPI 设定。

---

## 6. 官方原版与 Docker 替代方案

若偏好使用官方原版镜像，可直接使用官方 Docker。
- 对于习惯使用 Docker 的用户，可直接使用 docker run 命令运行。
