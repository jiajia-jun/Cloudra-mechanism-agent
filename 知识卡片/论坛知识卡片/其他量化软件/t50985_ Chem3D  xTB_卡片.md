## 1. GitHub 资源库 xTB_in_Chem3D

xTB_in_Chem3D 是一个旨在帮助化学专业初学者入门计算化学的演示项目。该项目展示了如何结合使用 Chem3D 和 MOPAC，并详细说明了在 Chem3D 中直接调用 xTB 进行结构优化的方法。相关演示还包括利用 MultiWFN 配合 xTB 和 molden 文件展示轨道波函数。该项目的代码和文档托管在 GitHub 平台上。

## 2. 计算化学入门工具选择

初学者常使用 Chem3D 自带的 MM2 力场进行分子力学优化。对于初学者而言，Chem3D 是一个直观且易于上手的可视化工具。利用此类图形化界面软件可以帮助初学者快速构建和理解分子模型。
