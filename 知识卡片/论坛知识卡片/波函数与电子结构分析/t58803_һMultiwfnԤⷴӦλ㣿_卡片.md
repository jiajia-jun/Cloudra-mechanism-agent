## 1. 反应体系双描述符文件示例

react.bwc 是一个针对反应体系生成的双描述符配置文件示例，用于定义计算参数与设置。
- 该文件包含了用于计算双描述符所需的基础输入信息，可直接作为模板使用。
- 双描述符通常结合 ESP（静电势）进行可视化分析，以展示反应位点。
- 文件大小为 14.83 KB，可在相关附件中获取。

## 2. Multiwfn 与 banewfn 的双描述符预测

Multiwfn 软件支持预测化学反应中的亲核/亲电位点及双描述符分析功能。
- banewfn 软件已经实现了针对 Multiwfn 的模块化封装，优化了相关功能的调用流程。
- 通过 banewfn 可以更便捷地利用 Multiwfn 进行化学性质的自动化计算与绘图。
- 相关技术细节与原理可参考 Multiwfn 官方论坛帖及教程视频。

---

## 3. banewfn 软件介绍与资源

banewfn 是基于 Multiwfn 开发的模块化工具，旨在简化和扩展 Multiwfn 的使用场景。
- 官方提供了详细的项目手册（BaneWfn_Project_Manual_zh.pdf），介绍软件功能与使用方法。
- 用户可参考该手册了解如何利用 banewfn 进行自定义功能的开发与集成。
- 软件相关教程视频已发布于 Bilibili 平台，供用户直观学习操作流程。

## 4. banewfn 运行环境准备

使用 banewfn 前需安装并配置 Git Bash、VMD 和 Multiwfn 运行环境。
- Git Bash 和 Multiwfn 必须正确安装并添加至系统 PATH 环境变量中。
- VMD 软件同样需要安装并配置好环境变量，以便进行可视化调用。
- 这些基础工具是 banewfn 正常运行的前置依赖。

## 5. banewfn Windows 安装包

banewfn 提供了 Windows 平台的一键安装程序 banewfn_setup.exe，简化了部署过程。
- 在安装 Git Bash 和 Multiwfn 并配置好环境后，可直接运行该安装程序。
- 安装过程中通常只需按照提示点击“next”即可完成默认配置。
- 该安装包体积约为 3.44 MB，适用于 Windows 系统。

## 6. banewfn Linux 安装脚本

Linux 系统下需要手动运行 shell 脚本 banewfn-1.3.0-linux-x86_64.sh 来安装 banewfn。
- 用户需下载该脚资料件并在终端赋予执行权限后运行。
- 安装过程可能需要根据系统环境手动配置相关路径。
- 该安装文件针对 x86_64 架构的 Linux 系统进行了编译。

## 7. 反应体系双描述符可视化结果

双击 react.bwc 文件后生成的可视化结果展示了反应体系的双描述符分布。
- 结果中包含多个文件，每个文件均对应不同的快照或构象。
- 每个结果文件均包含标准的 ESP 映射数据，用于直观显示电子特征。
- 可视化图形通过 vcube 工具进行渲染，以三维形式呈现静电势分布。

---

## 8. Vcube 可视化操作

使用 vcube 工具可以打开并查看生成的双描述符与 ESP 映射结果。
- 双击生成的文件即可直接启动 vcube 进行加载。
- vcube 支持同时打开并排显示多个结果文件，便于对比分析。
- 软件界面提供了标准的交互功能，用于旋转、缩放和检查分子模型。

## 9. CDFT 反应活性分析配置

cdft.bwc 是一个用于概念密度泛函理论（CDFT）反应活性分析的配置文件。
- 该文件定义了 Fukui 函数（f+, f-）、双描述符以及相关的加权公式。
- 进行此类分析需要提供分子动态轨迹生成的 wfn 文件作为输入。
- 文件大小为 978 Bytes，包含了计算反应活性指数所需的必要参数。
