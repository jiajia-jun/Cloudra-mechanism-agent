## 1. MCPB.py 自动化批处理脚本功能

该脚本旨在对含金属离子的蛋白质体系进行自动化处理，以简化使用 MCPB.py 构建金属中心力场的操作流程。脚本目前支持单核及双核金属中心体系，但不支持簇合物和金属有机框架（MOF）。

---

## 2. 脚本开发语言与依赖

该批处理脚本完全使用 Python 编写，基于 AmberTools 环境，需要安装额外的依赖包包括 dacase、acpype、psutil 和 hydra-core。

---

## 3. 环境安装命令

安装 AmberTools25 及相关依赖的命令如下，必须设置 conda-forge 频道并优先安装 ambertools-dac：
```text
conda create --name AmberTools25 python=3.12
conda activate AmberTools25
conda config --add channels conda-forge
conda config --set channel_priority strict
conda install dacase::ambertools-dac=25
source $CONDA_PREFIX/amber.sh
conda install -c conda-forge acpype
pip install psutil
pip install hydra-core --upgrade
```

---

## 4. H++ 输入文件格式要求

使用 H++ 网站生成脚本所需的初始 PDB 文件时，需采用默认参数。从 H++ 下载并保留后缀为 `0.15_80_10_pH6.5_{sys_name}.top` 和 `0.15_80_10_pH6.5_{sys_name}.crd` 的文件，原始 `{sys_name}.pdb` 文件中应去除水分子和多余离子，且必须确保 HETATM 仅对应金属离子。

---

## 5. 脚本运行方式

将 H++ 生成的原始 PDB 文件与脚本放置于同一目录下，在终端执行 `nohup python batch_run.py > batch_run.log 2>&1 &` 即可启动自动化处理。脚本会自动识别目录中的 PDB 文件并以文件名作为系统名称进行后续计算。

---

## 6. CPU 核心数阈值设置

配置文件中的 `cpu_threshold` 参数用于设定脚本判断系统 CPU 负载的阈值，当当前系统 CPU 负载低于此值时，脚本才会开启新的计算任务。

---

## 7. 预留核心数参数

配置文件中的 `reserve_cores` 参数用于指定系统需要预留的 CPU 核心数，脚本会将总核心数减去该数值作为实际可用的计算资源。

---

## 8. 并行计算核心分配逻辑

脚本实际使用的核心数由 `reserve_cores` 限制，即使终端环境变量 `nproc` 设置为 128 且硬件有 64 个物理核，若 `reserve_cores` 设为 32，则脚本实际只会使用 32 个核心。每个 Gaussian 计算任务使用的核心数由 `g16_settings` 中的 `nproc` 决定，剩余可用核心数小于任务所需核心数时，任务将不会启动。

---

## 9. Morse 势能函数参数

对于涉及多层体系或需要将 GROMACS 拓扑文件 `[bonds]` 中的键合项转换为 Morse 势能函数形式的情况，需在配置中设置 `Morse_run`、`Morse_D` 和 `Morse_beta` 参数。若不涉及此类转换，设置 `Morse_run=False`。

---

## 10. 系统名称与金属离子设置

配置文件中 `name` 参数用于指定系统名称，默认会与目录下的 PDB 文件名保持一致。`metal_name` 参数必须与 PDB 文件中金属离子的名称完全一致。

---

## 11. 组氨酸质子化状态修正

配置文件中 `modify_hip` 参数设为 `True` 时，脚本会根据设定的截断距离 `cut_off` 修正组氨酸的质子化状态。当 Nδ1 原子在截断距离内时，H++ 生成的 PDB 中被标记为 HIP 或 HIE 的残基将被修正为 HID；当 Nε2 原子在截断距离内时，被标记为 HIP 或 HID 的残基将被修正为 HIE。

---

## 12. Gaussian 任务错误处理逻辑

脚本处理 Gaussian 计算任务的逻辑采用队列机制，依次读取任务文件进行提交。若检测到上一个 Gaussian 计算报错，脚本会自动终止并停止启动后续的新计算任务。

---

## 13. 脚本功能局限与规划

该脚本已实现含金属蛋白质体系的 MCPB.py 自动化流程及 Gaussian 计算监控，但尚未实现对硬件配置的自动检测、双核及以上金属中心的全功能支持以及簇合物和 MOF 的处理。未来计划增加如 H++ 参数自动化集成、小分子配体自动处理等进阶功能。
