## 1. ztop 工具简介

ztop 是一个基于 Python 脚本的工具，用于通过片段组装的方式构建聚合物模型。该工具支持生成 Gromacs、Amber、Charmm 等格式的拓扑文件和坐标文件，能够自动对齐接口并合并片段。ztop 的安装及详细使用方法可参考相关量子化学论坛的优化帖。

---

## 2. 片段组装基本原理

片段组装的基本逻辑是将聚合物分解为重复的片段单元。用户需要提供小分子片段的结构文件，工具将这些片段按指定顺序连接成大分子。输入的小分子结构文件支持 Gromacs、Amber、Charmm 格式，可直接使用 GAFF2 或 Amber 中的力场参数；若无现成拓扑文件，需手动生成。

---

## 3. 片段提取方式

用户通过指定小分子结构文件来进行切割，得到片段。同一分子可进行不同方式的切割得到不同片段，也可从不同的分子得到相同的片段。这些片段可被重复使用，或通过连接拼合成大分子。用户通过指定命令将不同片段按序列连接，同时生成对应的拓扑文件和坐标文件。

---

## 4. ztop 文件支持格式

ztop 支持的输入文件格式包括 Gromacs、Amber、Charmm 格式的拓扑文件和坐标文件。输出文件同样支持这些格式。

---

## 5. DON 片段拓扑与结构生成

对于 DON 片段，若已有 DON.log 和 DON.fchk 文件，可使用默认的 resp 电荷和 gaff2 力场生成拓扑和坐标文件。具体命令如下：
```bash
cp PI_poly_init/DON.log ./
cp PI_poly_init/DON.fchk ./
ztop.py -g "DON.log" -r e -o DON.top,DON.gro
```

---

## 6. DON 片段定义与保存

定义 DON 片段需指定 top 文件、gro 文件、位点、残基名和注释。位点参数 D12:11-22 和 D11:8-21 定义了连接点，需注意原子顺序与片段定义顺序一致。使用 `--savelib` 选项将生成的片段库文件保存在当前目录的 FRAG_LIB 下，生成 DON.frg 文件。命令如下：
```bash
ztop.py -f "D;p=DON.top;x=DON.gro;site=D12:11-22,D11:8-21;resname=DON;comment=benzodithiophene" --savelib
```

---

## 7. 片段位点连接规则

从分子中切割片段时，每个断点处对应一个连接位点。片段连接时依据位点标签匹配规则：优先标签完全一致；其次是子串匹配（如 D1 可匹配 D1、D12、D123）；最后是位阻匹配（如 A1H 优先匹配 A1H 而非 A1T）。匹配规则遵循最长字符串优先和位阻最小原则。

---

## 8. ACC 片段生成

对于 ACC 片段，生成拓扑和结构文件的命令如下：
```bash
cp PI_poly_init/ACC.log ./
cp PI_poly_init/ACC.fchk ./
ztop.py -g "ACC.log" -r e -o ACC.top,ACC.gro
```
定义片段时使用位点标签 A21 和 A22，这些位点不能直接与 DON 片段的 D11、D12 连接，需通过中间片段过渡。命令示例：
```bash
ztop.py -f "A;p=ACC.top;x=ACC.gro;site=A21:4-11,A22:1-10;resname=DON;comment=benzothiadiazole" --savelib
```

---

## 9. PPI 及头尾片段生成

生成 PPI 拓扑文件后，可一次性定义三个片段：中间重复单元 P、头部 H 和尾部 T。P 片段连接位点为 P1 和 P2；H 片段和 T 片段分别具有位点 H1 和 T2。命令如下：
```bash
ztop.py -f "P;p=PPI.top;x=PPI.gro;site=P1:15-8,P2:18-20;resname=PPI;comment=thiophene" \
-f "H;p=PPI.top;x=PPI.gro;site=H1:8-15;resname=DON;comment=D as head" \
-f "T;p=PPI.top;x=PPI.gro;site=T2:20-18;resname=ACC;comment=A as tail" --savelib
```

---

## 10. 查看片段库

使用 `--loadlib` 选项可以读取并显示 FRAG_LIB 目录下所有 frg 文件中的片段信息。输出内容包括片段标签、位点信息以及注释。位点信息中的描述如 "T2:C2-C2" 表示该位点由两个 C 原子组成。命令如下：
```bash
ztop.py --loadlib
```

---

## 11. 简单聚合物构建演示

构建简单聚合物序列时，使用 `-b` 选项指定片段序列。例如构建 HPAPDPT 或 10 个重复单元的聚合物：
```bash
ztop.py --loadlib -b HPAPDPT
ztop.py --loadlib -b HP[APDP]10T -o poly.top,poly.pdb
```
生成的 PDB 文件可用 GaussView 查看。

---

## 12. 片段组装逻辑

组装逻辑遵循从左至右的顺序：以 H 片段为起始，剩余接口 H1 与 P 片段的 P1 连接，P 片段剩余接口 P2 再与 A 片段的 A21 连接，依此类推。若接口不匹配（如 A22 无法直接连接 D11），程序会报错。构建无规则或支化聚合物时，需确保相邻片段存在兼容的接口。

---

## 13. 接口参数分配与电荷处理

ztop 从初始片段中获取参数，若片段末端有 1 个原子在对侧片段上，直接截取；若截取处涉及 2 个原子在对侧片段上（如二面角），则会进行等效处理。目前的电荷分配采用简单平均法，将总电荷平均分配到每个原子上。为改善电荷精度，建议从更好的源分子获取片段或使用电荷转移工具进行微调。

---

## 14. 参数与电荷转移

当聚合物中片段的构象与初始单分子构象不同时，可通过参数转移功能调整特定片段的拓扑参数。通过 `-t` 选项指定匹配原子范围和需要转移参数的原子范围，可将二面角等参数从一个结构转移到目标聚合物上。命令示例：
```bash
ztop.py -f "S;p=PPI.top;x=PPI.gro" -p poly.top -x poly.pdb -t "S;m=1-2,7-9,15-19,29,38-39;a=7-9,15-16,19;p=d"
```
其中 `m` 为匹配原子，`a` 为应用参数转移的原子，`p=d` 表示转移二面角参数。

---

## 15. 片段拼接对齐规则

当新片段 B 连接到片段 A 时，系统会计算 B 的外接口与 A 的内接口的匹配度。匹配度基于接口原子的元素类型、连接性及杂化状态。通过旋转和平移片段 B，使其接口原子与 A 的接口原子重叠，以实现最佳匹配。

---

## 16. 片段库文件管理

使用 `-f` 选项生成的片段保存在 FRAG_LIB 目录下，每个片段包含三个文件。frg 文件记录了生成片段时的命令参数。用户可直接复制相应的文件到 FRAG_LIB 目录下，通过修改 frg 文件中的标签和位点来复用或更新片段定义。

---

## 17. 同类工具对比

Polypargen 提供在线服务，提交小分子结构即可生成聚合物，但自动化程度较高，难以手动干预细节。pyPolyBuilder 也是基于片段构建的 Python 工具，但需要用户手动配置 itp 文件和 rtp 文件，操作相对繁琐。相比之下，ztop 在处理复杂拓扑结构和手动参数调整方面提供了更多的灵活性。
