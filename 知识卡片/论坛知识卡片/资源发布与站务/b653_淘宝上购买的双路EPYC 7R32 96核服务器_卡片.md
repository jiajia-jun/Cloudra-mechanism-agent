# 淘宝上购买的双路EPYC 7R32 96核服务器的使用感受和杂谈 — 知识卡片

## 1. AMD EPYC 7R32 处理器规格与特性

AMD EPYC 7R32 是亚马逊特供的 EPYC 二代（Roma 核心）处理器，拥有 48 个物理核心和 96 个逻辑核心，基础频率为 2.8 GHz。该处理器支持八通道 DDR4-3200 内存，在关闭超线程（HT）时全核满载可稳定运行在 3.3 GHz。在 EPYC 二代中，它是 48 核及以上产品中基础频率最高的型号，TDP 为 280 W。

---

## 2. 技嘉 MZ72-HB0 主板管理界面登录设置

技嘉 MZ72-HB0 主板支持通过 MegaRAC SP-X 网络管理界面进行远程监控与设置。进入 BIOS 的 Server Mgmt - BMC network configuration 菜单，可将 IP 地址设置为静态模式（如 192.168.5.100）。保存重启后，在同一网段的设备浏览器中输入该 IP 即可访问管理界面，登录用户名为 admin，密码为主板贴纸上 3/A/ 后方的字符串（如 LH4PA800228）。

---

## 3. 技嘉 MZ72-HB0 风扇转速策略配置

在技嘉 MZ72-HB0 的网络管理界面中，可通过 Settings - Fan Profile 自定义风扇转速策略以平衡噪音与散热。推荐设置策略为：温度低于 30 度时风扇转速 20%；30~77 度之间转速从 20% 线性提升至 40%；77~90 度之间转速从 40% 变化至 90%；达到或超过 95 度时风扇全速运转。此配置可将室温下 CPU 满载温度控制在 78~80 度，同时保持低转速以降低噪音。

---

## 4. 双路 EPYC 7R32 服务器散热与风扇布局建议

双路 EPYC 7R32 服务器采用从下往上的风道设计效果优于从前往后，能使两个 CPU 温度基本一致。机箱风扇并非必须，保留机箱上方两个和下方一个 14 cm 风扇即可满足散热需求，拆除机箱前面板和后侧风扇对温度影响极小但能显著降低噪音。对于 CPU 散热器，猫头鹰 NH-U12S TR4-SP3 配备单个 NF-F12 风扇已足够，加装双风扇仅能降低约 3 度温度。

---

## 5. 双路 EPYC 7R32 服务器功耗数据

双路 EPYC 7R32 服务器在关机状态下功耗约为 13 瓦，在 Windows 11 或 Rocky Linux 9.0 下待机功耗为 80~90 瓦。运行 AIDA64 压力测试（CPU/FPU/Cache/System Memory 全选）时，输入功耗约为 640 瓦，折合输出功率不足 580 瓦。使用额定 1000 W 电源（如海韵 FOCUS GX1000）已绰绰有余，无需购买 1300 W 电源。

---

## 6. Rocky Linux 9.0 在 EPYC 服务器上的安装注意事项

Rocky Linux 9.0 与双路 EPYC 7R32 服务器完全兼容，安装时建议使用 Workstation 版本并勾选 GNOME Applications、Legacy UNIX Compatibility、Development Tools 等组件。制作启动盘建议使用 Rufus 而非 UltraISO。在编译 OpenMPI 之前，需使用 yum 安装 gfortran，否则可能导致 ORCA 等程序无法正常并行。

---

## 7. Gaussian 16 在 EPYC 7R32 上的并行效率表现

在 Gaussian 16 C.02 AVX2 版测试中，双路 EPYC 7R32 使用 96 核计算大基组（def2-TZVP）任务的速度是双路 2696v3 的 3.5 倍，而小基组（def2-SVP）任务仅快 2.9 倍。开启超线程会导致满载频率从 3.3 GHz 降至 3.0 GHz，从而降低性能，因此建议在 BIOS 中关闭 SMT（超线程）功能。

---

## 8. Gaussian 多任务运行的 NUMA 绑定策略

在双路 EPYC 7R32 服务器上同时运行两个 Gaussian 任务时，建议将每个任务绑定到不同的 CPU 上（例如使用 %cpu=0-47 和 %cpu=48-95）。若不进行绑定仅使用 %nproc=48，两个 48 核任务的总耗时将比绑定模式慢约 10%。若只运行一个任务，直接运行比分跑两个任务的总速度更快。

---

## 9. ORCA 5.0.3 在 EPYC 7R32 上的性能表现

ORCA 5.0.3 在 wB97M-V/def2-TZVP 等典型任务测试中，双路 EPYC 7R32 使用 96 核的速度是双路 2696v3 的 2.8 倍。由于并行效率随核数增加而衰减，在单机上同时运行多个任务并绑定到不同 CPU 上更为划算。ORCA 的并行效率在典型任务中不及 Gaussian 使用大基组进行 DFT 计算时的效率。

---

## 10. CP2K 在 EPYC 7R32 上的最佳核数与多任务策略

在 CP2K 2022.1 测试中，使用全部 96 核运行单个任务时 SCF 步骤速度不稳定且偶发耗时剧增，使用 81 核更为保险。超过 48 核后性能提升不明显，因此建议同时运行两个 48 核任务，并通过 mpirun 结合 -rf 参数将任务分别绑定在两个 CPU 上，以获得最佳总吞吐量并避免内存访问冲突。

---

## 11. 双路 EPYC 7R32 整体性能评价

在 Cinebench R23 测试中，双路 EPYC 7R32 多核得分约为双路 2696v3 的 3.5 倍，略高于双路 XEON 8375C 的得分。受限于量子化学和第一性原理程序的并行效率，实际计算任务中的性能提升倍数通常低于理论值。该处理器适合组建高性价比的计算化学服务器，尤其在大基组 DFT 计算中优势明显。
