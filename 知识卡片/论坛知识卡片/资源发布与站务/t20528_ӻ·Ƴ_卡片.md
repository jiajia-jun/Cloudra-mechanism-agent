## 1. MEPplot 简介

MEPplot 是一款用于计算化学路径可视化的绘图工具，能够在等值面图上绘制反应路径。该工具适用于计算化学中反应路径的分析与展示。
- 支持在等值面图上绘制反应路径

---

## 2. MEPplot 的获取与使用

MEPplot 软件打包为 Windows 可执行程序，下载压缩包并解压后即可直接运行，无需额外安装步骤。
- 解压后可直接运行

## 4. 算法基础与兼容性

MEPplot 的算法核心基于 String method，适用于计算化学中反应路径的追踪。该软件能够读取 NEB（微动弹性带）方法输出的路径数据进行可视化。
- 基于 String method 算法
- 适用于 NEB 方法输出数据的可视化
