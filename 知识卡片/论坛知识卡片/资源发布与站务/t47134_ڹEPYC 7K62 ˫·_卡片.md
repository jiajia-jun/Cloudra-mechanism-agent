## 1. EPYC 7K62 服务器搭建选型

AMD EPYC 7K62 服务器平台具有较高的性价比和双路性能表现，适合搭建个人计算服务器。平台主板仅支持 PCIe 3.0 且 M.2 接口数量有限，若需加装 SSD 建议选择兼容的型号（如三星 980 PRO 或 Intel 905P）。为了节省成本，可选用 1200w 沙龙改服务器电源替代昂贵且噪音较大的专用服务器电源。

---

## 2. 服务器散热注意事项

在安装 CPU 和散热器之前，建议先涂抹硅脂，并提前准备一瓶“530 清洁剂”和一把细毛刷。这些工具用于在散热器安装过程中清理溢出的硅脂，防止液体硅脂流入 CPU 插槽造成损坏。

---

## 3. BMC 基板管理控制器功能

BMC 是服务器主板上的独立管理系统，支持远程监控温度、电压、功耗以及控制开关机。BMC 能够记录系统运行日志，便于排查故障，即使主机处于关机状态也能独立工作。用户可以直接通过 BMC 界面查看系统信息或进行 BIOS 设置，无需连接显示器。

---

## 4. 风扇转速阈值与噪音控制

由于 EPYC 7K62 发热较小，系统默认的风扇转速阈值较高会导致风扇持续高速旋转产生噪音。用户可以通过 BMC 设置调整风扇阈值（如将下限设为 200、300、400），从而降低转速，但需注意修改设置后需执行 BMC 冷重启（mc reset cold）才能生效。

---

## 5. Ubuntu 环境下的 IPMI 工具安装

在 Ubuntu 24.04 LTS 系统中，可通过包管理器安装 `ipmitool` 和 `sensors` 工具以实现对 BMC 的访问和温度监控。安装命令为 `sudo apt install ipmitool sensors -y`，安装后即可通过命令行与 BMC 进行通信。

---

## 6. IPMI 命令行配置风扇阈值

使用 `ipmitool` 命令可以通过局域网修改 BMC 的风扇阈值。基本命令格式包括指定协议、BMC IP 地址、用户名及密码，例如：`ipmitool -I lanplus -H 192.168.31.252 -U ADMIN -P ADMIN sensor thresh FAN1 lower 200 300 400`。配置完成后需执行冷重置命令使设置生效。

---

## 7. 基于温度的自动风扇控制脚本

通过 Shell 脚本结合 `sensors` 和 `ipmitool` 可实现根据 CPU 温度自动调节风扇转速的功能。脚本需将风扇模式设置为手动全速模式（raw 0x30 0x45 0x01 0x01），并设定初始速度（如 20%），随后在循环中读取 Tctl 温度并动态调整风扇百分比（20%、40%、60%、100%）。

---

## 8. 自动风扇控制脚本配置与运行

使用自动风扇控制脚本时，需根据实际环境修改脚本顶部的 IPMI 主机地址、用户名及密码变量。脚本编写完成后，可通过 `bash fans.sh > fan_control.log 2>&1 &` 命令将其放入后台运行，从而实现无人值守的温度监控与风扇调节。

---

## 9. 服务器显示接口兼容性

EPYC 7K62 服务器通常仅配备 VGA 视频接口，若连接 4K 或 2K 等现代显示器，可能需要额外的 VGA 转 HDMI 转换器。虽然服务器也可通过 PCIe 插槽安装如 RX580 等独立显卡，但对于纯计算节点用途通常无此必要，且需考虑电源功耗和主板兼容性。

---

## 10. 系统安装与 UEFI 启动模式

在该服务器平台上安装操作系统时，必须将 Boot 模式设置为 UEFI。若未在安装前切换至 UEFI 模式，即使安装完成系统也可能无法正常启动，需在 BIOS 设置中进行相应修改。
