## 1. 硬件兼容性与核显配置

华硕 X10DRL-I 搭配 C612 芯片组主板及 RTX 2060 显卡的硬件平台存在开机与显示信号问题。该问题通常涉及板载显卡与独立显卡之间的切换冲突，通过简单连接 VGA 线或调整 BIOS 设定可能无法彻底解决。若 BIOS 设定调整无效且主板支持核显，安装 Linux 系统时可直接连接 VGA 线至核显进行操作，待系统装好后再处理显卡切换。

---

## 2. 系统安装与引导工具制作

使用 Rufus 工具将 CentOS 7.6 系统镜像以 ISO 格式写入 U 盘制作启动盘。安装系统时建议遵循相关视频教程，安装过程中若出现 X server error 等错误，可能与 NVIDIA 驱动或 GNOME 环境有关，需记录错误信息以便后续排查。

---

## 3. NVIDIA 驱动与 CUDA 安装顺序冲突

在双显卡环境下安装 CUDA 时，若先安装 CUDA，其内置的驱动程序可能导致冲突并引发 X server error。建议先单独安装 NVIDIA 官方驱动，安装过程中选择不安装 OpenGL 文件，随后再安装 CUDA 时取消驱动选项，仅安装 Toolkit 和 Samples。

---

## 4. 预安装依赖包

在 CentOS 系统中安装 NVIDIA 驱动前，需预先安装必要的依赖包以确保编译顺利进行。执行以下命令进行安装：
```bash
yum -y install epel-release
yum -y install kernel-devel
yum -y install kernel-headers
```

---

## 5. 禁用 nouveau 驱动配置

需禁用系统自带的 nouveau 开源驱动以避免与 NVIDIA 驱动冲突。创建并编辑配置文件 `/etc/modprobe.d/nvidia-installer-disable-nouveau.conf` 和 `/lib/modprobe.d/nvidia-installer-disable-nouveau.conf`，写入以下内容：
```
blacklist nouveau
options nouveau modeset=0
```

---

## 6. 验证 nouveau 禁用状态

执行命令 `lsmod | grep nouveau` 检查 nouveau 模块是否仍在运行。若命令无输出显示，则表示 nouveau 已被成功禁用；若仍有输出，需进一步检查配置文件或执行后续步骤。

---

## 7. 修改 grub 配置禁用 nouveau

若仅修改 modprobe 配置文件未能禁用 nouveau，需修改 grub 配置。编辑 `/etc/default/grub` 文件，在 `GRUB_CMDLINE_LINUX` 行中加入 `rd.driver.blacklist=nouveau nouveau.modeset=0`，并执行 `grub2-mkconfig -o /boot/grub2/grub.cfg` 更新配置。

---

## 8. 切换至文本模式

安装 NVIDIA 驱动前需退出图形界面进入文本模式。在登录界面按下 `CTRL+ALT+F2` (或 F3) 切换至 TTY 终端，登录 root 用户后执行 `init 3` 命令进入多用户文本模式。

---

## 9. 安装 NVIDIA 驱动与参数设置

在文本模式下执行 NVIDIA 驱动安装包，关键参数为 `--no-opengl-files` 以避免与 GNOME 的 OpenGL 库冲突。安装命令示例：
```bash
sh NVIDIA*.run --no-opengl-files
```
安装过程中若提示写入 xconfig，选择 "no"。

---

## 10. 验证 NVIDIA 驱动安装

驱动安装完成后，可通过命令检查显卡识别状态与驱动信息。执行以下命令验证：
```bash
lspci |grep NVIDIA
nvidia-smi
```

---

## 11. 返回图形界面

驱动安装验证无误后，执行 `init 5` 命令切换回图形界面模式进行后续操作。

---

## 12. 安装 CUDA Toolkit

在图形界面下以 root 用户执行 CUDA 安装包。运行过程中需取消 Driver 选项的勾选（因驱动已单独安装），仅安装 Toolkit 和 Samples 组件。执行命令：
```bash
sh cuda*.run
```

---

## 13. 配置 CUDA 环境变量

安装完成后需将 CUDA 路径添加至系统环境变量。编辑用户目录下的 `~/.bashrc` 文件，添加以下内容：
```bash
export PATH=/usr/local/cuda/bin:$PATH
export LD_LIBRARY_PATH=/usr/local/cuda/lib64:$LD_LIBRARY_PATH
```
保存后执行 `source ~/.etc/profile` 或重启终端使配置生效（注意原文此处为 `source /etc/profile`）。

---

## 14. 验证 CUDA 安装版本

通过命令行工具检查 CUDA 编译器版本以确认安装成功。输入 `nvcc --version` 可查看 CUDA release 版本及构建信息，例如显示 "Cuda compilation tools, release 9.0, V9.0.176"。

---

## 15. 多版本 CUDA 管理与软件安装

系统可能存在多个 CUDA 版本，通过软链接 `cuda -> cuda-10.2` 等形式指向默认使用的版本。环境变量配置生效后，即可在普通用户权限下安装并运行各类计算化学软件。
