# Dalton程序编译安装与运行基础 — 知识卡片

## 1. Dalton程序简介

Dalton是开源免费的量子化学程序，虽然使用复杂对新手不友好，但因擅长计算响应性质具有独特地位。本文介绍Dalton suite中1983年开始发展的那个Dalton程序（非线性标度版LSDalton）的安装和运行方法。Dalton常用于计算磷光速率、寿命、旋轨耦合矩阵元、双光子吸收截面及CASSCF下的磁属性如NICS。

## Intel编译器与环境配置
编译过程基于Intel Fortran/C++编译器、MKL数学库和Intel MPI。需下载安装Intel oneAPI Base Toolkit（含DPC++/C++ Compiler和Math Kernel Library）和Intel HPC Toolkit（含Fortran Compiler和MPI Library）。编辑用户目录下的.bashrc文件，加入`source /opt/intel/oneapi/setvars.sh > /dev/null`后重新进入终端。

## cmake版本要求与处理
Dalton 2020.1要求cmake 3.x版本，若系统自带低版本（如CentOS 7.2的2.8）需升级。在联网情况下运行`yum install cmake3`，执行`mv /usr/bin/cmake /usr/bin/cmake2`备份旧版，运行`ln -s /usr/bin/cmake3 /usr/bin/cmake`创建符号链接以使用新版。

## Dalton源码下载方法
在Linux命令行运行`git clone --recursive https://gitlab.com/dalton/dalton.git`将最新版本下载到当前目录下的dalton目录，并手动将目录改名为dalton_src。不要直接在网页点击download下载压缩包，因为压缩包缺少external目录下的外部project文件。下载特定正式版（如2020.1）应使用`git clone -b Dalton2020.1 --recursive https://gitlab.com/dalton/dalton.git`。

## Dalton MPI并行版编译命令
Dalton主要靠MPI并行，需链接串行版MKL库。进入dalton_src目录依次运行：`./setup --fc=mpiifort --cc=mpiicx --cxx=mpiicpx --mkl=sequential --prefix=/sob`、`cd build`、`make install -j`。编译完成后在/sob目录下生成dalton目录，包含可执行文件。在vmware虚拟机下使用-j可能卡住，建议去掉-j以串行方式编译。

## MPI版环境变量配置与测试
在用户主目录的.bashrc文件中添加：`export PATH=$PATH:/sob/dalton`、`export DALTON_TMPDIR=/sob`（临时文件产生在/sob/DALTON_scratch_root）、`export DALTON_LAUNCHER="mpirun -np 96"`（设置默认并行进程数）。重新进入终端生效后，可在dalton_src/build目录运行ctest进行测试，测试耗时约1700秒，部分Failed结果一般不影响使用。

## AMFI旋轨耦合计算的编译Bug警告
结合Intel编译器做AMFI方式旋轨耦合计算存在严重bug（结果不合理），详见https://gitlab.com/dalton/dalton/-/issues/186。解决方法是改用gcc编译：确保非Intel环境、gcc和OpenMPI已安装并活动，运行`./setup --mpi --prefix=/sob/dalton`。此方法编译的Dalton运行速度比Intel版慢几倍，建议仅AMFI计算使用。

## Dalton MKL并行版编译与配置
对于不支持MPI并行的功能（如耦合簇），可编译串行版Dalton但链接并行版MKL库。重命名原dalton目录（如dalton_MPI），删掉build目录后运行：`./setup --fc=ifort --cc=icx --cxx=icpx --mkl=parallel --prefix=/sob`、`cd build`、`make install -j`。在.bashrc中注释掉DALTON_LAUNCHER，加入`export OMP_NUM_THREADS=96`，重新进入终端生效。

## MPI并行与MKL并行的选择建议
通过MKL实现并行可以跑所有任务，通过MPI实现并行只能跑支持MPI并行的任务。凡是能用MPI并行的任务建议用MPI并行版，耗时通常更低。MKL并行版仅适用于不支持MPI并行的功能以利用多核加速。长时间使用后记得清理Dalton临时文件目录下的积攒文件。

## Dalton基本运行格式
运行需要一个.dal文件（含计算任务说明）和一个.mol文件（含分子结构、基组定义）。运行格式为：`dalton [选项] [.dal] [.mol]`，例如`dalton DFT1 H2O`。运行完毕后当前目录生成输出文件"dal名_mol名.out"及同名.tar.gz压缩包（含molden.inp等零碎文件）。

## 监控Dalton运算过程
运算期间屏幕不显示细节信息，可随时查看临时文件目录下的`$DALTON_TMPDIR/DALTON_scratch_用户名/dal名_mol名_pid号/DALTON.OUT`。使用`tail -f [文件名]`可实时将此文件最新写入的信息同步输出到屏幕进行监控。

## Dalton常用运行选项
常用选项包括：`-N 96`（MPI版用96个进程）；`-omp 96`（MKL版用96个线程）；`-mb 2500`/`-gb 5`（设定每个进程内存上限）；`-noarch`（不产生.tar.gz）；`-nobackup`（不备份旧输出文件）；`-ow`（输出文件直接输出到当前目录）；`-o [文件名]`（指定输出文件名）。MPI版内存限制是每个进程的量，非总量。

## 运行选项默认值修改
dalton命令实际是调用dalton目录下的bash脚本。若想修改默认选项，可编辑dalton脚本第74行附近（针对Dalton 2020.1）的参数，如将opt_nobackup、opt_noarch设为1，opto设为2，则默认启用nobackup、noarch、ow选项。

## 同时使用MPI版和MKL版的方法
若同时使用MPI版（/sob/dalton_MPI）和MKL版（/sob/dalton），建议在.bashrc中不设DALTON_LAUNCHER和OMP_NUM_THREADS，但添加别名`alias daltonmpi='/sob/dalton_MPI/dalton'`。运行MKL并行版使用`dalton -omp 96 love live`，运行MPI并行版使用`daltonmpi -N 96 love live`。

## Dalton输入文件注意事项
Dalton对基组大小写敏感（如aug-cc-pVDZ不能写为aug-cc-pvdz）。Dalton主要计算闭壳层基态，默认自旋多重度为1。默认对所有基组使用球谐函数且不冻核。.dal文件内可用#或!进行注释。

## CCSD(T)单点计算输入示例
CCSD(T)单点计算的.dal文件示例如下：
**DALTON INPUT
.RUN WAVE FUNCTIONS
**WAVE FUNCTIONS
.CC
*CC INPUT
.CC(T)
**END OF INPUT

## B3LYP几何优化输入示例
B3LYP几何优化任务的.dal文件示例如下（B3LYPg代表使用与Gaussian相同的定义）：
**DALTON INPUT
.OPTIMIZE
**WAVE FUNCTIONS
.DFT
 B3LYPg
**END OF INPUT

## Dalton分子文件格式与示例
.mol文件使用ATOMBASIS分别设定基组，标题行必须有。Atomtypes指原子类型（非元素种类），使用Nosymmetry时直接对应元素数。示例：
ATOMBASIS
test molecule
Generated by Multiwfn
Atomtypes=4 Angstrom Nosymmetry charge=0
Charge=1.0 Atoms=3 Basis=6-31G*
H1 -0.45438149 1.43099761 0.00000000
...
（后续原子定义略）

## 基组与赝势的使用
基组库目录dalton/basis下的基组可通过basis或atombasis使用，基组名即文件名。赝势在basis/ecp_data里，通过ECP=xxx使用。例如：`Basis=stuttgart_rlc_ecp ECP=stuttgart_rlc_ecp`。若文件中含有基函数信息（如.fch），Multiwfn还可将波函数写入.dal文件作为初猜。

## 利用Multiwfn生成Dalton输入文件
由于.mol文件格式复杂，建议使用Multiwfn生成：启动Multiwfn载入结构文件，依次输入100（主功能）、2（导出文件）、19（导出Dalton输入文件），指定.dal和.mol文件名。生成的.dal对应B3LYP单点计算，.mol对应6-31G*基组且无对称性。若此功能带来便利，建议引用Multiwfn原文。
